# Companion settings

Open the app menu and select **Settings**. These settings affect Companion on your phone or tablet. To change a paired StbEmu installation, use its device actions instead.

![Companion settings categories](/img/companion/settings.png)

## Language, appearance, and vibration

Open **Interface**:

- **Language:** select an available app language. Companion currently offers English and Ukrainian; the documentation language does not change the app language.
- **Theme:** select **Light** or **Dark**.
- **UI haptic feedback:** vibrate for app buttons, menus, and selection controls.
- **Remote control haptic feedback:** vibrate for sent key presses, long presses, and repeats on the remote.

Both vibration switches default to on and are independent. Turning off UI vibration does not turn off remote vibration. Visible remote feedback remains available without vibration.

Preferences are saved locally. If saving fails, follow the displayed retry/error guidance and check the selected value; do not assume an unsaved choice persisted.

## Backup settings and licenses

**Backups > System backup** configures Android backup of Companion. Read [Android system backup](system-backup.md) for archive inclusion, estimates, and restore limits. The working **Backups** library is opened from the app menu; it is not the system-backup settings page.

**About > Third-party licenses** displays notices for libraries distributed with Companion.
