# StbEmu Companion

**StbEmu Companion** is an Android app for managing StbEmu from a phone or tablet on your local network. It provides remote controls, profile management, transfers between devices, and a private backup library. It does not provide TV channels, playlists, or an IPTV subscription.

:::note
StbEmu Companion requires **StbEmu 2.0.25 or later** on the device you want to connect to.
:::

:::note
StbEmu Companion is not publicly released yet. To join the beta, email [support@stbemu.com](mailto:support@stbemu.com).
:::

Companion requires Android 8.0 or later and a StbEmu build with Companion support. Connect both devices to the same reachable local network and enable the service in [StbEmu's Companion settings](../settings/companion.md). Pairing authorizes the connection; actions appear only when supported by the connected device and your current access.

![Available actions for a paired StbEmu device](/img/companion/device-actions.png)

Start with [connecting and pairing](connecting-devices.md), then choose a guide:

- [Remote control](remote-control.md): navigate the portal and use supported playback keys.
- [Profiles](profiles.md): browse, create, edit, delete, and copy profiles.
- [Transferring profiles and settings](transferring-profiles.md): copy selected content to another paired device.
- [Backups and restore](backups.md): save StbEmu JSON files, import/export/share them, and restore a device.
- [Companion settings](settings.md): language, appearance, vibration, and licenses.
- [Android system backup](system-backup.md): understand backup of Companion's own settings, saved devices, and optional archives.

The documentation is available in more languages than the app. Button and setting names in these guides use the app's English labels; screenshots show the English interface. Device names, versions, and available actions can differ from the examples.
