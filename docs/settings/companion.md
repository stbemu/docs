# Companion

Open **Settings > Companion** to manage the Companion service and its paired devices. Opening this page does not start pairing.

## Service

Enable or disable the service, set its port, and review service and discovery status. If startup fails and **Retry** is offered, use it after resolving the reported problem. A service that is enabled is not necessarily listening yet; check the status and displayed address.

## Pairing

Start pairing explicitly when you want to authorize a new Companion device. Use the displayed one-time code while its pairing window is active. Cancel the pairing window when it is no longer needed. Pairing-code screens are protected from screen capture.

## Remembered devices

Review the remembered devices and select one to revoke its access. Revocation requires confirmation and applies to the selected device. Pairing trust and revocation records are not transferred through [configuration backups](/settings/backup-restore).

The [Legacy remote](/settings/common-settings#legacy-remote) category configures a separate service for older MAG software remote controls.

For the phone/tablet app, see the [StbEmu Companion guides](../stbemu-companion/index.md).
