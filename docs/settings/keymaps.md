# Key mapping

Open **Settings > Key mapping** to assign actions to physical remote keys. Mappings belong to the remote they were captured from; short and long presses can have separate assignments.

## Add or edit a mapping

1. Select the add-key action, or open an existing mapping.
2. Select **Capture a key** and press the desired key on the physical remote. Capture ends after the key is received. Arrow keys and OK remain navigation controls.
3. Choose the action to perform. Enable **Long key press** if this assignment is for a long press.
4. Select **Save** to store the assignment.

Use **Show default keys** to include the built-in mappings in the list. It is off by default.

**Reset** asks for confirmation, discards the pending changes, and reloads the mapping. It does not reset every remote key. **Delete** asks for confirmation before deleting the selected mapping.

If a key assignment already exists, a different remote uses the same name, or the mapping has changed elsewhere, review the error and correct the draft before saving again. If a mapping is saved but cannot be applied to the running portal, use the offered **Retry** action to refresh it.
