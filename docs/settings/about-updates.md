# About & updates

Open **Settings > About & updates** for app information and **Third-party notices**, which list notices for libraries shipped with the app.

Update settings, the update list, and update details appear only in builds that enable in-app updates. They are disabled in the Google Play variants of the Settings version described here. A missing update section does not indicate a settings error.

Where updates are available, review the selected update before downloading. The app displays download progress and supports cancellation. Opening Android's installer does not mean the update has been installed; complete the installation in Android and check the app version afterward.
