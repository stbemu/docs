# Settings

Open the app menu and select **Settings**. This guide covers the redesigned Settings interface; older app versions may group options differently. Available categories and actions depend on your app edition and its configuration.

## Navigation

On a TV, use Up/Down to select a category in the left pane. Its page loads automatically. Press Right to enter the page, Left to return to the categories, OK to activate a control, and Back to return to the previous page. Enter and Esc are also supported.

On a phone, select a category from the Settings home page. Use the Back control or Android's Back action to return. Wider touch layouts may show the categories beside the selected page.

## Saving changes

Switches save when activated. Text and choice editors save after you confirm them. Wait for a pending save to finish before submitting another change. Leaving a page does not cancel a save that has already been accepted.

Invalid input stays in the editor with an explanation. If settings change elsewhere while you are editing, choose **Reload**, review your draft against the refreshed settings, and confirm it again. Reload keeps the draft for review; it does not automatically save it. An item that has been deleted cannot be saved.

If the app reports that a change was saved but could not be applied to the running app, the stored value has already changed. Follow the retry or restart instruction rather than assuming that the save failed. Password-protected settings may ask you to authenticate again after reopening them.
