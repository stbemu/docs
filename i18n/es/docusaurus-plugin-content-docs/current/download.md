# Descarga {/* #download */}

![StbEmu gratuito](/img/stbemu_free_icon.png)

StbEmu está disponible en dos versiones: gratuita y Pro (de pago).

| Versión gratuita | Versión Pro (de pago) |
|--------------|---------------------------------------------------|
| Muestra anuncios | Sin anuncios |
| | Compatible con mandos por software para MAG 250 * |
| [Descargar desde Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Descargar desde Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Antes de usar un mando por software de Google Play, comprueba que sea compatible con MAG 250.
