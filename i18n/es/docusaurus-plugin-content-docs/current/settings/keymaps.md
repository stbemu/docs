# Asignación de teclas {/* #key-mapping */}

Abre **Ajustes > Asignación de teclas** para asignar acciones a las teclas de un mando físico. Las asignaciones pertenecen al mando del que se capturaron; las pulsaciones cortas y largas pueden tener asignaciones distintas.

## Añadir o editar una asignación {/* #add-or-edit-a-mapping */}

1. Selecciona la acción para añadir una tecla o abre una asignación existente.
2. Selecciona **Capturar una tecla** y pulsa la tecla deseada en el mando físico. La captura termina al recibir la tecla. Las flechas y OK siguen funcionando como controles de navegación.
3. Elige la acción que se realizará. Activa **Pulsación larga de tecla** si la asignación corresponde a una pulsación larga.
4. Selecciona **Guardar** para almacenar la asignación.

Usa **Mostrar teclas predeterminadas** para incluir en la lista las asignaciones integradas. Está desactivado de forma predeterminada.

**Restablecer** pide confirmación, descarta los cambios pendientes y vuelve a cargar la asignación. No restablece todas las teclas del mando. **Eliminar** pide confirmación antes de eliminar la asignación seleccionada.

Si ya existe una asignación para la tecla, otro mando usa el mismo nombre o la asignación ha cambiado en otro lugar, revisa el error y corrige el borrador antes de volver a guardarlo. Si una asignación se guarda pero no puede aplicarse al portal en ejecución, usa la acción **Reintentar** que se ofrece para actualizarlo.
