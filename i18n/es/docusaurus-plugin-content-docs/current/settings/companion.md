# Companion {/* #companion */}

Abre **Ajustes > Companion** para gestionar el servicio Companion y sus dispositivos vinculados. Abrir esta página no inicia la vinculación.

## Servicio Companion {/* #service */}

Activa o desactiva el servicio, establece su puerto y revisa el estado del servicio y de la detección. Si falla el inicio y se ofrece **Reintentar el servicio de conexión**, úsalo después de resolver el problema indicado. Que un servicio esté activado no significa que ya esté escuchando; comprueba el estado y la dirección mostrada.

## Emparejar un Companion {/* #pairing */}

Inicia la vinculación de forma explícita cuando quieras autorizar un nuevo dispositivo Companion. Usa el código de un solo uso mostrado mientras esté abierta la ventana de vinculación. Cancela la ventana de vinculación cuando ya no la necesites. Las pantallas del código de vinculación están protegidas contra capturas de pantalla.

## Companion recordados {/* #remembered-devices */}

Revisa los dispositivos recordados y selecciona uno para revocar su acceso. La revocación requiere confirmación y se aplica al dispositivo seleccionado. La confianza establecida mediante vinculación y los registros de revocación no se transfieren mediante las [copias de seguridad de la configuración](/settings/backup-restore).

La categoría [Mando remoto antiguo](/settings/common-settings#legacy-remote) configura un servicio independiente para los mandos por software MAG antiguos.

Para la aplicación del teléfono o la tableta, consulta las [guías de StbEmu Companion](../stbemu-companion/index.md).
