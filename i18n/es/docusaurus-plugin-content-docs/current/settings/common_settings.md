# Application settings {/* #application-settings */}

Las opciones generales de la aplicación se agrupan en las siguientes categorías de [Ajustes](/settings). Las opciones específicas de cada perfil están en [Perfiles](/settings/profiles).

## Apariencia y controles {/* #appearance--controls */}

| Opción | Función |
|--------|---------|
| Idioma de la aplicación | Usa un idioma compatible o el predeterminado del sistema Android. |
| Ocultar la barra de navegación | Oculta los botones de navegación de Android cuando sea posible. En una pantalla táctil, el primer toque puede mostrar la navegación y puede ser necesario un segundo toque para mostrar los controles de la aplicación. |
| Mostrar siempre los botones superpuestos | Muestra los controles en pantalla. Puedes desactivarlo en un dispositivo de TV si al pulsar las teclas del mando aparecen botones no deseados. |
| Ocultar los controles después de… (ms) | Establece en milisegundos el tiempo que tardan en ocultarse los controles en pantalla. Valor predeterminado: 5000 (5 segundos). |
| Orientación de pantalla | Elige cómo se comporta la orientación de la aplicación. |
| Tipo de teclado | Elige el teclado que usa la aplicación. |
| Método de entrada del teclado en pantalla | Elige cómo se procesa la entrada del teclado por software. |

## Reproducción y comportamiento {/* #playback--behavior */}

| Opción | Función |
|--------|---------|
| Detener en segundo plano | Pausa la reproducción al cambiar a otra aplicación. Este control no está disponible mientras esté activado el modo automático de imagen en imagen. |
| Cambiar a PiP al minimizar | Usa el modo de imagen en imagen al salir de la aplicación, cuando Android y el dispositivo lo permitan. |
| Iniciar automáticamente al arrancar el dispositivo | Inicia la aplicación tras el arranque del dispositivo. La aplicación debe estar instalada en el almacenamiento interno; una pantalla de bloqueo puede retrasar el inicio hasta que se desbloquee. |
| Usar siempre el volumen del sistema | Usa el volumen del sistema en lugar de un volumen independiente para la aplicación. |
| Activar recomendaciones | Muestra tarjetas de recomendación de perfiles en las pantallas de inicio de Android TV compatibles. |
| Crear una sesión multimedia al iniciar la reproducción | Activa la integración con las sesiones multimedia de Android. |

## Red {/* #network */}

**Método de escalado** cambia el escalado del navegador si un portal se ve demasiado grande o pequeño. La mayoría de los dispositivos pueden mantener el valor predeterminado; una pantalla de baja resolución puede necesitar otro método.

**Activar caché de red** almacena en caché las solicitudes de red para mejorar la carga del portal. Desactívalo si encuentras problemas repetidos de autenticación u otros problemas de red.

El **Tamaño de la caché (KB)** se introduce en KB. El valor predeterminado es **20480 KB (20 MB)**. Reinicia la aplicación cuando se te indique para aplicar el cambio de tamaño de la caché.

## Seguridad {/* #security */}

Activa la protección de los ajustes mediante contraseña y establece la contraseña. Los ajustes protegidos requieren autenticación. El editor de contraseñas no conserva el valor secreto cuando se vuelve a crear la pantalla; introdúcelo de nuevo si es necesario.

## Mando remoto antiguo {/* #legacy-remote */}

Esta categoría configura el servicio antiguo de mando por software para MAG 250, AuraHD y aplicaciones de mando similares. Es independiente de [Companion](/settings/companion) y de la [asignación de teclas físicas](/settings/key-maps).

Activa el servicio y configura el nombre del dispositivo y la contraseña. El nombre y la contraseña admiten hasta 32 caracteres cada uno. Esta categoría solo está disponible en las ediciones de la aplicación que la habilitan.
