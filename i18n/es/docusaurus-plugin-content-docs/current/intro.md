# StbEmu {/* #stbemu */}

**StbEmu** es una aplicación para Android 8.0 o posterior que carga portales web diseñados para decodificadores (STB)
en dispositivos Android, incluidos teléfonos, tabletas y dispositivos de TV.
La aplicación permite actualmente emular varios modelos de STB fabricados por la empresa ucraniana Infomir,
como MAG 250, MAG 270 y MAG 322. Consulta la [lista de dispositivos emulados](/supported-devices).

:::note
**StbEmu** es una herramienta tecnológica neutral y un emulador de hardware. No proporciona, aloja ni indexa contenido multimedia,
listas de reproducción ni portales de streaming. La aplicación está diseñada para que los usuarios accedan a su propio contenido adquirido legalmente.
El desarrollador no está afiliado a ningún proveedor de contenido externo.
:::

Hay dos versiones de la aplicación: gratuita y de pago. La [versión gratuita](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) muestra anuncios; la [versión Pro](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) no.
Esta es la principal diferencia entre ambas.
