# App-Einstellungen {/* #application-settings */}

App-weite Optionen sind in [Einstellungen](/settings) in die folgenden Kategorien unterteilt. Profilspezifische Optionen finden Sie unter [Profile](/settings/profiles).

## Darstellung und Steuerung {/* #appearance--controls */}

| Option | Zweck |
|--------|---------|
| App-Sprache | Eine unterstützte App-Sprache oder die Android-Systemsprache verwenden. |
| Navigationsleiste ausblenden | Die Android-Navigationstasten ausblenden, soweit unterstützt. Auf einem Touchscreen zeigt die erste Berührung möglicherweise die Navigation an; für die App-Bedienelemente kann eine zweite Berührung nötig sein. |
| Überlagerte Schaltflächen immer anzeigen | Bildschirm-Bedienelemente anzeigen. Auf einer TV-Box können Sie dies deaktivieren, wenn Fernbedienungstasten unerwünschte Bildschirmtasten einblenden. |
| Bedienelemente ausblenden nach… (ms) | Die Anzeigedauer der Bildschirm-Bedienelemente in Millisekunden festlegen. Standard: 5000 (5 Sekunden). |
| Bildschirmausrichtung | Das Ausrichtungsverhalten der App wählen. |
| Tastaturtyp | Die von der App verwendete Tastatur wählen. |
| Eingabemethode der Bildschirmtastatur | Festlegen, wie die Softwaretastatur Eingaben verarbeitet. |

## Wiedergabe und Verhalten {/* #playback--behavior */}

| Option | Zweck |
|--------|---------|
| Im Hintergrund anhalten | Die Wiedergabe beim Wechsel zu einer anderen App anhalten. Diese Option ist bei aktiviertem automatischem Bild-in-Bild nicht verfügbar. |
| Beim Minimieren in PiP-Modus wechseln | Beim Verlassen der App Bild-in-Bild verwenden, sofern Android und das Gerät dies unterstützen. |
| Beim Gerätestart automatisch starten | Die App nach dem Gerätestart starten. Sie muss im internen Speicher installiert sein; ein Sperrbildschirm kann den Start bis zum Entsperren verzögern. |
| Immer Systemlautstärke verwenden | Die Systemlautstärke anstelle einer separaten App-Lautstärke verwenden. |
| Empfehlungen aktivieren | Profil-Empfehlungskarten auf unterstützten Android-TV-Startbildschirmen anzeigen. |
| Beim Wiedergabestart Mediensitzung erstellen | Die Integration von Android-Mediensitzungen aktivieren. |

## Netzwerk {/* #network */}

**Skalierungsmethode** ändert die Browser-Skalierung, wenn ein Portal zu groß oder zu klein erscheint. Meist kann die Standardeinstellung bleiben; ein niedrig auflösendes Display benötigt eventuell eine andere Methode.

**Netzwerkcache aktivieren** speichert Netzwerkanfragen zwischen, um das Laden des Portals zu verbessern. Deaktivieren Sie dies bei wiederholten Authentifizierungs- oder anderen Netzwerkproblemen.

**Cachegröße (KByte)** wird in KB eingegeben. Der Standardwert ist **20480 KB (20 MB)**. Starten Sie die App auf Aufforderung neu, um eine geänderte Cachegröße anzuwenden.

## Sicherheit {/* #security */}

Aktivieren Sie den Passwortschutz für die Einstellungen und legen Sie ein Passwort fest. Geschützte Einstellungen erfordern eine Authentifizierung. Der Passworteditor behält das Passwort nicht, wenn die Ansicht neu erstellt wird; geben Sie es bei Bedarf erneut ein.

## Klassische Fernsteuerung {/* #legacy-remote */}

Diese Kategorie konfiguriert den älteren Software-Fernbedienungsdienst für MAG 250, AuraHD und ähnliche Fernbedienungs-Apps. Er ist von [Companion](/settings/companion) und der [Belegung physischer Tasten](/settings/key-maps) getrennt.

Aktivieren Sie den Dienst und konfigurieren Sie seinen Gerätenamen und sein Passwort. Beide dürfen jeweils bis zu 32 Zeichen lang sein. Diese Kategorie ist nur in App-Editionen verfügbar, in denen sie aktiviert ist.
