# Einstellungen {/* #settings */}

Öffnen Sie das App-Menü und wählen Sie **Settings**. Diese Anleitung beschreibt die neu gestaltete Einstellungsoberfläche; ältere App-Versionen können Optionen anders gruppieren. Welche Kategorien und Aktionen verfügbar sind, hängt von Ihrer App-Edition und ihrer Konfiguration ab.

## Navigation {/* #navigation */}

Wählen Sie auf einem Fernseher mit Up/Down eine Kategorie im linken Bereich. Ihre Seite wird automatisch geladen. Drücken Sie Right, um die Seite zu öffnen, Left, um zu den Kategorien zurückzukehren, OK, um ein Bedienelement zu aktivieren, und Back, um zur vorherigen Seite zurückzukehren. Enter und Esc werden ebenfalls unterstützt.

Wählen Sie auf einem Smartphone eine Kategorie auf der Startseite von Settings. Kehren Sie über das Back-Bedienelement oder die Android-Zurück-Aktion zurück. Breitere Touch-Layouts können die Kategorien neben der ausgewählten Seite anzeigen.

## Änderungen speichern {/* #saving-changes */}

Schalter speichern bei Betätigung. Text- und Auswahleingaben werden nach Ihrer Bestätigung gespeichert. Warten Sie auf den Abschluss eines laufenden Speichervorgangs, bevor Sie eine weitere Änderung übermitteln. Das Verlassen einer Seite bricht einen bereits angenommenen Speichervorgang nicht ab.

Ungültige Eingaben bleiben mit einer Erklärung im Editor. Werden Einstellungen während Ihrer Bearbeitung an anderer Stelle geändert, wählen Sie **Reload**, vergleichen Sie Ihren Entwurf mit den aktualisierten Einstellungen und bestätigen Sie ihn erneut. Reload behält den Entwurf zur Prüfung bei und speichert ihn nicht automatisch. Ein gelöschter Eintrag kann nicht gespeichert werden.

Wenn die App meldet, dass eine Änderung gespeichert, aber nicht auf die laufende App angewendet werden konnte, wurde der gespeicherte Wert bereits geändert. Folgen Sie der Anweisung zum erneuten Anwenden oder Neustart, statt von einem fehlgeschlagenen Speichervorgang auszugehen. Passwortgeschützte Einstellungen können nach erneutem Öffnen eine weitere Authentifizierung verlangen.
