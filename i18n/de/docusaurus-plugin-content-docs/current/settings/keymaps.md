# Tastenbelegung {/* #key-mapping */}

Öffnen Sie **Settings > Key mapping**, um physischen Fernbedienungstasten Aktionen zuzuweisen. Belegungen gehören zur Fernbedienung, von der sie erfasst wurden; kurzes und langes Drücken können unterschiedliche Zuordnungen haben.

## Eine Belegung hinzufügen oder bearbeiten {/* #add-or-edit-a-mapping */}

1. Wählen Sie die Aktion zum Hinzufügen einer Taste oder öffnen Sie eine vorhandene Belegung.
2. Wählen Sie **Capture a key** und drücken Sie die gewünschte Taste der physischen Fernbedienung. Die Erfassung endet, sobald die Taste empfangen wurde. Pfeiltasten und OK bleiben der Navigation vorbehalten.
3. Wählen Sie die auszuführende Aktion. Aktivieren Sie **Long key press**, wenn die Zuordnung für langes Drücken gelten soll.
4. Wählen Sie **Save**, um die Zuordnung zu speichern.

Mit **Show default keys** werden die integrierten Belegungen in die Liste aufgenommen. Die Option ist standardmäßig deaktiviert.

**Reset** fordert eine Bestätigung an, verwirft ausstehende Änderungen und lädt die Belegung neu. Es setzt nicht alle Fernbedienungstasten zurück. **Delete** fordert vor dem Löschen der ausgewählten Belegung eine Bestätigung an.

Falls bereits eine Tastenzuordnung existiert, eine andere Fernbedienung denselben Namen verwendet oder die Belegung an anderer Stelle geändert wurde, prüfen Sie den Fehler und korrigieren Sie den Entwurf vor dem erneuten Speichern. Wenn eine Belegung gespeichert, aber nicht auf das laufende Portal angewendet werden kann, aktualisieren Sie sie mit der angebotenen Aktion **Retry**.
