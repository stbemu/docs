### Settings {/* #settings */}
#### App Language {/* #app-language */}
Ändern Sie die App-Sprache. Standardmäßig verwendet die App die Android-Systemsprache, sofern sie unterstützt wird.

#### Hide navigation bar {/* #hide-navigation-bar */}
Die Navigationsleiste und ihre Tasten ausblenden (funktioniert möglicherweise nicht auf allen Geräten). Bei aktivierter Option müssen Sie auf
einem Touchscreen gegebenenfalls zweimal tippen, um ausgeblendete Bildschirmtasten anzuzeigen.
Das erste Tippen zeigt die Navigationsleiste an; dies ist eine Android-Beschränkung.

#### Always show overlay buttons {/* #always-show-overlay-buttons */}
Bildschirmtasten anzeigen. Diese Option sollte normalerweise aktiviert bleiben. Auf STBs können Sie sie deaktivieren, wenn die Tasten
beim Drücken einer Fernbedienungstaste erscheinen.

#### Screen configuration {/* #screen-configuration */}
Aktivieren oder deaktivieren Sie die Bildschirmdrehung bei einer Änderung der Geräteausrichtung.

#### Keyboard configuration {/* #keyboard-configuration */}
Fernbedienungseinstellungen (in der kostenlosen Version nicht verfügbar).

Konfigurieren Sie den Fernbedienungsserver, um ein Portal mit einer Software-Fernbedienung für MAG 250, AuraHD oder ähnliche Geräte zu steuern.

#### Boot options {/* #boot-options */}
##### Auto start on device boot {/* #auto-start-on-device-boot */}

Die App beim Gerätestart starten. Dies funktioniert nur, wenn die App im internen Speicher installiert ist.
Wenn Ihr Gerät einen aktiven Sperrbildschirm hat (etwa ein Smartphone oder Tablet), startet die App nach dem Entsperren.

#### Stop in the background {/* #stop-in-the-background */}
Die App beim Wechsel zu einer anderen App anhalten.

#### Android TV {/* #android-tv */}
Spezielle Optionen für Android TV.

##### Enable recommendations {/* #enable-recommendations */}

Aktivieren Sie Empfehlungskarten auf dem Android-Startbildschirm. Die App zeigt für jedes konfigurierte Profil eine Karte an,
damit Sie schnell darauf zugreifen können.

#### Browser settings {/* #browser-settings */}
Browser-Einstellungen.

##### Scaling method {/* #scaling-method */}
Wählen Sie eine andere Browser-Skalierungsmethode, wenn das Portal zu groß oder zu klein erscheint.
Bei den meisten Geräten ist keine Änderung nötig. Eine Ausnahme sind Geräte, deren Bildschirmauflösung niedriger ist
als die Auflösung des Portals, die üblicherweise 1280x720 beträgt.

#### Network settings {/* #network-settings */}
Netzwerkeinstellungen.

##### Enable network cache {/* #enable-network-cache */}
Netzwerkanfragen zwischenspeichern, um das Laden des Portals in den meisten Fällen zu beschleunigen. Deaktivieren Sie diese Option, wenn häufig
Authentifizierungsfehler oder andere Netzwerkprobleme auftreten.

##### Cache size {/* #cache-size */}
Die Größe des Netzwerkcaches. Standard: 20 MB.
