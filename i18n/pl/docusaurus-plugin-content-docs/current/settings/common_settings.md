# Ustawienia aplikacji {/* #application-settings */}

Opcje dotyczące całej aplikacji są zgrupowane w następujących kategoriach w [Settings](/settings). Opcje poszczególnych profili znajdują się w [Profiles](/settings/profiles).

## Appearance & controls

| Opcja | Przeznaczenie |
|--------|---------|
| App language | Użyj obsługiwanego języka aplikacji lub domyślnego języka systemu Android. |
| Hide navigation bar | Ukryj przyciski nawigacji Androida tam, gdzie jest to obsługiwane. Na ekranie dotykowym pierwsze dotknięcie może pokazać nawigację, a do pokazania elementów sterujących aplikacji może być potrzebne drugie. |
| Always show overlay buttons | Wyświetlaj elementy sterujące na ekranie. Na przystawce telewizyjnej możesz wyłączyć tę opcję, jeśli naciśnięcia przycisków pilota wywołują niepożądane przyciski. |
| Hide controls after… (ms) | Ustaw czas ukrywania elementów sterujących w milisekundach. Domyślnie: 5000 (5 sekund). |
| Screen orientation | Wybierz sposób obsługi orientacji ekranu przez aplikację. |
| Keyboard type | Wybierz klawiaturę używaną przez aplikację. |
| Software keyboard input method | Wybierz sposób obsługi wprowadzania danych przez klawiaturę ekranową. |

## Playback & behavior

| Opcja | Przeznaczenie |
|--------|---------|
| Pause media in background | Wstrzymaj odtwarzanie przy przejściu do innej aplikacji. Ten element jest niedostępny, gdy włączono automatyczny tryb obrazu w obrazie. |
| Picture-in-picture | Używaj trybu obrazu w obrazie po opuszczeniu aplikacji, jeśli Android i urządzenie go obsługują. |
| Auto start on device boot | Uruchamiaj aplikację po włączeniu urządzenia. Aplikacja musi być zainstalowana w pamięci wewnętrznej; ekran blokady może opóźnić uruchomienie do czasu odblokowania urządzenia. |
| Always use system volume level | Używaj głośności systemowej zamiast osobnej głośności aplikacji. |
| Enable recommendations | Wyświetlaj karty rekomendacji profili na obsługiwanych ekranach głównych Android TV. |
| Media sessions | Włącz integrację z sesjami multimedialnymi Androida. |

## Network

**Scaling method** zmienia skalowanie przeglądarki, jeśli portal jest zbyt duży lub zbyt mały. Na większości urządzeń można pozostawić ustawienie domyślne; ekran o niskiej rozdzielczości może wymagać innej metody.

**Enable network cache** buforuje żądania sieciowe, aby usprawnić wczytywanie portalu. Wyłącz tę opcję w razie powtarzających się problemów z uwierzytelnianiem lub innych problemów sieciowych.

**Cache size** jest podawane w KB. Wartość domyślna to **20480 KB (20 MB)**. Gdy pojawi się monit, uruchom aplikację ponownie, aby zastosować zmieniony rozmiar pamięci podręcznej.

## Security

Włącz ochronę ustawień hasłem i ustaw hasło. Chronione ustawienia wymagają uwierzytelnienia. Edytor hasła nie zachowuje go po ponownym utworzeniu ekranu; w razie potrzeby wpisz je ponownie.

## Legacy remote

Ta kategoria służy do konfiguracji starszej usługi programowego pilota dla MAG 250, AuraHD i podobnych aplikacji. Jest oddzielna od [Companion](/settings/companion) i [mapowania fizycznych przycisków](/settings/key-maps).

Włącz usługę oraz ustaw nazwę urządzenia i hasło. Zarówno nazwa urządzenia, jak i hasło mogą mieć do 32 znaków. Ta kategoria jest dostępna tylko w wydaniach aplikacji, które ją udostępniają.
