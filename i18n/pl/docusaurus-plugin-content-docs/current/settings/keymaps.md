# Key mapping

Otwórz **Settings > Key mapping**, aby przypisać działania fizycznym przyciskom pilota. Mapowania należą do pilota, z którego zostały przechwycone; krótkie i długie naciśnięcia mogą mieć osobne przypisania.

## Dodawanie lub edycja mapowania {/* #add-or-edit-a-mapping */}

1. Wybierz działanie dodawania przycisku lub otwórz istniejące mapowanie.
2. Wybierz **Capture a key** i naciśnij żądany przycisk na fizycznym pilocie. Przechwytywanie kończy się po odebraniu przycisku. Strzałki i OK nadal służą do nawigacji.
3. Wybierz działanie do wykonania. Włącz **Long key press**, jeśli przypisanie ma dotyczyć długiego naciśnięcia.
4. Wybierz **Save**, aby zapisać przypisanie.

Użyj **Show default keys**, aby uwzględnić wbudowane mapowania na liście. Domyślnie ta opcja jest wyłączona.

**Reset** wymaga potwierdzenia, odrzuca oczekujące zmiany i ponownie wczytuje mapowanie. Nie resetuje wszystkich przycisków pilota. **Delete** wymaga potwierdzenia przed usunięciem wybranego mapowania.

Jeśli przypisanie przycisku już istnieje, inny pilot używa tej samej nazwy lub mapowanie zmieniło się gdzie indziej, sprawdź błąd i popraw wersję roboczą przed ponownym zapisaniem. Jeśli mapowanie zostało zapisane, ale nie można go zastosować w działającym portalu, użyj oferowanego działania **Retry**, aby je odświeżyć.
