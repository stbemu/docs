### Settings
#### App Language
Изменяет язык приложения. По умолчанию используется системный язык Android, если он поддерживается.

#### Hide navigation bar
Скрывает панель навигации и её кнопки (на некоторых устройствах может не работать). Если параметр включён и вы пользуетесь сенсорным экраном, для отображения скрытых экранных кнопок может потребоваться два касания. Первое показывает панель навигации — это ограничение Android.

#### Always show overlay buttons
Показывает экранные кнопки. Обычно параметр следует оставлять включённым. На приставках STB его можно отключить, если нажатия кнопок пульта вызывают экранные кнопки.

#### Screen configuration
Включает или отключает поворот экрана при изменении ориентации устройства.

#### Keyboard configuration
Параметры дистанционного управления (недоступны в бесплатной версии).

Настройка сервера дистанционного управления порталом через программный пульт для MAG 250, AuraHD и подобных устройств.

#### Boot options
##### Auto start on device boot

Запускает приложение при включении устройства. Работает только при установке во внутреннюю память. Если включён экран блокировки (например, на телефоне или планшете), приложение запустится после разблокировки.

#### Stop in the background
Приостанавливает приложение при переходе в другое приложение.

#### Android TV
Параметры для Android TV.

##### Enable recommendations

Включает карточки рекомендаций на главном экране Android. Для каждого настроенного профиля показывается карточка быстрого доступа.

#### Browser settings
Параметры браузера.

##### Scaling method
Выберите другой способ масштабирования браузера, если портал выглядит слишком большим или маленьким. На большинстве устройств менять этот параметр не нужно. Исключение — устройство с разрешением экрана ниже разрешения портала, обычно 1280x720.

#### Network settings
Параметры сети.

##### Enable network cache
Кеширует сетевые запросы, обычно ускоряя загрузку портала. Отключите при частых ошибках аутентификации или других сетевых проблемах.

##### Cache size
Размер сетевого кеша. По умолчанию: 20 МБ.
