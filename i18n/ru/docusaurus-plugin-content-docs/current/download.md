# Загрузка

![Бесплатная версия StbEmu](/img/stbemu_free_icon.png)

StbEmu доступен в двух версиях: Free (бесплатная) и Pro (платная).

| Бесплатная версия | Версия Pro (платная) |
|-------------------|---------------------|
| Показывает рекламу | Без рекламы |
| | Поддерживает программные пульты для MAG 250 * |
| [Загрузить из Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Загрузить из Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Перед использованием программного пульта из Google Play проверьте, поддерживает ли он MAG 250.
