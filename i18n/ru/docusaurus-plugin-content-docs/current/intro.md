# StbEmu

**StbEmu** — приложение для Android 8.0+, позволяющее загружать веб-порталы, предназначенные для телевизионных приставок (STB), на устройствах Android: телефонах, планшетах и ТВ-приставках. Сейчас приложение поддерживает эмуляцию нескольких моделей украинской компании Infomir, например MAG 250, MAG 270 и MAG 322. См. [список эмулируемых устройств](/supported-devices).

:::note
**StbEmu** — нейтральный технологический инструмент и эмулятор оборудования. Он не предоставляет, не размещает и не индексирует медиаконтент, списки воспроизведения или потоковые порталы. Приложение предназначено для доступа пользователей к собственному законно полученному контенту. Разработчик не связан со сторонними поставщиками контента.
:::

Есть две версии приложения: бесплатная и платная. [Бесплатная версия](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) показывает рекламу, а [версия Pro](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) — нет. Это основное различие между ними.
