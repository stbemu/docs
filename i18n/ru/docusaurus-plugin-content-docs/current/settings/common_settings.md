# Настройки приложения

Общие параметры сгруппированы в перечисленных ниже категориях [Settings](/settings). Параметры отдельных профилей находятся в [Profiles](/settings/profiles).

## Appearance & controls

| Параметр | Назначение |
|----------|------------|
| App language | Поддерживаемый язык приложения или системный язык Android. |
| Hide navigation bar | Скрывает кнопки навигации Android, если устройство это поддерживает. На сенсорном экране первое касание может показать навигацию, а второе — элементы управления приложения. |
| Always show overlay buttons | Показывает экранные кнопки. На ТВ-приставке можно отключить, если нажатия пульта вызывают ненужные кнопки. |
| Hide controls after… (ms) | Время показа экранных кнопок в миллисекундах. По умолчанию: 5000 (5 секунд). |
| Screen orientation | Выбор поведения ориентации приложения. |
| Keyboard type | Выбор клавиатуры приложения. |
| Software keyboard input method | Способ обработки ввода программной клавиатурой. |

## Playback & behavior

| Параметр | Назначение |
|----------|------------|
| Pause media in background | Приостанавливает воспроизведение при переходе в другое приложение. Недоступно при включённой автоматической картинке в картинке. |
| Picture-in-picture | Картинка в картинке при выходе из приложения, если Android и устройство её поддерживают. |
| Auto start on device boot | Запуск после включения устройства. Приложение должно быть во внутренней памяти; экран блокировки может задержать запуск до разблокировки. |
| Always use system volume level | Системная громкость вместо отдельной громкости приложения. |
| Enable recommendations | Карточки профилей на поддерживаемых главных экранах Android TV. |
| Media sessions | Интеграция с медиасессиями Android. |

## Network

**Scaling method** меняет масштаб браузера, если портал выглядит слишком большим или маленьким. На большинстве устройств можно оставить значение по умолчанию; экрану с низким разрешением может потребоваться другой способ.

**Enable network cache** кеширует сетевые запросы для ускорения загрузки портала. Отключите параметр при повторяющихся ошибках аутентификации или других сетевых проблемах.

**Cache size** задаётся в КБ. По умолчанию: **20480 КБ (20 МБ)**. Перезапустите приложение, если оно предлагает это для применения нового размера кеша.

## Security

Включите защиту настроек паролем и задайте пароль. Защищённые настройки требуют аутентификации. Редактор пароля не сохраняет секрет при пересоздании экрана; при необходимости введите его снова.

## Legacy remote

Эта категория настраивает старую службу программного пульта для MAG 250, AuraHD и подобных приложений. Она отделена от [Companion](/settings/companion) и [назначения физических кнопок](/settings/key-maps).

Включите службу и задайте имя устройства и пароль. Имя и пароль могут содержать до 32 символов каждый. Категория доступна только в редакциях приложения, где она включена.
