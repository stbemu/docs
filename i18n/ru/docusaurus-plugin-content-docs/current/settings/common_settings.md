# Настройки приложения

Общие параметры сгруппированы в перечисленных ниже категориях [Настройки](/settings). Параметры отдельных профилей находятся в [Профили](/settings/profiles).

## Внешний вид и управление {/* #appearance--controls */}

| Параметр | Назначение |
|----------|------------|
| Язык приложения | Поддерживаемый язык приложения или системный язык Android. |
| Скрыть строку навигации | Скрывает кнопки навигации Android, если устройство это поддерживает. На сенсорном экране первое касание может показать навигацию, а второе — элементы управления приложения. |
| Всегда показывать экранные кнопки | Показывает экранные кнопки. На ТВ-приставке можно отключить, если нажатия пульта вызывают ненужные кнопки. |
| Время отображения элементов управления (мс) | Время показа экранных кнопок в миллисекундах. По умолчанию: 5000 (5 секунд). |
| Ориентация экрана | Выбор поведения ориентации приложения. |
| Тиа клавиатуры | Выбор клавиатуры приложения. |
| Метод ввода с клавиатуры | Способ обработки ввода программной клавиатурой. |

## Воспроизведение и поведение {/* #playback--behavior */}

| Параметр | Назначение |
|----------|------------|
| Пауза при неактивном окне | Приостанавливает воспроизведение при переходе в другое приложение. Недоступно при включённой автоматической картинке в картинке. |
| Переключать в режим PiP при сворачивании приложения | Картинка в картинке при выходе из приложения, если Android и устройство её поддерживают. |
| Автозапуск при включении устройства | Запуск после включения устройства. Приложение должно быть во внутренней памяти; экран блокировки может задержать запуск до разблокировки. |
| Всегда использовать системный уровень звука | Системная громкость вместо отдельной громкости приложения. |
| Включить рекомендации | Карточки профилей на поддерживаемых главных экранах Android TV. |
| Содавать медиа-сессию при воспроизведении | Интеграция с медиасессиями Android. |

## Сеть {/* #network */}

**Метод масштабирования** меняет масштаб браузера, если портал выглядит слишком большим или маленьким. На большинстве устройств можно оставить значение по умолчанию; экрану с низким разрешением может потребоваться другой способ.

**Включить кэширование сетевых запросов** кеширует сетевые запросы для ускорения загрузки портала. Отключите параметр при повторяющихся ошибках аутентификации или других сетевых проблемах.

**Размер кэша (в килобайтах)** задаётся в КБ. По умолчанию: **20480 КБ (20 МБ)**. Перезапустите приложение, если оно предлагает это для применения нового размера кеша.

## Безопасность {/* #security */}

Включите защиту настроек паролем и задайте пароль. Защищённые настройки требуют аутентификации. Редактор пароля не сохраняет секрет при пересоздании экрана; при необходимости введите его снова.

## Старый пульт {/* #legacy-remote */}

Эта категория настраивает старую службу программного пульта для MAG 250, AuraHD и подобных приложений. Она отделена от [Companion](/settings/companion) и [назначения физических кнопок](/settings/key-maps).

Включите службу и задайте имя устройства и пароль. Имя и пароль могут содержать до 32 символов каждый. Категория доступна только в редакциях приложения, где она включена.
