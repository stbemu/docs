# Профили {/* #stb-profiles */}

**Профиль STB** — набор параметров для эмуляции приставки в приложении. При первом запуске создаётся один профиль. Его можно изменить или добавить другие, чтобы загружать разные порталы на одном устройстве. Откройте **Настройки > Профили** и выберите **Добавить профиль** либо существующий профиль для редактирования. Обзор группирует параметры в разделах **Подключение**, **Воспроизведение и устройство** и **Управление профилем**. Доступные действия зависят от редакции приложения и ограничений профиля. Активный профиль удалить нельзя: сначала переключитесь на другой. Удаление требует подтверждения.

Правки текста и выбор из списка требуют подтверждения; переключатели сохраняются сразу. Ошибки проверки, конфликты и применение сохранённых изменений описаны в разделе [Сохранение изменений](/settings#saving-changes).

StbEmu не предоставляет, не размещает и не индексирует медиаконтент или списки воспроизведения IPTV. Пользователи должны иметь законное право на доступ к контенту через эмулятор.

### Имя профиля {/* #profile-name */}
Имя профиля. Допускается любая непустая строка.

### Настройки портала {/* #portal-settings */}
Параметры конкретного портала.
##### URL адрес портала {/* #portal-url */}
Введите абсолютный URL **http://** или **https://**. Поддерживаются узлы локальной сети, localhost, IPv6 и международные доменные имена. Сетевые URL не должны содержать пробелы. Для внутреннего портала также принимаются абсолютный путь к файлам или поддерживаемый абсолютный URL **file://**. Обновлённый редактор не принимает FTP-адреса.

##### Язык портала {/* #portal-language */}
Язык портала по умолчанию — двухбуквенный код языка по стандарту [ISO 639-1](https://en.wikipedia.org/wiki/ISO_639-1).

#### Настройки HTTP-прокси {/* #http-proxy-settings */}
Параметры HTTP-прокси.

##### Использовать HTTP прокси {/* #use-http-proxy */}
Включите, если хотите использовать HTTP-прокси.

##### Адрес сервера {/* #proxy-host-name */}
Хост прокси задаётся отдельно от порта; по умолчанию — 127.0.0.1.
##### Порт {/* #proxy-port */}
По умолчанию: 3128. Хост и порт можно редактировать, только если включён **Использовать HTTP прокси**.

##### Используется внутренний портал {/* #portal-is-internal */}
Включите для внутреннего портала MAG. Локальный URL автоматически включает параметр и блокирует переключатель. Переход на сетевой URL сбрасывает автоматическую отметку внутреннего портала.

##### URL адрес портала (Используется внутренний портал) {/* #internal-portal-url */}
Введите локальный путь или файловый URL в поле **URL адрес портала**; отдельного редактора внутреннего адреса нет.

Для установки портала откройте **Настройки > Профили > нужный профиль > Настройки портала**, выберите действие установки и архив. Дождитесь распаковки и подтвердите предложенный локальный URL. Установка файлов и принятие адреса — отдельные шаги. Для удаления установленного внутреннего портала используйте действие удаления в **Настройки портала**.

### Настройка приставки {/* #stb-configuration */}
Основные параметры эмуляции.

#### Тип приставки {/* #stb-model */}
Модель приставки для эмуляции.

#### Прошивка {/* #firmware */}
Эмулируемая **прошивка**; настоящая прошивка не устанавливается. Некоторые порталы требуют определённую прошивку. В таком случае выберите её из списка, если она доступна. Для большинства поддерживаемых моделей STB доступна только **Generic**, обычно соответствующая последней версии.

Доступные варианты прошивки:

* Generic: обычно последняя доступная прошивка.
* Custom (только MAG 250): настраиваемая прошивка. Используйте её, если нужно изменить отдельные параметры прошивки.

Большинству пользователей следует использовать прошивку **Generic**, выбранную по умолчанию.

#### Настройки прошивки {/* #firmware-settings */}
Параметр доступен только для прошивки **Custom** (сейчас только для MAG 250). Задайте версии движка проигрывателя, JavaScript API и STB API, а также версию, описание и дату образа. Перед изменением собственной строки User Agent включите её использование.

#### User Agent
Строка User Agent веб-браузера приложения.

#### Разрешение экрана {/* #screen-resolution */}
Эмулируемое разрешение; фактическое разрешение экрана не меняется. Выберите поддерживаемое порталом значение, обычно **1280x720**.

#### MAC-адрес {/* #mac-address */}
MAC-адрес эмулируемого устройства. Можно использовать адрес принадлежащего вам устройства MAG 250 или 12 случайных шестнадцатеричных цифр (0–9, A–F), сгруппированных попарно и разделённых двоеточиями. [^wrong_mac]

Большинство порталов требуют, чтобы MAC-адрес начинался с 00:1A:79.

[^wrong_mac]: На некоторых устройствах только с Wi-Fi созданный MAC-адрес может быть **00:1A:79:00:00:00**. Это значит, что приложению не удалось определить его из-за ограничений Android. Замените часть **00:00:00** случайными шестнадцатеричными цифрами, сохраняя двоеточия между парами.

#### Серийный номер {/* #serial-number */}
Серийный номер эмулируемого устройства. Большинство порталов его не проверяют, поэтому обычно подойдёт произвольная текстовая строка.

#### ID устройства {/* #device-id */}
Параметры идентификатора устройства.

##### Использовать ID устройства на основе MAC-адреса {/* #use-mac-based-device-id */}
Создаёт идентификатор на основе MAC-адреса устройства. После включения или отключения нажмите **Сбросить ID устройства к начальному значению…**, чтобы создать идентификатор заново.

##### Отправлять ID устройства {/* #send-device-id */}
Отправляет идентификатор по запросу портала. Если выключено, отправляется пустая строка.

##### Зерно случайности идентификатора устройства {/* #device-id-random-seed */}
Начальное значение для генерации идентификатора устройства. Используйте одинаковое значение на устройствах с одинаковыми URL портала и MAC-адресом. Подтверждение нового значения автоматически создаёт идентификаторы заново. Не нажимайте **Сбросить ID устройства к начальному значению…**, если хотите сохранить начальное значение: это действие его очищает.

##### ID устройства {/* #device-id-value */}
Идентификатор устройства. Используйте созданное значение или введите своё.

##### Собственные идентификатор устройства 2 и подпись {/* #custom-device-id-2-and-signature */}
Включите этот параметр, чтобы изменять поле **Идентификатор устройства 2** и подпись.

##### Идентификатор устройства 2 {/* #device-id-2 */}
##### Подпись {/* #signature */}
##### Сбросить ID устройства к начальному значению… {/* #reset-device-id-to-default-value */}
После подтверждения очищает начальное значение и заново создаёт **ID устройства**, **Идентификатор устройства 2** и подпись из текущих данных профиля. Другие параметры профиля сохраняются.

Ручное изменение поля **ID устройства** доступно, только если включён параметр **Отправлять ID устройства** и выключена генерация на основе MAC-адреса. Для изменения полей **Идентификатор устройства 2** и **Подпись** также требуется включить параметр **Собственные идентификатор устройства 2 и подпись**. Автоматически полученные значения доступны для чтения, даже если редактирование недоступно.

#### Настройки эмуляции аппаратной части {/* #hardware-settings */}
##### Производитель {/* #vendor */}
##### Аппаратная версия {/* #hardware-version */}

Параметры устройства также включают совместимость с Ministra и перенаправление браузера. Меняйте их по требованиям портала.

### Настройки медиаплеера {/* #media-player-settings */}

Параметры проигрывателя для этого профиля.
#### Видеопроигрыватель {/* #media-player */}
Выберите проигрыватель по умолчанию для этого профиля.

Список включает автоматический выбор, Exo, внутренний проигрыватель Android и внешний проигрыватель, а также дополнительные проигрыватели, доступные в сборке. Выбирайте из вариантов приложения. Поддержка кодеков внутренним проигрывателем зависит от Android; внешние проигрыватели открывают потоки в другом приложении.

#### Настройки UDPXY {/* #udpxy-settings */}
##### Включить поддержку UDPXY {/* #enable-udxpy-support */}
Включайте UDPXY только после ввода корректного HTTP/HTTPS URL сервера.
##### URL сервера UDPXY {/* #udpxy-server-url */}
URL можно ввести при выключенном UDPXY. Пустое значение допускается только в выключенном состоянии; непустой URL должен быть корректным HTTP/HTTPS-адресом.
##### Заменять протокол потока {/* #overwrite-stream-protocol */}
Выберите замену протокола потока, когда UDPXY включён.
### Расширенные настройки {/* #advanced-settings */}
Параметры совместимости профиля включают CSS-патчи, обнаружение эмулятора, исправления цвета фона, ссылок на локальные файлы и AJAX, а также события возврата и кнопок для внешних проигрывателей. События Назад, Выход и OK зависят от включения события возврата к списку каналов. Меняйте их только по требованиям портала или внешнего проигрывателя.
