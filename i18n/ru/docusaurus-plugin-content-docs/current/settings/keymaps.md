# Назначение кнопок

Откройте **Settings > Key mapping**, чтобы назначить действия физическим кнопкам пульта. Назначения относятся к пульту, с которого они были считаны; короткое и долгое нажатия могут иметь отдельные действия.

## Добавление или изменение назначения {/* #add-or-edit-a-mapping */}

1. Выберите действие добавления кнопки или откройте существующее назначение.
2. Нажмите **Capture a key** и нужную физическую кнопку пульта. После получения кнопки захват заканчивается. Стрелки и OK остаются элементами навигации.
3. Выберите действие. Включите **Long key press**, если назначение относится к долгому нажатию.
4. Нажмите **Save**, чтобы сохранить назначение.

Включите **Show default keys**, чтобы отобразить встроенные назначения в списке. По умолчанию они скрыты.

**Reset** запрашивает подтверждение, отменяет несохранённые изменения и перезагружает назначение. Это не сбрасывает все кнопки пульта. **Delete** запрашивает подтверждение перед удалением выбранного назначения.

Если назначение уже существует, другой пульт использует то же имя или назначение изменилось в другом месте, проверьте ошибку и исправьте черновик перед повторным сохранением. Если назначение сохранено, но не применилось к работающему порталу, используйте предложенное действие **Retry**.
