# Settings

Abra o menu da aplicação e selecione **Settings**. Este guia aborda a interface de Settings reformulada; versões mais antigas da aplicação podem agrupar as opções de outra forma. As categorias e ações disponíveis dependem da edição da aplicação e da sua configuração.

## Navegação {/* #navigation */}

Numa TV, use Up/Down para selecionar uma categoria no painel esquerdo. A página correspondente é carregada automaticamente. Prima Right para entrar na página, Left para voltar às categorias, OK para ativar um controlo e Back para voltar à página anterior. Enter e Esc também são aceites.

Num telemóvel, selecione uma categoria na página inicial de Settings. Use o controlo Back ou a ação Voltar do Android para voltar. Em ecrãs táteis mais largos, as categorias podem aparecer ao lado da página selecionada.

## Como guardar alterações {/* #saving-changes */}

Os interruptores guardam as alterações ao serem acionados. Os editores de texto e de seleção guardam após a sua confirmação. Aguarde a conclusão de uma gravação pendente antes de enviar outra alteração. Sair de uma página não cancela uma gravação já aceite.

Entradas inválidas permanecem no editor com uma explicação. Se as definições forem alteradas noutro local enquanto edita, escolha **Reload**, compare o seu rascunho com as definições atualizadas e confirme novamente. Reload mantém o rascunho para revisão; não o guarda automaticamente. Um item eliminado não pode ser guardado.

Se a aplicação informar que uma alteração foi guardada, mas não pôde ser aplicada à aplicação em execução, o valor armazenado já foi alterado. Siga a instrução para tentar novamente ou reiniciar, em vez de presumir que a gravação falhou. As definições protegidas por palavra-passe podem pedir uma nova autenticação depois de serem reabertas.
