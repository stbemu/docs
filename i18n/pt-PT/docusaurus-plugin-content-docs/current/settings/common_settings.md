# Definições da aplicação {/* #application-settings */}

As opções que se aplicam a toda a aplicação estão agrupadas nas categorias abaixo em [Settings](/settings). As opções específicas de cada perfil ficam em [Profiles](/settings/profiles).

## Appearance & controls

| Opção | Finalidade |
|-------|------------|
| App language | Usar um idioma compatível com a aplicação ou o predefinido do sistema Android. |
| Hide navigation bar | Ocultar os botões de navegação do Android quando houver suporte. Num ecrã tátil, o primeiro toque pode mostrar a navegação, e um segundo toque pode ser necessário para mostrar os controlos da aplicação. |
| Always show overlay buttons | Mostrar controlos no ecrã. Pode desativar essa opção numa TV box se premir as teclas do comando fizer aparecer botões indesejados. |
| Hide controls after… (ms) | Definir o tempo limite dos controlos no ecrã em milissegundos. Predefinição: 5000 (5 segundos). |
| Screen orientation | Escolher o comportamento da orientação da aplicação. |
| Keyboard type | Escolher o teclado usado pela aplicação. |
| Software keyboard input method | Escolher como a entrada é processada pelo teclado virtual. |

## Playback & behavior

| Opção | Finalidade |
|-------|------------|
| Pause media in background | Colocar em pausa a reprodução ao mudar para outra aplicação. Este controlo fica indisponível quando o picture-in-picture automático está ativado. |
| Picture-in-picture | Usar picture-in-picture ao sair da aplicação, quando houver suporte no Android e no dispositivo. |
| Auto start on device boot | Iniciar a aplicação após o arranque do dispositivo. A aplicação tem de estar instalada no armazenamento interno; um ecrã de bloqueio pode adiar o arranque até que o dispositivo seja desbloqueado. |
| Always use system volume level | Usar o volume do sistema em vez de um volume separado para a aplicação. |
| Enable recommendations | Mostrar cartões de recomendação de perfis nos ecrãs iniciais de Android TV compatíveis. |
| Media sessions | Ativar a integração com as sessões de multimédia do Android. |

## Network

**Scaling method** altera a escala do navegador quando um portal aparece demasiado grande ou pequeno. Na maioria dos dispositivos, é possível manter o valor predefinido; um ecrã de baixa resolução pode precisar de outro método.

**Enable network cache** armazena pedidos de rede em cache para melhorar o carregamento do portal. Desative se ocorrerem problemas recorrentes de autenticação ou de rede.

O **Cache size** é indicado em KB. O valor predefinido é **20480 KB (20 MB)**. Reinicie a aplicação quando solicitado para aplicar a alteração no tamanho do cache.

## Security

Ative a proteção das definições por palavra-passe e defina uma palavra-passe. As definições protegidas exigem autenticação. O editor de palavra-passe não mantém a palavra-passe quando o ecrã é recriado; introduza-a novamente se necessário.

## Legacy remote

Esta categoria configura o serviço antigo de comando por software para MAG 250, AuraHD e aplicações de comando semelhantes. Este é separado do [Companion](/settings/companion) e do [mapeamento de teclas físicas](/settings/key-maps).

Ative o serviço e configure o nome do dispositivo e a palavra-passe. Cada um desses campos aceita até 32 caracteres. Esta categoria está disponível apenas nas edições da aplicação que a habilitam.
