# Definições da aplicação {/* #application-settings */}

As opções que se aplicam a toda a aplicação estão agrupadas nas categorias abaixo em [Definições](/settings). As opções específicas de cada perfil ficam em [Perfis](/settings/profiles).

## Aparência e controlos {/* #appearance--controls */}

| Opção | Finalidade |
|-------|------------|
| Idioma da aplicação | Usar um idioma compatível com a aplicação ou o predefinido do sistema Android. |
| Ocultar barra de navegação | Ocultar os botões de navegação do Android quando houver suporte. Num ecrã tátil, o primeiro toque pode mostrar a navegação, e um segundo toque pode ser necessário para mostrar os controlos da aplicação. |
| Mostrar sempre botões sobrepostos | Mostrar controlos no ecrã. Pode desativar essa opção numa TV box se premir as teclas do comando fizer aparecer botões indesejados. |
| Ocultar controlos após… (ms) | Definir o tempo limite dos controlos no ecrã em milissegundos. Predefinição: 5000 (5 segundos). |
| Orientação do ecrã | Escolher o comportamento da orientação da aplicação. |
| Tipo de teclado | Escolher o teclado usado pela aplicação. |
| Método de entrada do teclado virtual | Escolher como a entrada é processada pelo teclado virtual. |

## Reprodução e comportamento {/* #playback--behavior */}

| Opção | Finalidade |
|-------|------------|
| Parar em segundo plano | Colocar em pausa a reprodução ao mudar para outra aplicação. Este controlo fica indisponível quando o picture-in-picture automático está ativado. |
| Mudar para o modo PiP ao minimizar | Usar picture-in-picture ao sair da aplicação, quando houver suporte no Android e no dispositivo. |
| Iniciar automaticamente no arranque do dispositivo | Iniciar a aplicação após o arranque do dispositivo. A aplicação tem de estar instalada no armazenamento interno; um ecrã de bloqueio pode adiar o arranque até que o dispositivo seja desbloqueado. |
| Utilizar sempre o volume do sistema | Usar o volume do sistema em vez de um volume separado para a aplicação. |
| Ativar recomendações | Mostrar cartões de recomendação de perfis nos ecrãs iniciais de Android TV compatíveis. |
| Criar sessão multimédia ao iniciar a reprodução | Ativar a integração com as sessões de multimédia do Android. |

## Rede {/* #network */}

**Método de dimensionamento** altera a escala do navegador quando um portal aparece demasiado grande ou pequeno. Na maioria dos dispositivos, é possível manter o valor predefinido; um ecrã de baixa resolução pode precisar de outro método.

**Ativar cache de rede** armazena pedidos de rede em cache para melhorar o carregamento do portal. Desative se ocorrerem problemas recorrentes de autenticação ou de rede.

O **Tamanho da cache (KBytes)** é indicado em KB. O valor predefinido é **20480 KB (20 MB)**. Reinicie a aplicação quando solicitado para aplicar a alteração no tamanho do cache.

## Segurança {/* #security */}

Ative a proteção das definições por palavra-passe e defina uma palavra-passe. As definições protegidas exigem autenticação. O editor de palavra-passe não mantém a palavra-passe quando o ecrã é recriado; introduza-a novamente se necessário.

## Comando antigo {/* #legacy-remote */}

Esta categoria configura o serviço antigo de comando por software para MAG 250, AuraHD e aplicações de comando semelhantes. Este é separado do [Companion](/settings/companion) e do [mapeamento de teclas físicas](/settings/key-maps).

Ative o serviço e configure o nome do dispositivo e a palavra-passe. Cada um desses campos aceita até 32 caracteres. Esta categoria está disponível apenas nas edições da aplicação que a habilitam.
