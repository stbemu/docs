# Mapeamento de teclas {/* #key-mapping */}

Abra **Definições > Mapeamento de teclas** para atribuir ações às teclas de um comando físico. Os mapeamentos pertencem ao comando do qual foram capturados; toques curtos e longos podem ter atribuições separadas.

## Adicionar ou editar um mapeamento {/* #add-or-edit-a-mapping */}

1. Selecione a ação de adicionar tecla ou abra um mapeamento existente.
2. Selecione **Capturar uma tecla** e prima a tecla desejada no comando físico. A captura termina assim que a tecla é recebida. As setas e OK continuam a funcionar como controlos de navegação.
3. Escolha a ação a executar. Ative **Pressão longa de tecla** se esta atribuição for para um toque longo.
4. Selecione **Guardar** para armazenar a atribuição.

Use **Mostrar teclas predefinidas** para incluir os mapeamentos predefinidos na lista. Essa opção fica desativada por predefinição.

**Repor** pede confirmação, descarta as alterações pendentes e recarrega o mapeamento. Essa ação não repõe todas as teclas do comando. **Eliminar** pede confirmação antes de eliminar o mapeamento selecionado.

Se já existir uma atribuição para a tecla, se outro comando usar o mesmo nome ou se o mapeamento tiver sido alterado noutro local, verifique o erro e corrija o rascunho antes de guardar novamente. Se um mapeamento for guardado, mas não puder ser aplicado ao portal em execução, use a ação **Tentar novamente** oferecida para atualizá-lo.
