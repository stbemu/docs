# Transferir {/* #download */}

![StbEmu gratuito](/img/stbemu_free_icon.png)

O StbEmu está disponível em duas versões: gratuita e Pro (paga).

| Versão gratuita | Versão Pro (paga) |
|-----------------|-------------------|
| Apresenta anúncios | Sem anúncios |
| | Compatível com comandos por software para MAG 250 * |
| [Transferir do Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Transferir do Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Antes de usar um comando por software do Google Play, verifique se ele é compatível com o MAG 250.
