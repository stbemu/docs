| Version gratuite | Version Pro (payante) |
|--------------|---------------------------------------------------|
| Affiche des publicités | Sans publicité |
| | Prend en charge les télécommandes logicielles pour MAG 250 * |
| [Télécharger sur Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free)  | [Télécharger sur Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |
