# Paramètres de l’application {/* #application-settings */}

Les options globales de l’application sont regroupées dans les catégories suivantes de [Settings](/settings). Les options propres à chaque profil se trouvent sous [Profiles](/settings/profiles).

## Appearance & controls {/* #appearance--controls */}

| Option | Fonction |
|--------|---------|
| App language | Utiliser une langue prise en charge par l’application ou la langue par défaut du système Android. |
| Hide navigation bar | Masquer les boutons de navigation Android lorsque c’est possible. Sur un écran tactile, un premier appui peut afficher la navigation et un second peut être nécessaire pour afficher les commandes de l’application. |
| Always show overlay buttons | Afficher les commandes à l’écran. Vous pouvez désactiver cette option sur un boîtier TV si les touches de la télécommande font apparaître des boutons indésirables. |
| Hide controls after… (ms) | Définir le délai de masquage des commandes à l’écran en millisecondes. Valeur par défaut : 5000 (5 secondes). |
| Screen orientation | Choisir le comportement d’orientation de l’application. |
| Keyboard type | Choisir le clavier utilisé par l’application. |
| Software keyboard input method | Choisir le mode de traitement des saisies par le clavier logiciel. |

## Playback & behavior {/* #playback--behavior */}

| Option | Fonction |
|--------|---------|
| Pause media in background | Mettre la lecture en pause lors du passage à une autre application. Cette commande est indisponible lorsque l’incrustation vidéo automatique est activée. |
| Picture-in-picture | Utiliser l’incrustation vidéo en quittant l’application, si Android et l’appareil le permettent. |
| Auto start on device boot | Lancer l’application après le démarrage de l’appareil. Elle doit être installée dans le stockage interne ; un écran de verrouillage peut retarder son lancement jusqu’au déverrouillage. |
| Always use system volume level | Utiliser le volume du système plutôt qu’un volume propre à l’application. |
| Enable recommendations | Afficher des cartes de recommandation de profils sur les écrans d’accueil Android TV compatibles. |
| Media sessions | Activer l’intégration des sessions multimédias Android. |

## Network {/* #network */}

**Scaling method** modifie la mise à l’échelle du navigateur si un portail apparaît trop grand ou trop petit. La plupart des appareils peuvent conserver la valeur par défaut ; un écran basse résolution peut nécessiter une autre méthode.

**Enable network cache** met les requêtes réseau en cache pour améliorer le chargement du portail. Désactivez cette option en cas de problèmes répétés d’authentification ou d’autres problèmes réseau.

**Cache size** se saisit en Ko. La valeur par défaut est **20480 Ko (20 Mo)**. Redémarrez l’application lorsque cela vous est demandé pour appliquer la nouvelle taille du cache.

## Security {/* #security */}

Activez la protection des paramètres par mot de passe et définissez ce mot de passe. Les paramètres protégés nécessitent une authentification. L’éditeur de mot de passe ne conserve pas le secret lorsque l’écran est recréé ; saisissez-le à nouveau si nécessaire.

## Legacy remote {/* #legacy-remote */}

Cette catégorie configure l’ancien service de télécommande logicielle pour MAG 250, AuraHD et les applications similaires. Il est distinct de [Companion](/settings/companion) et de l’[affectation des touches physiques](/settings/key-maps).

Activez le service et configurez son nom d’appareil et son mot de passe. Chacun peut comporter jusqu’à 32 caractères. Cette catégorie est disponible uniquement dans les éditions de l’application qui l’activent.
