# Paramètres {/* #settings */}

Ouvrez le menu de l’application et sélectionnez **Paramètres**. Ce guide décrit la nouvelle interface des paramètres ; les anciennes versions peuvent regrouper les options différemment. Les catégories et actions disponibles dépendent de l’édition de votre application et de sa configuration.

## Navigation {/* #navigation */}

Sur un téléviseur, utilisez les touches Up/Down pour sélectionner une catégorie dans le volet gauche. Sa page se charge automatiquement. Appuyez sur Right pour entrer dans la page, Left pour revenir aux catégories, OK pour activer une commande et Retour pour revenir à la page précédente. Enter et Esc sont également pris en charge.

Sur un téléphone, sélectionnez une catégorie sur la page d’accueil de Paramètres. Utilisez la commande Retour ou l’action Retour d’Android pour revenir en arrière. Sur les écrans tactiles plus larges, les catégories peuvent apparaître à côté de la page sélectionnée.

## Enregistrement des modifications {/* #saving-changes */}

Les interrupteurs enregistrent les modifications dès leur activation. Les champs de texte et de sélection enregistrent après confirmation. Attendez la fin d’un enregistrement en cours avant de soumettre une autre modification. Quitter une page n’annule pas un enregistrement déjà accepté.

Les saisies invalides restent dans l’éditeur avec une explication. Si les paramètres changent ailleurs pendant votre modification, choisissez **Recharger**, comparez votre brouillon aux paramètres actualisés, puis confirmez-le à nouveau. Recharger conserve le brouillon pour vérification sans l’enregistrer automatiquement. Un élément supprimé ne peut pas être enregistré.

Si l’application indique qu’une modification a été enregistrée mais n’a pas pu être appliquée à l’application en cours d’exécution, la valeur stockée a déjà changé. Suivez l’instruction de nouvelle tentative ou de redémarrage plutôt que de supposer que l’enregistrement a échoué. Les paramètres protégés par mot de passe peuvent demander une nouvelle authentification après leur réouverture.
