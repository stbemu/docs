# Appinnstillinger {/* #application-settings */}

Alternativer som gjelder hele appen, er gruppert i følgende kategorier under [Settings](/settings). Profilspesifikke alternativer finner du under [Profiles](/settings/profiles).

## Appearance & controls

| Alternativ | Formål |
|--------|---------|
| App language | Bruk et støttet appspråk eller Androids standardspråk. |
| Hide navigation bar | Skjul Androids navigasjonsknapper der det støttes. På en berøringsskjerm kan det første trykket vise navigasjonen, og et nytt trykk kan være nødvendig for å vise appkontrollene. |
| Always show overlay buttons | Vis kontroller på skjermen. Du kan slå dette av på en TV-boks hvis trykk på fjernkontrollen viser uønskede knapper. |
| Hide controls after… (ms) | Angi hvor lenge skjermkontrollene skal vises, i millisekunder. Standard: 5000 (5 sekunder). |
| Screen orientation | Velg hvordan appen skal håndtere skjermretning. |
| Keyboard type | Velg tastaturet appen skal bruke. |
| Software keyboard input method | Velg hvordan inndata fra skjermtastaturet skal håndteres. |

## Playback & behavior

| Alternativ | Formål |
|--------|---------|
| Pause media in background | Sett avspillingen på pause når du bytter til en annen app. Denne kontrollen er utilgjengelig mens automatisk bilde-i-bilde er aktivert. |
| Picture-in-picture | Bruk bilde-i-bilde når du forlater appen, der Android og enheten støtter det. |
| Auto start on device boot | Start appen etter at enheten har startet. Appen må være installert i intern lagring. En låseskjerm kan utsette oppstarten til enheten låses opp. |
| Always use system volume level | Bruk systemets lydnivå i stedet for et eget lydnivå for appen. |
| Enable recommendations | Vis anbefalingskort for profiler på støttede Android TV-startskjermer. |
| Media sessions | Aktiver integrering med Androids medieøkter. |

## Network

**Scaling method** endrer nettleserens skalering hvis en portal vises for stor eller for liten. De fleste enheter kan bruke standarden; en skjerm med lav oppløsning kan trenge en annen metode.

**Enable network cache** mellomlagrer nettverksforespørsler for å forbedre innlasting av portaler. Deaktiver dette ved gjentatte autentiseringsfeil eller andre nettverksproblemer.

**Cache size** angis i KB. Standardverdien er **20480 KB (20 MB)**. Start appen på nytt når du blir bedt om det, for å ta i bruk endret mellomlagerstørrelse.

## Security

Aktiver passordbeskyttelse for innstillinger og angi passordet. Beskyttede innstillinger krever autentisering. Passordfeltet beholder ikke passordet når skjermen opprettes på nytt; skriv det inn igjen ved behov.

## Legacy remote

Denne kategorien konfigurerer den eldre tjenesten for fjernkontrollapper for MAG 250, AuraHD og lignende. Den er atskilt fra [Companion](/settings/companion) og [tilordning av fysiske taster](/settings/key-maps).

Aktiver tjenesten og angi enhetsnavn og passord. Både enhetsnavnet og passordet kan ha opptil 32 tegn. Kategorien finnes bare i apputgaver som aktiverer den.
