# Appinnstillinger {/* #application-settings */}

Alternativer som gjelder hele appen, er gruppert i følgende kategorier under [Innstillinger](/settings). Profilspesifikke alternativer finner du under [Profiler](/settings/profiles).

## Utseende og betjening {/* #appearance--controls */}

| Alternativ | Formål |
|--------|---------|
| Appspråk | Bruk et støttet appspråk eller Androids standardspråk. |
| Skjul navigasjonsfelt | Skjul Androids navigasjonsknapper der det støttes. På en berøringsskjerm kan det første trykket vise navigasjonen, og et nytt trykk kan være nødvendig for å vise appkontrollene. |
| Vis alltid overliggende knapper | Vis kontroller på skjermen. Du kan slå dette av på en TV-boks hvis trykk på fjernkontrollen viser uønskede knapper. |
| Skjul betjening etter… (ms) | Angi hvor lenge skjermkontrollene skal vises, i millisekunder. Standard: 5000 (5 sekunder). |
| Skjermretning | Velg hvordan appen skal håndtere skjermretning. |
| Tastaturtype | Velg tastaturet appen skal bruke. |
| Inndatametode for skjermtastatur | Velg hvordan inndata fra skjermtastaturet skal håndteres. |

## Avspilling og virkemåte {/* #playback--behavior */}

| Alternativ | Formål |
|--------|---------|
| Stopp i bakgrunnen | Sett avspillingen på pause når du bytter til en annen app. Denne kontrollen er utilgjengelig mens automatisk bilde-i-bilde er aktivert. |
| Bytt til PiP-modus ved minimering | Bruk bilde-i-bilde når du forlater appen, der Android og enheten støtter det. |
| Start automatisk når enheten starter | Start appen etter at enheten har startet. Appen må være installert i intern lagring. En låseskjerm kan utsette oppstarten til enheten låses opp. |
| Bruk alltid systemets volumnivå | Bruk systemets lydnivå i stedet for et eget lydnivå for appen. |
| Aktiver anbefalinger | Vis anbefalingskort for profiler på støttede Android TV-startskjermer. |
| Opprett medieøkt når avspilling starter | Aktiver integrering med Androids medieøkter. |

## Nettverk {/* #network */}

**Skaleringsmetode** endrer nettleserens skalering hvis en portal vises for stor eller for liten. De fleste enheter kan bruke standarden; en skjerm med lav oppløsning kan trenge en annen metode.

**Aktiver nettverksbuffer** mellomlagrer nettverksforespørsler for å forbedre innlasting av portaler. Deaktiver dette ved gjentatte autentiseringsfeil eller andre nettverksproblemer.

**Bufferstørrelse (kbyte)** angis i KB. Standardverdien er **20480 KB (20 MB)**. Start appen på nytt når du blir bedt om det, for å ta i bruk endret mellomlagerstørrelse.

## Sikkerhet {/* #security */}

Aktiver passordbeskyttelse for innstillinger og angi passordet. Beskyttede innstillinger krever autentisering. Passordfeltet beholder ikke passordet når skjermen opprettes på nytt; skriv det inn igjen ved behov.

## Eldre fjernstyring {/* #legacy-remote */}

Denne kategorien konfigurerer den eldre tjenesten for fjernkontrollapper for MAG 250, AuraHD og lignende. Den er atskilt fra [Companion](/settings/companion) og [tilordning av fysiske taster](/settings/key-maps).

Aktiver tjenesten og angi enhetsnavn og passord. Både enhetsnavnet og passordet kan ha opptil 32 tegn. Kategorien finnes bare i apputgaver som aktiverer den.
