# Om og oppdateringer {/* #about--updates */}

Åpne **Innstillinger > Om og oppdateringer** for appinformasjon og **Merknader fra tredjeparter**, som viser merknader for bibliotekene som følger med appen.

Oppdateringsinnstillinger, oppdateringslisten og oppdateringsdetaljer vises bare i appbygg som tillater oppdateringer i appen. De er deaktivert i Google Play-variantene av Innstillinger-versjonen som beskrives her. En manglende oppdateringsdel betyr ikke at det er feil i innstillingene.

Der oppdateringer er tilgjengelige, må du se gjennom den valgte oppdateringen før nedlasting. Appen viser nedlastingsfremdrift og lar deg avbryte. At Androids installasjonsprogram åpnes, betyr ikke at oppdateringen er installert; fullfør installasjonen i Android og kontroller appversjonen etterpå.
