# Download

| Versione gratuita | Versione Pro (a pagamento) |
|-------------------|---------------------------|
| Mostra annunci | Senza annunci |
| | Supporta telecomandi software per MAG 250 * |
| [Scarica da Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Scarica da Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |
