# Impostazioni dell'applicazione {/* #application-settings */}

Le opzioni valide per tutta l'app sono raggruppate nelle seguenti categorie di [Impostazioni](/settings). Le opzioni dei singoli profili si trovano in [Profili](/settings/profiles).

## Aspetto e comandi {/* #appearance--controls */}

| Opzione | Funzione |
|---------|----------|
| Lingua dell'app | Usa una lingua supportata dall'app o la lingua di sistema predefinita di Android. |
| Nascondi barra di navigazione | Nasconde i pulsanti di navigazione di Android, se supportato. Su uno schermo touch, il primo tocco può mostrare la navigazione e può essere necessario un secondo tocco per visualizzare i controlli dell'app. |
| Mostra sempre i pulsanti sovrapposti | Mostra i controlli sullo schermo. Puoi disattivarla su un TV box se le pressioni del telecomando fanno comparire pulsanti indesiderati. |
| Nascondi i comandi dopo… (ms) | Imposta in millisecondi il tempo di visualizzazione dei controlli. Valore predefinito: 5000 (5 secondi). |
| Orientamento dello schermo | Sceglie il comportamento dell'orientamento dell'app. |
| Tipo di tastiera | Sceglie la tastiera usata dall'app. |
| Metodo di immissione della tastiera software | Sceglie come viene gestito l'inserimento tramite tastiera software. |

## Riproduzione e comportamento {/* #playback--behavior */}

| Opzione | Funzione |
|---------|----------|
| Interrompi in background | Mette in pausa la riproduzione quando passi a un'altra app. Il controllo non è disponibile mentre è attivo il picture-in-picture automatico. |
| Passa alla modalità PiP quando ridotta a icona | Usa il picture-in-picture quando esci dall'app, se supportato da Android e dal dispositivo. |
| Avvia automaticamente all'accensione del dispositivo | Avvia l'app all'accensione del dispositivo. Deve essere installata nella memoria interna; la schermata di blocco può ritardare l'avvio fino allo sblocco. |
| Usa sempre il volume di sistema | Usa il volume di sistema anziché un volume separato dell'app. |
| Attiva suggerimenti | Mostra le schede dei profili nelle schermate iniziali Android TV supportate. |
| Crea una sessione multimediale all'avvio della riproduzione | Abilita l'integrazione con le sessioni multimediali di Android. |

## Rete {/* #network */}

**Metodo di ridimensionamento** cambia il ridimensionamento del browser se il portale appare troppo grande o troppo piccolo. Sulla maggior parte dei dispositivi puoi mantenere il valore predefinito; uno schermo a bassa risoluzione potrebbe richiedere un metodo diverso.

**Attiva cache di rete** memorizza nella cache le richieste di rete per velocizzare il caricamento del portale. Disattivala se riscontri frequenti errori di autenticazione o altri problemi di rete.

**Dimensione della cache (KByte)** è espresso in KB. Il valore predefinito è **20480 KB (20 MB)**. Riavvia l'app quando richiesto per applicare una modifica alla dimensione della cache.

## Sicurezza {/* #security */}

Abilita la protezione delle impostazioni con password e imposta la password. Le impostazioni protette richiedono l'autenticazione. L'editor della password non conserva il valore segreto quando la schermata viene ricreata: reinseriscilo se necessario.

## Telecomando precedente {/* #legacy-remote */}

Questa categoria configura il vecchio servizio per telecomandi software di MAG 250, AuraHD e app simili. È separata da [Companion](/settings/companion) e dalla [mappatura dei tasti fisici](/settings/key-maps).

Abilita il servizio e configura nome del dispositivo e password. Nome e password possono contenere fino a 32 caratteri ciascuno. La categoria è disponibile solo nelle edizioni dell'app che la abilitano.
