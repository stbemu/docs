### Settings
#### App Language
Cambia la lingua dell'app. Per impostazione predefinita usa la lingua di sistema Android, se supportata.

#### Hide navigation bar
Nasconde la barra di navigazione e i suoi pulsanti; potrebbe non funzionare su alcuni dispositivi. Se l'opzione è abilitata e usi uno schermo touch, potrebbe essere necessario toccare due volte per mostrare i pulsanti nascosti. Il primo tocco mostra la barra di navigazione: è una restrizione di Android.

#### Always show overlay buttons
Mostra i pulsanti sullo schermo. Questa opzione dovrebbe solitamente rimanere abilitata. Sui decoder STB puoi disabilitarla se i pulsanti appaiono quando premi un tasto del telecomando.

#### Screen configuration
Abilita o disabilita la rotazione dello schermo quando cambia l'orientamento del dispositivo.

#### Keyboard configuration
Impostazioni del telecomando, non disponibili nella versione gratuita.

Configura il server di controllo remoto per controllare un portale tramite un telecomando software per MAG 250, AuraHD o dispositivi simili.

#### Boot options
##### Auto start on device boot

Avvia l'app all'accensione del dispositivo. Funziona solo se l'app è installata nella memoria interna. Se il dispositivo ha una schermata di blocco, ad esempio su telefoni o tablet, l'app si avvia dopo lo sblocco.

#### Stop in the background
Mette in pausa l'app quando passi a un'altra app.

#### Android TV
Opzioni specifiche per Android TV.

##### Enable recommendations

Abilita le schede dei consigli nella schermata iniziale Android. L'app mostra una scheda per ogni profilo configurato, così puoi accedervi rapidamente.

#### Browser settings
Impostazioni del browser.

##### Scaling method
Seleziona un altro metodo di ridimensionamento del browser se il portale appare troppo grande o troppo piccolo. Sulla maggior parte dei dispositivi non serve cambiare questa impostazione. Fanno eccezione i dispositivi con risoluzione dello schermo inferiore a quella del portale, solitamente 1280x720.

#### Network settings
Impostazioni di rete.

##### Enable network cache
Memorizza nella cache le richieste di rete per velocizzare il caricamento del portale nella maggior parte dei casi. Disabilita l'opzione se riscontri frequenti errori di autenticazione o altri problemi di rete.

##### Cache size
La dimensione della cache di rete. Valore predefinito: 20 MB.
