### Settings
#### App Language
Promijenite jezik aplikacije. Aplikacija zadano upotrebljava jezik sustava Android ako je podržan.

#### Hide navigation bar
Sakrijte navigacijsku traku i njezine gumbe (možda neće raditi na nekim uređajima). Ako je ova opcija uključena i upotrebljavate
dodirni zaslon, možda ćete morati dodirnuti dvaput da se prikažu skriveni gumbi na zaslonu.
Prvi dodir prikazuje navigacijsku traku; to je ograničenje Androida.

#### Always show overlay buttons
Prikažite gumbe na zaslonu. Ova bi opcija obično trebala ostati uključena. Na STB uređajima možete je isključiti ako se gumbi
pojavljuju pri pritisku tipke na daljinskom upravljaču.

#### Screen configuration
Uključite ili isključite zakretanje zaslona kada se promijeni orijentacija uređaja.

#### Keyboard configuration
Postavke daljinskog upravljanja (nisu dostupne u besplatnoj verziji).

Konfigurirajte poslužitelj daljinskog upravljanja za upravljanje portalom softverskim daljinskim upravljačem za MAG 250, AuraHD ili slične uređaje.

#### Boot options
##### Auto start on device boot

Pokrenite aplikaciju pri pokretanju uređaja. To radi samo ako je aplikacija instalirana u unutarnjoj pohrani.
Ako je na uređaju uključen zaključani zaslon (primjerice na telefonu ili tabletu), aplikacija se pokreće nakon otključavanja.

#### Stop in the background
Pauzirajte aplikaciju kada prijeđete u drugu aplikaciju.

#### Android TV
Opcije specifične za Android TV.

##### Enable recommendations

Uključite kartice s preporukama na početnom zaslonu Androida. Aplikacija prikazuje karticu za svaki konfigurirani profil
kako biste mu mogli brzo pristupiti.

#### Browser settings
Postavke preglednika.

##### Scaling method
Odaberite drugu metodu skaliranja preglednika ako portal izgleda prevelik ili premalen.
Na većini uređaja nije potrebno mijenjati ovu postavku. Iznimka je uređaj čija je razlučivost zaslona niža
od razlučivosti portala, koja je obično 1280x720.

#### Network settings
Mrežne postavke.

##### Enable network cache
Predmemorirajte mrežne zahtjeve kako bi se portali u većini slučajeva brže učitavali. Isključite ovu opciju ako se često
pojavljuju pogreške autentifikacije ili drugi mrežni problemi.

##### Cache size
Veličina mrežne predmemorije. Zadano: 20 MB.
