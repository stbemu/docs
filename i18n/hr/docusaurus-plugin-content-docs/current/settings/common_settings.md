# Postavke aplikacije {/* #application-settings */}

Opcije za cijelu aplikaciju grupirane su u sljedeće kategorije u odjeljku [Settings](/settings). Opcije pojedinog profila nalaze se pod [Profiles](/settings/profiles).

## Appearance & controls

| Opcija | Namjena |
|--------|---------|
| App language | Upotrijebite podržani jezik aplikacije ili zadani jezik sustava Android. |
| Hide navigation bar | Sakrijte navigacijske gumbe Androida gdje je to podržano. Na dodirnom zaslonu prvi dodir može prikazati navigaciju, a drugi može biti potreban za prikaz kontrola aplikacije. |
| Always show overlay buttons | Prikažite kontrole na zaslonu. To možete isključiti na TV prijamniku ako pritisci na daljinski upravljač prikazuju neželjene gumbe. |
| Hide controls after… (ms) | Postavite vrijeme prikaza kontrola na zaslonu u milisekundama. Zadano: 5000 (5 sekundi). |
| Screen orientation | Odaberite ponašanje orijentacije aplikacije. |
| Keyboard type | Odaberite tipkovnicu koju aplikacija upotrebljava. |
| Software keyboard input method | Odaberite način obrade unosa softverske tipkovnice. |

## Playback & behavior

| Opcija | Namjena |
|--------|---------|
| Pause media in background | Pauzirajte reprodukciju pri prelasku u drugu aplikaciju. Ova kontrola nije dostupna dok je uključena automatska slika u slici. |
| Picture-in-picture | Upotrijebite sliku u slici pri napuštanju aplikacije ako to podržavaju Android i uređaj. |
| Auto start on device boot | Pokrenite aplikaciju nakon pokretanja uređaja. Aplikacija mora biti instalirana u unutarnjoj pohrani; zaključani zaslon uređaja može odgoditi pokretanje dok ga ne otključate. |
| Always use system volume level | Upotrijebite glasnoću sustava umjesto zasebne glasnoće aplikacije. |
| Enable recommendations | Prikažite kartice s preporukama profila na podržanim početnim zaslonima Android TV-a. |
| Media sessions | Uključite integraciju s medijskim sesijama Androida. |

## Network

**Scaling method** mijenja skaliranje preglednika ako portal izgleda prevelik ili premalen. Na većini uređaja možete zadržati zadanu vrijednost; zaslonu niske razlučivosti može trebati druga metoda.

**Enable network cache** predmemorira mrežne zahtjeve radi boljeg učitavanja portala. Isključite tu opciju ako se ponavljaju problemi s autentifikacijom ili drugi mrežni problemi.

**Cache size** unosi se u KB. Zadana vrijednost je **20480 KB (20 MB)**. Kada se to zatraži, ponovno pokrenite aplikaciju kako bi se primijenila promijenjena veličina predmemorije.

## Security

Uključite zaštitu postavki lozinkom i postavite lozinku. Zaštićene postavke zahtijevaju autentifikaciju. Uređivač lozinke ne zadržava tajni podatak pri ponovnom stvaranju zaslona; po potrebi ga ponovno unesite.

## Legacy remote

Ova kategorija konfigurira stariju uslugu softverskog daljinskog upravljanja za MAG 250, AuraHD i slične aplikacije. Odvojena je od usluge [Companion](/settings/companion) i [dodjele fizičkih tipki](/settings/key-maps).

Uključite uslugu i postavite naziv uređaja i lozinku. Naziv uređaja i lozinka mogu imati do 32 znaka svaki. Ova je kategorija dostupna samo u izdanjima aplikacije koja je omogućuju.
