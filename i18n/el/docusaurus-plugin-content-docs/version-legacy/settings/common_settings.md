### Settings
#### App Language
Αλλάξτε τη γλώσσα της εφαρμογής. Από προεπιλογή χρησιμοποιείται η γλώσσα συστήματος Android, εάν υποστηρίζεται.

#### Hide navigation bar
Αποκρύψτε τη γραμμή πλοήγησης και τα κουμπιά της (ενδέχεται να μη λειτουργεί σε ορισμένες συσκευές). Εάν αυτή η επιλογή είναι ενεργή και χρησιμοποιείτε
οθόνη αφής, μπορεί να χρειαστεί να αγγίξετε δύο φορές για να εμφανιστούν τα κρυμμένα κουμπιά στην οθόνη.
Το πρώτο άγγιγμα εμφανίζει τη γραμμή πλοήγησης· πρόκειται για περιορισμό του Android.

#### Always show overlay buttons
Εμφανίστε κουμπιά στην οθόνη. Αυτή η επιλογή συνήθως θα πρέπει να παραμένει ενεργή. Σε STB μπορείτε να την απενεργοποιήσετε εάν τα κουμπιά
εμφανίζονται όταν πατάτε πλήκτρο στο τηλεχειριστήριο.

#### Screen configuration
Ενεργοποιήστε ή απενεργοποιήστε την περιστροφή οθόνης όταν αλλάζει ο προσανατολισμός της συσκευής.

#### Keyboard configuration
Ρυθμίσεις τηλεχειριστηρίου (δεν διατίθενται στη δωρεάν έκδοση).

Ρυθμίστε τον διακομιστή τηλεχειρισμού για να ελέγχετε μια πύλη μέσω τηλεχειριστηρίου λογισμικού για MAG 250, AuraHD ή παρόμοιες συσκευές.

#### Boot options
##### Auto start on device boot

Εκκινήστε την εφαρμογή κατά την εκκίνηση της συσκευής. Αυτό λειτουργεί μόνο εάν η εφαρμογή είναι εγκατεστημένη στον εσωτερικό αποθηκευτικό χώρο.
Εάν η συσκευή σας έχει ενεργή οθόνη κλειδώματος (για παράδειγμα σε τηλέφωνο ή tablet), η εφαρμογή ξεκινά αφού την ξεκλειδώσετε.

#### Stop in the background
Κάντε παύση της εφαρμογής όταν μεταβαίνετε σε άλλη εφαρμογή.

#### Android TV
Επιλογές ειδικά για το Android TV.

##### Enable recommendations

Ενεργοποιήστε κάρτες προτάσεων στην αρχική οθόνη Android. Η εφαρμογή εμφανίζει μια κάρτα για κάθε ρυθμισμένο προφίλ
ώστε να έχετε γρήγορη πρόσβαση σε αυτό.

#### Browser settings
Ρυθμίσεις προγράμματος περιήγησης.

##### Scaling method
Επιλέξτε διαφορετική μέθοδο κλιμάκωσης προγράμματος περιήγησης εάν η πύλη εμφανίζεται υπερβολικά μεγάλη ή μικρή.
Στις περισσότερες συσκευές δεν χρειάζεται αλλαγή αυτής της ρύθμισης. Εξαίρεση αποτελεί μια συσκευή με ανάλυση οθόνης χαμηλότερη
από την ανάλυση της πύλης, η οποία συνήθως είναι 1280x720.

#### Network settings
Ρυθμίσεις δικτύου.

##### Enable network cache
Αποθηκεύστε προσωρινά αιτήματα δικτύου για να επιταχύνετε τη φόρτωση πύλης στις περισσότερες περιπτώσεις. Απενεργοποιήστε αυτή την επιλογή εάν συχνά
αντιμετωπίζετε σφάλματα ταυτοποίησης ή άλλα προβλήματα δικτύου.

##### Cache size
Το μέγεθος της προσωρινής μνήμης δικτύου. Προεπιλογή: 20 MB.
