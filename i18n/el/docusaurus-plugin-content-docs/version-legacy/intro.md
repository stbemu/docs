# StbEmu

Το **StbEmu** είναι μια εφαρμογή για Android 8.0+ που φορτώνει διαδικτυακές πύλες σχεδιασμένες για αποκωδικοποιητές (STB)
σε συσκευές Android, όπως τηλέφωνα, tablet και TV box.
Η εφαρμογή υποστηρίζει προς το παρόν την εξομοίωση διαφόρων μοντέλων STB της ουκρανικής εταιρείας Infomir,
όπως τα MAG 250, MAG 270 και MAG 322. Δείτε τη [λίστα εξομοιούμενων συσκευών](supported_devices.md).

:::note
Το **StbEmu** είναι ένα ουδέτερο τεχνολογικό εργαλείο και εξομοιωτής υλικού. Δεν παρέχει, φιλοξενεί ή ευρετηριάζει πολυμέσα,
λίστες αναπαραγωγής ή πύλες μετάδοσης ροής. Η εφαρμογή έχει σχεδιαστεί ώστε οι χρήστες να έχουν πρόσβαση στο δικό τους νόμιμα αποκτημένο περιεχόμενο.
Ο προγραμματιστής δεν συνδέεται με κανέναν τρίτο πάροχο περιεχομένου.
:::

Υπάρχουν δύο εκδόσεις της εφαρμογής: δωρεάν και επί πληρωμή. Η [δωρεάν έκδοση](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) εμφανίζει διαφημίσεις, ενώ η [έκδοση Pro](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) όχι.
Αυτή είναι η βασική διαφορά μεταξύ τους.
