# Key mapping

Ανοίξτε το **Settings > Key mapping** για να αντιστοιχίσετε ενέργειες στα φυσικά πλήκτρα του τηλεχειριστηρίου. Οι αντιστοιχίσεις ανήκουν στο τηλεχειριστήριο από το οποίο καταγράφηκαν· τα σύντομα και παρατεταμένα πατήματα μπορούν να έχουν ξεχωριστές αναθέσεις.

## Προσθήκη ή επεξεργασία αντιστοίχισης {/* #add-or-edit-a-mapping */}

1. Επιλέξτε την ενέργεια προσθήκης πλήκτρου ή ανοίξτε μια υπάρχουσα αντιστοίχιση.
2. Επιλέξτε **Capture a key** και πατήστε το επιθυμητό πλήκτρο στο φυσικό τηλεχειριστήριο. Η καταγραφή τελειώνει μόλις ληφθεί το πλήκτρο. Τα βέλη και το OK παραμένουν στοιχεία πλοήγησης.
3. Επιλέξτε την ενέργεια που θα εκτελείται. Ενεργοποιήστε το **Long key press** εάν η ανάθεση αφορά παρατεταμένο πάτημα.
4. Επιλέξτε **Save** για να αποθηκεύσετε την ανάθεση.

Χρησιμοποιήστε το **Show default keys** για να συμπεριλάβετε τις ενσωματωμένες αντιστοιχίσεις στη λίστα. Είναι απενεργοποιημένο από προεπιλογή.

Το **Reset** ζητά επιβεβαίωση, απορρίπτει τις εκκρεμείς αλλαγές και φορτώνει ξανά την αντιστοίχιση. Δεν επαναφέρει όλα τα πλήκτρα του τηλεχειριστηρίου. Το **Delete** ζητά επιβεβαίωση πριν διαγράψει την επιλεγμένη αντιστοίχιση.

Εάν υπάρχει ήδη ανάθεση πλήκτρου, ένα άλλο τηλεχειριστήριο χρησιμοποιεί το ίδιο όνομα ή η αντιστοίχιση έχει αλλάξει αλλού, ελέγξτε το σφάλμα και διορθώστε τις πρόχειρες αλλαγές πριν αποθηκεύσετε ξανά. Εάν μια αντιστοίχιση αποθηκευτεί αλλά δεν μπορεί να εφαρμοστεί στην εκτελούμενη πύλη, χρησιμοποιήστε την προσφερόμενη ενέργεια **Retry** για ανανέωση.
