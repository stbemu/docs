# Ρυθμίσεις {/* #settings */}

Ανοίξτε το μενού της εφαρμογής και επιλέξτε **Ρυθμίσεις**. Αυτός ο οδηγός καλύπτει το ανασχεδιασμένο περιβάλλον Ρυθμίσεις· οι παλαιότερες εκδόσεις μπορεί να ομαδοποιούν διαφορετικά τις επιλογές. Οι διαθέσιμες κατηγορίες και ενέργειες εξαρτώνται από την έκδοση της εφαρμογής σας και τη διαμόρφωσή της.

## Πλοήγηση {/* #navigation */}

Σε τηλεόραση, χρησιμοποιήστε τα πλήκτρα Up/Down για να επιλέξετε κατηγορία στο αριστερό πλαίσιο. Η σελίδα της φορτώνεται αυτόματα. Πατήστε Right για να μπείτε στη σελίδα, Left για επιστροφή στις κατηγορίες, OK για ενεργοποίηση ενός στοιχείου και Πίσω για επιστροφή στην προηγούμενη σελίδα. Υποστηρίζονται επίσης τα Enter και Esc.

Σε τηλέφωνο, επιλέξτε κατηγορία από την αρχική σελίδα Ρυθμίσεις. Χρησιμοποιήστε το στοιχείο Πίσω ή την ενέργεια επιστροφής του Android για να επιστρέψετε. Σε ευρύτερες διατάξεις αφής, οι κατηγορίες ενδέχεται να εμφανίζονται δίπλα στην επιλεγμένη σελίδα.

## Αποθήκευση αλλαγών {/* #saving-changes */}

Οι διακόπτες αποθηκεύονται όταν ενεργοποιούνται. Οι επεξεργασίες κειμένου και επιλογών αποθηκεύονται μετά την επιβεβαίωσή σας. Περιμένετε να ολοκληρωθεί μια εκκρεμής αποθήκευση πριν υποβάλετε άλλη αλλαγή. Η αποχώρηση από μια σελίδα δεν ακυρώνει αποθήκευση που έχει ήδη γίνει δεκτή.

Η μη έγκυρη καταχώριση παραμένει στον επεξεργαστή μαζί με εξήγηση. Εάν οι ρυθμίσεις αλλάξουν αλλού ενώ τις επεξεργάζεστε, επιλέξτε **Επαναφόρτωση**, συγκρίνετε τις πρόχειρες αλλαγές σας με τις ανανεωμένες ρυθμίσεις και επιβεβαιώστε ξανά. Το Επαναφόρτωση διατηρεί τις πρόχειρες αλλαγές για έλεγχο· δεν τις αποθηκεύει αυτόματα. Ένα στοιχείο που έχει διαγραφεί δεν μπορεί να αποθηκευτεί.

Εάν η εφαρμογή αναφέρει ότι μια αλλαγή αποθηκεύτηκε αλλά δεν ήταν δυνατό να εφαρμοστεί στην εκτελούμενη εφαρμογή, η αποθηκευμένη τιμή έχει ήδη αλλάξει. Ακολουθήστε την οδηγία επανάληψης ή επανεκκίνησης αντί να θεωρήσετε ότι η αποθήκευση απέτυχε. Οι ρυθμίσεις που προστατεύονται με κωδικό μπορεί να ζητήσουν νέα ταυτοποίηση όταν τις ανοίξετε ξανά.
