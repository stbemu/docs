# Ρυθμίσεις εφαρμογής {/* #application-settings */}

Οι επιλογές για όλη την εφαρμογή ομαδοποιούνται στις παρακάτω κατηγορίες του [Ρυθμίσεις](/settings). Οι επιλογές ανά προφίλ βρίσκονται στο [Προφίλ](/settings/profiles).

## Εμφάνιση και χειρισμός {/* #appearance--controls */}

| Επιλογή | Σκοπός |
|--------|---------|
| Γλώσσα εφαρμογής | Χρησιμοποιήστε μια υποστηριζόμενη γλώσσα εφαρμογής ή την προεπιλεγμένη γλώσσα του Android. |
| Απόκρυψη γραμμής πλοήγησης | Αποκρύψτε τα κουμπιά πλοήγησης του Android όπου υποστηρίζεται. Σε οθόνη αφής, το πρώτο άγγιγμα μπορεί να εμφανίσει την πλοήγηση και ίσως χρειαστεί δεύτερο για τα χειριστήρια της εφαρμογής. |
| Να εμφανίζονται πάντα τα κουμπιά οθόνης | Εμφανίστε χειριστήρια στην οθόνη. Μπορείτε να το απενεργοποιήσετε σε TV box εάν το πάτημα πλήκτρων του τηλεχειριστηρίου εμφανίζει ανεπιθύμητα κουμπιά. |
| Απόκρυψη χειριστηρίων μετά από… (ms) | Ορίστε τον χρόνο απόκρυψης των χειριστηρίων οθόνης σε χιλιοστά του δευτερολέπτου. Προεπιλογή: 5000 (5 δευτερόλεπτα). |
| Προσανατολισμός οθόνης | Επιλέξτε τη συμπεριφορά προσανατολισμού της εφαρμογής. |
| Τύπος πληκτρολογίου | Επιλέξτε το πληκτρολόγιο που χρησιμοποιεί η εφαρμογή. |
| Μέθοδος εισαγωγής πληκτρολογίου λογισμικού | Επιλέξτε τον τρόπο χειρισμού εισαγωγής από το πληκτρολόγιο λογισμικού. |

## Αναπαραγωγή και συμπεριφορά {/* #playback--behavior */}

| Επιλογή | Σκοπός |
|--------|---------|
| Διακοπή στο παρασκήνιο | Παύση αναπαραγωγής κατά τη μετάβαση σε άλλη εφαρμογή. Αυτό το στοιχείο δεν είναι διαθέσιμο όταν είναι ενεργή η αυτόματη εικόνα μέσα σε εικόνα. |
| Μετάβαση σε PiP κατά την ελαχιστοποίηση | Χρησιμοποιήστε εικόνα μέσα σε εικόνα όταν φεύγετε από την εφαρμογή, όπου υποστηρίζεται από το Android και τη συσκευή. |
| Αυτόματη εκκίνηση κατά την εκκίνηση της συσκευής | Εκκίνηση της εφαρμογής μετά την εκκίνηση της συσκευής. Η εφαρμογή πρέπει να είναι εγκατεστημένη στον εσωτερικό αποθηκευτικό χώρο· η οθόνη κλειδώματος μπορεί να καθυστερήσει την εκκίνηση μέχρι να ξεκλειδωθεί η συσκευή. |
| Να χρησιμοποιείται πάντα η ένταση ήχου του συστήματος | Χρησιμοποιήστε την ένταση του συστήματος αντί για ξεχωριστή ένταση της εφαρμογής. |
| Ενεργοποίηση προτάσεων | Εμφανίστε κάρτες προτάσεων προφίλ στις υποστηριζόμενες αρχικές οθόνες Android TV. |
| Δημιουργία συνεδρίας πολυμέσων στην έναρξη αναπαραγωγής | Ενεργοποιήστε την ενσωμάτωση συνεδριών πολυμέσων του Android. |

## Δίκτυο {/* #network */}

Το **Μέθοδος κλιμάκωσης** αλλάζει την κλιμάκωση του προγράμματος περιήγησης εάν μια πύλη εμφανίζεται υπερβολικά μεγάλη ή μικρή. Οι περισσότερες συσκευές μπορούν να διατηρήσουν την προεπιλογή· μια οθόνη χαμηλής ανάλυσης μπορεί να χρειάζεται διαφορετική μέθοδο.

Το **Ενεργοποίηση προσωρινής μνήμης δικτύου** αποθηκεύει προσωρινά αιτήματα δικτύου για καλύτερη φόρτωση της πύλης. Απενεργοποιήστε το εάν αντιμετωπίζετε επαναλαμβανόμενα προβλήματα ταυτοποίησης ή άλλα προβλήματα δικτύου.

Το **Μέγεθος προσωρινής μνήμης (KB)** εισάγεται σε KB. Η προεπιλογή είναι **20480 KB (20 MB)**. Επανεκκινήστε την εφαρμογή όταν σας ζητηθεί για να εφαρμοστεί η αλλαγή μεγέθους προσωρινής μνήμης.

## Ασφάλεια {/* #security */}

Ενεργοποιήστε την προστασία ρυθμίσεων με κωδικό και ορίστε τον κωδικό. Οι προστατευμένες ρυθμίσεις απαιτούν ταυτοποίηση. Ο επεξεργαστής κωδικού δεν διατηρεί τον μυστικό κωδικό όταν η οθόνη δημιουργείται ξανά· εισαγάγετέ τον ξανά εάν χρειάζεται.

## Παλαιό τηλεχειριστήριο {/* #legacy-remote */}

Αυτή η κατηγορία ρυθμίζει την παλαιότερη υπηρεσία τηλεχειρισμού λογισμικού για MAG 250, AuraHD και παρόμοιες εφαρμογές τηλεχειριστηρίου. Είναι ξεχωριστή από το [Companion](/settings/companion) και την [αντιστοίχιση φυσικών πλήκτρων](/settings/key-maps).

Ενεργοποιήστε την υπηρεσία και ρυθμίστε το όνομα συσκευής και τον κωδικό της. Το όνομα συσκευής και ο κωδικός επιτρέπουν έως 32 χαρακτήρες το καθένα. Η κατηγορία διατίθεται μόνο στις εκδόσεις εφαρμογής που την ενεργοποιούν.
