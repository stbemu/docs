# Ρυθμίσεις εφαρμογής {/* #application-settings */}

Οι επιλογές για όλη την εφαρμογή ομαδοποιούνται στις παρακάτω κατηγορίες του [Settings](/settings). Οι επιλογές ανά προφίλ βρίσκονται στο [Profiles](/settings/profiles).

## Appearance & controls

| Επιλογή | Σκοπός |
|--------|---------|
| App language | Χρησιμοποιήστε μια υποστηριζόμενη γλώσσα εφαρμογής ή την προεπιλεγμένη γλώσσα του Android. |
| Hide navigation bar | Αποκρύψτε τα κουμπιά πλοήγησης του Android όπου υποστηρίζεται. Σε οθόνη αφής, το πρώτο άγγιγμα μπορεί να εμφανίσει την πλοήγηση και ίσως χρειαστεί δεύτερο για τα χειριστήρια της εφαρμογής. |
| Always show overlay buttons | Εμφανίστε χειριστήρια στην οθόνη. Μπορείτε να το απενεργοποιήσετε σε TV box εάν το πάτημα πλήκτρων του τηλεχειριστηρίου εμφανίζει ανεπιθύμητα κουμπιά. |
| Hide controls after… (ms) | Ορίστε τον χρόνο απόκρυψης των χειριστηρίων οθόνης σε χιλιοστά του δευτερολέπτου. Προεπιλογή: 5000 (5 δευτερόλεπτα). |
| Screen orientation | Επιλέξτε τη συμπεριφορά προσανατολισμού της εφαρμογής. |
| Keyboard type | Επιλέξτε το πληκτρολόγιο που χρησιμοποιεί η εφαρμογή. |
| Software keyboard input method | Επιλέξτε τον τρόπο χειρισμού εισαγωγής από το πληκτρολόγιο λογισμικού. |

## Playback & behavior

| Επιλογή | Σκοπός |
|--------|---------|
| Pause media in background | Παύση αναπαραγωγής κατά τη μετάβαση σε άλλη εφαρμογή. Αυτό το στοιχείο δεν είναι διαθέσιμο όταν είναι ενεργή η αυτόματη εικόνα μέσα σε εικόνα. |
| Picture-in-picture | Χρησιμοποιήστε εικόνα μέσα σε εικόνα όταν φεύγετε από την εφαρμογή, όπου υποστηρίζεται από το Android και τη συσκευή. |
| Auto start on device boot | Εκκίνηση της εφαρμογής μετά την εκκίνηση της συσκευής. Η εφαρμογή πρέπει να είναι εγκατεστημένη στον εσωτερικό αποθηκευτικό χώρο· η οθόνη κλειδώματος μπορεί να καθυστερήσει την εκκίνηση μέχρι να ξεκλειδωθεί η συσκευή. |
| Always use system volume level | Χρησιμοποιήστε την ένταση του συστήματος αντί για ξεχωριστή ένταση της εφαρμογής. |
| Enable recommendations | Εμφανίστε κάρτες προτάσεων προφίλ στις υποστηριζόμενες αρχικές οθόνες Android TV. |
| Media sessions | Ενεργοποιήστε την ενσωμάτωση συνεδριών πολυμέσων του Android. |

## Network

Το **Scaling method** αλλάζει την κλιμάκωση του προγράμματος περιήγησης εάν μια πύλη εμφανίζεται υπερβολικά μεγάλη ή μικρή. Οι περισσότερες συσκευές μπορούν να διατηρήσουν την προεπιλογή· μια οθόνη χαμηλής ανάλυσης μπορεί να χρειάζεται διαφορετική μέθοδο.

Το **Enable network cache** αποθηκεύει προσωρινά αιτήματα δικτύου για καλύτερη φόρτωση της πύλης. Απενεργοποιήστε το εάν αντιμετωπίζετε επαναλαμβανόμενα προβλήματα ταυτοποίησης ή άλλα προβλήματα δικτύου.

Το **Cache size** εισάγεται σε KB. Η προεπιλογή είναι **20480 KB (20 MB)**. Επανεκκινήστε την εφαρμογή όταν σας ζητηθεί για να εφαρμοστεί η αλλαγή μεγέθους προσωρινής μνήμης.

## Security

Ενεργοποιήστε την προστασία ρυθμίσεων με κωδικό και ορίστε τον κωδικό. Οι προστατευμένες ρυθμίσεις απαιτούν ταυτοποίηση. Ο επεξεργαστής κωδικού δεν διατηρεί τον μυστικό κωδικό όταν η οθόνη δημιουργείται ξανά· εισαγάγετέ τον ξανά εάν χρειάζεται.

## Legacy remote

Αυτή η κατηγορία ρυθμίζει την παλαιότερη υπηρεσία τηλεχειρισμού λογισμικού για MAG 250, AuraHD και παρόμοιες εφαρμογές τηλεχειριστηρίου. Είναι ξεχωριστή από το [Companion](/settings/companion) και την [αντιστοίχιση φυσικών πλήκτρων](/settings/key-maps).

Ενεργοποιήστε την υπηρεσία και ρυθμίστε το όνομα συσκευής και τον κωδικό της. Το όνομα συσκευής και ο κωδικός επιτρέπουν έως 32 χαρακτήρες το καθένα. Η κατηγορία διατίθεται μόνο στις εκδόσεις εφαρμογής που την ενεργοποιούν.
