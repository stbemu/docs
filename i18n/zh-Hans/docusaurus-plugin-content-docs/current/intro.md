# StbEmu

**StbEmu** 是一款适用于 Android 8.0+ 的应用，可在手机、平板电脑、电视盒子等 Android 设备上
加载为机顶盒（STB）设计的网络门户。
目前，该应用支持模拟乌克兰公司 Infomir 生产的多种机顶盒型号，
例如 MAG 250、MAG 270 和 MAG 322。请参阅[可模拟的设备列表](/supported-devices).

:::note
**StbEmu** 是一款中立的技术工具和硬件模拟器，不提供、托管或索引任何媒体、
播放列表或流媒体门户。该应用旨在让用户访问自己合法获取的内容。
开发者与任何第三方内容提供商均无关联。
:::

该应用分为免费版和付费版。[免费版](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free)会显示广告；[Pro 版](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro)不显示广告。
这是两者之间的主要区别。
