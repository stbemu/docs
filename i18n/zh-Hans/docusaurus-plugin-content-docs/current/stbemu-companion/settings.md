# Companion 设置 {/* #companion-settings */}

打开应用菜单并选择 **Settings**。这些设置影响手机或平板电脑上的 Companion。要更改已配对的 StbEmu 安装实例，请使用相应的设备操作。

![Companion 设置类别](/img/companion/settings.png)

## 语言、外观和振动 {/* #language-appearance-and-vibration */}

打开 **Interface**：

- **Language**：选择可用的应用语言。Companion 目前提供 **English** 和 **Ukrainian**；文档语言不会更改应用语言。
- **Theme**：选择 **Light** 或 **Dark**。
- **UI haptic feedback**：为应用按钮、菜单和选择控件提供振动。
- **Remote control haptic feedback**：为遥控器发送的按键、长按和重复按键提供振动。

两个振动开关默认均开启，且彼此独立。关闭界面振动不会关闭遥控振动。关闭振动后仍可获得遥控视觉反馈。

偏好设置保存在本地。如果保存失败，请遵循屏幕上的重试/错误提示，并检查当前选中值；不要认为未保存的选择已持久保存。

## 备份设置与许可证 {/* #backup-settings-and-licenses */}

**Backups > System backup** 配置 Companion 的 Android 备份。有关归档文件的包含方式、估算和恢复限制，请阅读 [Android 系统备份](system-backup.md)。日常使用的 **Backups** 库从应用菜单打开，它不是系统备份设置页面。

**About > Third-party licenses** 显示随 Companion 分发的库的声明。
