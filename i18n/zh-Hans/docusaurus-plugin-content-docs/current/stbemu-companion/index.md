# StbEmu Companion {/* #stbemu-companion */}

**StbEmu Companion** 是一款 Android 应用，可通过本地网络，在手机或平板电脑上管理 StbEmu。它提供远程控制、配置文件管理、设备间传输和私有备份库功能。它不提供电视频道、播放列表或 IPTV 订阅。

:::note
要使用 StbEmu Companion 连接设备，该设备必须安装 **StbEmu 2.0.25 或更高版本**。
:::

:::note
StbEmu Companion 尚未公开发布。如需参加 Beta 测试，请发送邮件至 [support@stbemu.com](mailto:support@stbemu.com)。
:::

Companion 需要 Android 8.0 或更高版本，以及支持 Companion 的 StbEmu 版本。将两台设备连接到同一个能够互相访问的本地网络，并在 [StbEmu 的 Companion 设置](../settings/companion.md)中启用服务。配对用于授权连接；只有连接的设备和当前访问权限支持的操作才会显示。
