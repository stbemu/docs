# 关于与更新 {/* #about--updates */}

打开 **Settings > About & updates** 可查看应用信息和 **Third-party notices**，后者列出了应用所附库的相关声明。

更新设置、更新列表和更新详情仅在启用了应用内更新的构建版本中显示。本文所述 Settings 版本的 Google Play 变体禁用了这些功能。没有更新区域并不表示设置发生错误。

如果有可用更新，请在下载前查看所选更新。应用会显示下载进度，并支持取消。打开 Android 安装程序并不表示更新已安装；请在 Android 中完成安装，然后检查应用版本。
