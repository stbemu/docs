# 设置 {/* #settings */}

打开应用菜单并选择 **设置**。本指南介绍重新设计的 设置 界面；旧版应用的选项分组可能有所不同。可用类别和操作取决于您的应用版本及其配置。

## 导航 {/* #navigation */}

在电视上，使用上/下方向键选择左侧窗格中的类别，对应页面会自动加载。按右方向键进入页面，按左方向键返回类别，按 OK 激活控件，按 返回 返回上一页。也支持 Enter 和 Esc。

在手机上，从 设置 首页选择类别。使用 返回 控件或 Android 的返回操作返回。在较宽的触控布局中，类别可能显示在所选页面旁边。

## 保存更改 {/* #saving-changes */}

开关在操作后即会保存。文本和选项编辑器在您确认后保存。请等待正在进行的保存完成，再提交其他更改。离开页面不会取消已接受的保存操作。

无效输入会保留在编辑器中，并附有原因说明。如果您编辑期间设置在其他位置发生变化，请选择 **重新加载**，将草稿与刷新后的设置进行对照检查，然后再次确认。重新加载 会保留草稿供您检查，但不会自动保存。已删除的项目无法保存。

如果应用提示更改已保存但无法应用于正在运行的应用，表示存储的值已经更改。请按照提示重试或重启，不要将其视为保存失败。重新打开受密码保护的设置时，可能需要再次验证身份。
