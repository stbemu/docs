# 按键映射 {/* #key-mapping */}

打开 **设置 > 按键映射**，为实体遥控器按键分配操作。映射归属于捕获按键时使用的遥控器；短按和长按可以分别分配不同的操作。

## 添加或编辑映射 {/* #add-or-edit-a-mapping */}

1. 选择添加按键的操作，或打开已有映射。
2. 选择 **捕获按键**，然后按下实体遥控器上所需的按键。接收到按键后，捕获即结束。方向键和 OK 仍用于导航。
3. 选择要执行的操作。如果要为长按分配操作，请启用 **长按按键**。
4. 选择 **保存** 保存分配。

使用 **显示默认按键** 可在列表中显示内置映射。该选项默认关闭。

**重置** 会要求确认，然后放弃待处理的更改并重新加载该映射。它不会重置所有遥控器按键。**删除** 会在删除所选映射前要求确认。

如果按键分配已存在、其他遥控器使用了相同名称，或映射已在其他位置发生更改，请查看错误信息并修正草稿，然后再次保存。如果映射已保存但无法应用于正在运行的门户，请使用提供的 **重试** 操作刷新映射。
