### Settings
#### App Language
更改应用语言。默认情况下，如果应用支持 Android 系统语言，就会使用该语言。

#### Hide navigation bar
隐藏导航栏及其按钮（可能不适用于某些设备）。如果启用了此选项，且您使用
触摸屏，可能需要点击两次才能显示隐藏的屏幕按钮。
第一次点击会显示导航栏；这是 Android 的限制。

#### Always show overlay buttons
显示屏幕按钮。通常应保持启用此选项。在机顶盒上，如果按遥控器按键时
出现这些按钮，可以将其禁用。

#### Screen configuration
启用或禁用设备方向改变时的屏幕旋转。

#### Keyboard configuration
遥控器设置（免费版不可用）。

配置遥控器服务器，以便使用适用于 MAG 250、AuraHD 或类似设备的软件遥控器控制门户。

#### Boot options
##### Auto start on device boot

设备启动时启动应用。此功能仅在应用安装于内部存储空间时有效。
如果设备启用了锁屏（例如手机或平板电脑），应用会在您解锁后启动。

#### Stop in the background
切换到其他应用时暂停当前应用。

#### Android TV
Android TV 专用选项。

##### Enable recommendations

在 Android 主屏幕上启用推荐卡片。应用会为每个已配置的配置文件显示一张卡片，
以便您快速访问。

#### Browser settings
浏览器设置。

##### Scaling method
如果门户显示过大或过小，请选择其他浏览器缩放方式。
大多数设备无需更改此设置。例外情况是设备的显示分辨率低于
门户分辨率（通常为 1280x720）。

#### Network settings
网络设置。

##### Enable network cache
缓存网络请求，通常可以加快门户加载。如果您经常
遇到身份验证错误或其他网络问题，请禁用此选项。

##### Cache size
网络缓存的大小。默认值：20 MB。
