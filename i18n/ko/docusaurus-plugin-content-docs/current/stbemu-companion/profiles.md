# 프로필 관리 {/* #managing-profiles */}

연결된 기기를 열고 **Profiles**를 선택하세요. 목록에 프로필 이름, 식별자(UUID), 사용 가능한 포털 주소가 표시됩니다. 프로필을 선택하면 설정을 살펴볼 수 있습니다. 추가 페이지는 **Load more**, 최신 데이터는 **Refresh**를 사용하세요. 작업은 기기에서 지원하는 권한에 따라 달라집니다.

## 생성, 편집 및 삭제 {/* #create-edit-and-delete */}

- 목록에서 **Create profile**을 선택하세요. 지원되는 생성 필드에는 **Name**과 **Portal URL**이 있습니다. 변경하지 않은 필드는 StbEmu 기본값을 사용합니다.
- 프로필을 열고 **Edit profile**을 선택하여 지원되는 편집 가능 필드를 변경하세요. 편집한 필드만 변경되고 기기에 보관된 추가 설정은 유지됩니다.
- **Delete profile**을 선택하여 삭제를 준비하세요. 확인하기 전에 활성 프로필 변경이나 대체 프로필을 검토하세요.

**Review changes**를 선택하고 미리 보기와 경고를 살펴본 후 **Confirm changes** 또는 **Confirm deletion**을 선택하세요. 첫 번째 작업은 프로필을 즉시 저장하거나 삭제하지 않습니다. 호환되지 않는 변경 사항은 확정할 수 없습니다. 편집 중 프로필이나 사용 가능한 필드가 바뀌면 새로 고친 후 다시 검토하세요.

StbEmu 프로필 필드의 의미는 [STB 프로필](../settings/profiles.md)을 참고하세요.

## 프로필 복사 {/* #copy-a-profile */}

프로필을 열고 **Copy profile**을 선택하세요. 같은 기기에 복사하려면 **This device**를 선택한 다음 변경 사항을 검토하고 확정하세요. 복사본에는 새로운 식별 정보가 있으므로 이름만으로 식별하지 마세요. 성공 후 **Edit copied profile**이 제공되는 경우, 이 작업은 원본이 아닌 결과로 반환된 복사본을 엽니다.

조건을 충족하는 다른 페어링된 기기를 선택하면 해당 프로필이 선택된 상태로 [전송 가이드의 절차](transferring-profiles.md)가 열립니다.

## 작업 결과 {/* #operation-results */}

연결에 실패하거나 결과가 불확실하면 다른 변경을 시작하기 전에 기기의 **Recent operation results**를 열고 **Check result**를 사용하세요. 결과 확인에는 허가된 연결이 필요하며 원래 작업을 조회합니다. 변경 사항을 다시 보내지는 않습니다. 이는 [전송](transferring-profiles.md)과 [백업 복원](backups.md)에도 적용됩니다.

미리 보기가 만료되면 명시적으로 새 검토를 진행해야 합니다. 취소와 저장이 동시에 일어날 수 있으므로 **Cancel operation**이 변경 사항을 되돌렸다고 가정하지 말고 최종 결과를 읽으세요. **Changes saved on the device**는 데이터가 저장되었음을 확인하지만 실행 상태 새로 고침은 아직 대기 중일 수 있습니다. 결과를 확인해도 실행 상태 새로 고침은 재시도되지 않으며, 삭제된 프로필 복사본이 기록 확인으로 다시 생성되는 일은 없습니다.
