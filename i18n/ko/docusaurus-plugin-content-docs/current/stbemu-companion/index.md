# StbEmu Companion {/* #stbemu-companion */}

**StbEmu Companion**은 로컬 네트워크의 StbEmu를 휴대전화나 태블릿에서 관리하는 Android 앱입니다. 원격 제어, 프로필 관리, 기기 간 전송, 비공개 백업 라이브러리를 제공합니다. TV 채널, 재생 목록 또는 IPTV 구독은 제공하지 않습니다.

:::note
StbEmu Companion으로 연결하려는 기기에는 **StbEmu 2.0.25 이상**이 설치되어 있어야 합니다.
:::

:::note
StbEmu Companion은 아직 정식으로 공개되지 않았습니다. 베타 테스트에 참여하려면 [support@stbemu.com](mailto:support@stbemu.com)으로 이메일을 보내 주세요.
:::

Companion에는 Android 8.0 이상과 Companion을 지원하는 StbEmu 빌드가 필요합니다. 두 기기를 서로 통신할 수 있는 동일한 로컬 네트워크에 연결하고 [StbEmu의 Companion 설정](../settings/companion.md)에서 서비스를 켜세요. 페어링으로 연결 권한을 부여합니다. 연결된 기기와 현재 접근 권한에서 지원하는 작업만 표시됩니다.

![페어링된 StbEmu 기기에서 사용 가능한 작업](/img/companion/device-actions.png)

먼저 [연결 및 페어링](connecting-devices.md)을 진행한 다음 가이드를 선택하세요.

- [원격 제어](remote-control.md): 포털을 탐색하고 지원되는 재생 키를 사용합니다.
- [프로필](profiles.md): 프로필을 찾아보고 생성, 편집, 삭제, 복사합니다.
- [프로필 및 설정 전송](transferring-profiles.md): 선택한 콘텐츠를 다른 페어링된 기기로 복사합니다.
- [백업 및 복원](backups.md): StbEmu JSON 파일을 저장하고 가져오기/내보내기/공유를 수행하며 기기를 복원합니다.
- [Companion 설정](settings.md): 언어, 모양, 진동, 라이선스에 대해 알아봅니다.
- [Android 시스템 백업](system-backup.md): Companion 자체 설정, 저장된 기기, 선택적 보관 파일의 백업에 대해 알아봅니다.

문서는 앱보다 더 많은 언어로 제공됩니다. 이 가이드의 버튼과 설정 이름은 앱의 영어 레이블을 사용하며, 스크린샷은 영어 인터페이스를 보여 줍니다. 기기 이름, 버전, 사용 가능한 작업은 예시와 다를 수 있습니다.
