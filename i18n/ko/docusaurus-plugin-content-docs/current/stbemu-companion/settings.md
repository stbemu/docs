# Companion 설정 {/* #companion-settings */}

앱 메뉴를 열고 **Settings**를 선택하세요. 이 설정은 휴대전화나 태블릿의 Companion에 영향을 줍니다. 페어링된 StbEmu 설치를 변경하려면 해당 기기의 작업을 사용하세요.

![Companion 설정 범주](/img/companion/settings.png)

## 언어, 모양 및 진동 {/* #language-appearance-and-vibration */}

**Interface**를 여세요.

- **Language:** 사용 가능한 앱 언어를 선택하세요. Companion은 현재 **English**와 **Ukrainian**을 제공합니다. 문서 언어가 앱 언어를 바꾸지는 않습니다.
- **Theme:** **Light** 또는 **Dark**를 선택하세요.
- **UI haptic feedback:** 앱 버튼, 메뉴, 선택 컨트롤을 사용할 때 진동합니다.
- **Remote control haptic feedback:** 리모컨에서 전송하는 키 누르기, 길게 누르기, 반복 입력에 진동합니다.

두 진동 스위치는 기본적으로 켜져 있으며 서로 독립적입니다. UI 진동을 꺼도 리모컨 진동은 꺼지지 않습니다. 진동 없이도 리모컨의 시각적 피드백은 제공됩니다.

환경설정은 로컬에 저장됩니다. 저장에 실패하면 표시된 재시도/오류 안내를 따르고 선택된 값을 확인하세요. 저장하지 못한 선택이 유지되었다고 가정하지 마세요.

## 백업 설정 및 라이선스 {/* #backup-settings-and-licenses */}

**Backups > System backup**은 Companion의 Android 백업을 구성합니다. 보관 파일 포함, 예상 크기, 복원 제한은 [Android 시스템 백업](system-backup.md)을 읽어 보세요. 실제 사용하는 **Backups** 라이브러리는 앱 메뉴에서 열며 시스템 백업 설정 페이지와는 다릅니다.

**About > Third-party licenses**는 Companion과 함께 배포되는 라이브러리의 고지 사항을 표시합니다.
