# StbEmu {/* #stbemu */}

**StbEmu**는 셋톱박스(STB)용으로 설계된 웹 포털을
휴대전화, 태블릿, TV 박스 등의 Android 기기에서 불러오는 Android 8.0 이상용 앱입니다.
현재 우크라이나 기업 Infomir에서 제조하는 여러 STB 모델의 에뮬레이션을 지원하며,
MAG 250, MAG 270, MAG 322 등이 포함됩니다. [에뮬레이션 지원 기기 목록](/supported-devices)을 확인하세요.

:::note
**StbEmu**는 중립적인 기술 도구이자 하드웨어 에뮬레이터입니다. 미디어,
재생목록, 스트리밍 포털을 제공하거나 호스팅하거나 색인하지 않습니다. 사용자가 합법적으로 확보한 콘텐츠에 접근하도록 설계된 앱입니다.
개발자는 제3자 콘텐츠 제공업체와 제휴 관계가 없습니다.
:::

앱에는 무료 버전과 유료 버전이 있습니다. [무료 버전](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free)에는 광고가 표시되며, [Pro 버전](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro)에는 광고가 없습니다.
이것이 두 버전의 가장 큰 차이점입니다.
