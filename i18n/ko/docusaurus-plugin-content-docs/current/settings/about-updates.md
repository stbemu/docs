# About & updates {/* #about--updates */}

**Settings > About & updates**를 열면 앱 정보와 앱에 포함된 라이브러리의 고지 사항을 나열하는 **Third-party notices**를 확인할 수 있습니다.

업데이트 설정, 업데이트 목록, 업데이트 상세 정보는 앱 내 업데이트가 활성화된 빌드에만 표시됩니다. 여기서 설명하는 Settings 버전의 Google Play 배포판에서는 이 기능이 비활성화되어 있습니다. 업데이트 항목이 없다고 해서 설정에 오류가 있는 것은 아닙니다.

업데이트를 사용할 수 있는 경우 다운로드 전에 선택한 업데이트를 검토하세요. 앱은 다운로드 진행 상황을 표시하며 취소를 지원합니다. Android 설치 프로그램이 열렸다고 해서 업데이트가 설치된 것은 아닙니다. Android에서 설치를 완료한 뒤 앱 버전을 확인하세요.
