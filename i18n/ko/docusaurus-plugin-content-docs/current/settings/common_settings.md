# 앱 설정 {/* #application-settings */}

앱 전체에 적용되는 옵션은 [설정](/settings)의 다음 카테고리에 나뉘어 있습니다. 프로필별 옵션은 [프로필](/settings/profiles)에 있습니다.

## 모양 및 조작 {/* #appearance--controls */}

| 옵션 | 용도 |
|--------|---------|
| 앱 언어 | 지원되는 앱 언어 또는 Android 시스템 기본 언어를 사용합니다. |
| 내비게이션 바 숨기기 | 지원되는 환경에서 Android 탐색 버튼을 숨깁니다. 터치스크린에서는 첫 번째 터치로 탐색 버튼이 나타나고 앱 컨트롤을 표시하려면 한 번 더 터치해야 할 수 있습니다. |
| 오버레이 버튼 항상 표시 | 화면 컨트롤을 표시합니다. TV 박스에서 리모컨 키를 누를 때 불필요한 버튼이 나타나면 끌 수 있습니다. |
| 조작 버튼 숨기기 지연 시간…(ms) | 화면 컨트롤이 사라질 때까지의 시간을 밀리초로 설정합니다. 기본값: 5000(5초). |
| 화면 방향 | 앱의 화면 방향 동작을 선택합니다. |
| 키보드 종류 | 앱에서 사용할 키보드를 선택합니다. |
| 소프트웨어 키보드 입력 방식 | 소프트웨어 키보드의 입력 처리 방식을 선택합니다. |

## 재생 및 동작 {/* #playback--behavior */}

| 옵션 | 용도 |
|--------|---------|
| 백그라운드에서 중지 | 다른 앱으로 전환할 때 재생을 일시 정지합니다. 자동 화면 속 화면이 켜져 있는 동안에는 이 컨트롤을 사용할 수 없습니다. |
| 최소화 시 PiP 모드로 전환 | Android와 기기가 지원하는 경우 앱을 나갈 때 화면 속 화면을 사용합니다. |
| 기기 부팅 시 자동 시작 | 기기 부팅 후 앱을 시작합니다. 앱이 내부 저장소에 설치되어 있어야 하며, 잠금 화면이 있으면 잠금을 해제할 때까지 시작이 지연될 수 있습니다. |
| 항상 시스템 음량 사용 | 별도의 앱 음량 대신 시스템 음량을 사용합니다. |
| 추천 사용 | 지원되는 Android TV 홈 화면에 프로필 추천 카드를 표시합니다. |
| 재생 시작 시 미디어 세션 생성 | Android 미디어 세션 연동을 활성화합니다. |

## 네트워크 {/* #network */}

**크기 조절 방식**는 포털이 너무 크거나 작게 표시될 때 브라우저 배율 조정 방식을 변경합니다. 대부분의 기기는 기본값을 유지해도 되지만, 저해상도 화면에서는 다른 방식이 필요할 수 있습니다.

**네트워크 캐시 사용**는 네트워크 요청을 캐시하여 포털 로딩을 개선합니다. 인증 오류나 다른 네트워크 문제가 반복되면 끄세요.

**캐시 크기(KByte)**는 KB 단위로 입력합니다. 기본값은 **20480 KB (20 MB)**입니다. 캐시 크기 변경을 적용하기 위해 재시작을 요청하면 앱을 다시 시작하세요.

## 보안 {/* #security */}

설정의 비밀번호 보호를 켜고 비밀번호를 설정하세요. 보호된 설정에는 인증이 필요합니다. 화면이 다시 생성되면 비밀번호 편집기에 입력한 비밀번호가 유지되지 않으므로 필요하면 다시 입력하세요.

## 기존 리모컨 {/* #legacy-remote */}

이 카테고리는 MAG 250, AuraHD 등의 기존 리모컨 앱용 소프트웨어 리모컨 서비스를 설정합니다. [Companion](/settings/companion) 및 [물리 키 매핑](/settings/key-maps)과는 별개입니다.

서비스를 켜고 기기 이름과 비밀번호를 설정하세요. 기기 이름과 비밀번호는 각각 최대 32자까지 입력할 수 있습니다. 이 카테고리는 해당 기능이 활성화된 앱 에디션에서만 사용할 수 있습니다.
