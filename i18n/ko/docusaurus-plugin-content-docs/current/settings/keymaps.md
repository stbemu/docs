# Key mapping {/* #key-mapping */}

**Settings > Key mapping**를 열면 실제 리모컨 키에 동작을 할당할 수 있습니다. 매핑은 키를 캡처한 리모컨에 연결되며, 짧게 누르기와 길게 누르기에 서로 다른 동작을 할당할 수 있습니다.

## 매핑 추가 또는 편집 {/* #add-or-edit-a-mapping */}

1. 키 추가 작업을 선택하거나 기존 매핑을 여세요.
2. **Capture a key**를 선택하고 실제 리모컨에서 원하는 키를 누르세요. 키를 수신하면 캡처가 종료됩니다. 방향 키와 OK는 계속 탐색에 사용됩니다.
3. 실행할 동작을 선택하세요. 길게 누르기에 할당하려면 **Long key press**를 켜세요.
4. **Save**를 선택하여 할당을 저장하세요.

**Show default keys**를 사용하면 기본 매핑도 목록에 표시됩니다. 기본적으로 꺼져 있습니다.

**Reset**은 확인을 요청한 뒤 대기 중인 변경 사항을 버리고 해당 매핑을 다시 로드합니다. 모든 리모컨 키를 초기화하지는 않습니다. **Delete**는 선택한 매핑을 삭제하기 전에 확인을 요청합니다.

키 할당이 이미 존재하거나 다른 리모컨이 같은 이름을 사용하거나 매핑이 다른 곳에서 변경되었다면 오류를 확인하고 초안을 수정한 뒤 다시 저장하세요. 매핑이 저장되었지만 실행 중인 포털에 적용되지 않으면 제공되는 **Retry** 동작으로 새로고침하세요.
