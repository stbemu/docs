# 다운로드 {/* #download */}

![StbEmu Free](/img/stbemu_free_icon.png)

StbEmu는 무료인 Free 버전과 유료인 Pro 버전으로 제공됩니다.

| 무료 버전 | Pro(유료) 버전 |
|--------------|---------------------------------------------------|
| 광고 표시 | 광고 없음 |
| | MAG 250용 소프트웨어 리모컨 지원 * |
| [Google Play에서 다운로드](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Google Play에서 다운로드](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Google Play의 소프트웨어 리모컨을 사용하기 전에 MAG 250을 지원하는지 확인하세요.
