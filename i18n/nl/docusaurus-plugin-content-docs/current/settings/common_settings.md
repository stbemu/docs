# Appinstellingen {/* #application-settings */}

Appbrede opties zijn in [Settings](/settings) onderverdeeld in de volgende categorieën. Profielspecifieke opties staan onder [Profiles](/settings/profiles).

## Appearance & controls

| Optie | Functie |
|--------|---------|
| App language | Gebruik een ondersteunde apptaal of de standaardtaal van Android. |
| Hide navigation bar | Verberg de navigatieknoppen van Android waar dit wordt ondersteund. Op een aanraakscherm kan de eerste tik de navigatie tonen en kan een tweede tik nodig zijn om de appbediening te tonen. |
| Always show overlay buttons | Toon bedieningselementen op het scherm. U kunt dit uitschakelen op een tv-box als het indrukken van toetsen op de afstandsbediening ongewenste knoppen laat verschijnen. |
| Hide controls after… (ms) | Stel in na hoeveel milliseconden de schermbediening wordt verborgen. Standaard: 5000 (5 seconden). |
| Screen orientation | Kies hoe de app omgaat met de schermoriëntatie. |
| Keyboard type | Kies het toetsenbord dat de app gebruikt. |
| Software keyboard input method | Kies hoe invoer via het softwaretoetsenbord wordt verwerkt. |

## Playback & behavior

| Optie | Functie |
|--------|---------|
| Pause media in background | Pauzeer het afspelen wanneer u naar een andere app overschakelt. Deze optie is niet beschikbaar als automatisch beeld-in-beeld is ingeschakeld. |
| Picture-in-picture | Gebruik beeld-in-beeld wanneer u de app verlaat, indien Android en het apparaat dit ondersteunen. |
| Auto start on device boot | Start de app nadat het apparaat is opgestart. De app moet in het interne geheugen zijn geïnstalleerd; een vergrendelscherm kan het starten uitstellen totdat het apparaat is ontgrendeld. |
| Always use system volume level | Gebruik het systeemvolume in plaats van een afzonderlijk appvolume. |
| Enable recommendations | Toon aanbevelingskaarten voor profielen op ondersteunde startschermen van Android TV. |
| Media sessions | Schakel integratie met Android-mediasessies in. |

## Network

**Scaling method** wijzigt de schaling van de browser als een portaal te groot of te klein wordt weergegeven. Op de meeste apparaten kunt u de standaardwaarde behouden; voor een scherm met een lage resolutie kan een andere methode nodig zijn.

**Enable network cache** slaat netwerkverzoeken op in een cache zodat portalen beter laden. Schakel dit uit bij herhaalde authenticatiefouten of andere netwerkproblemen.

**Cache size** wordt opgegeven in KB. De standaardwaarde is **20480 KB (20 MB)**. Start de app opnieuw wanneer daarom wordt gevraagd om een gewijzigde cachegrootte toe te passen.

## Security

Schakel wachtwoordbeveiliging voor de instellingen in en stel het wachtwoord in. Beveiligde instellingen vereisen authenticatie. De wachtwoordeditor bewaart het wachtwoord niet wanneer het scherm opnieuw wordt gemaakt; voer het indien nodig opnieuw in.

## Legacy remote

In deze categorie configureert u de oudere softwareafstandsbedieningsservice voor MAG 250, AuraHD en vergelijkbare afstandsbedieningsapps. Deze staat los van [Companion](/settings/companion) en [fysieke toetskoppelingen](/settings/key-maps).

Schakel de service in en configureer de apparaatnaam en het wachtwoord. De apparaatnaam en het wachtwoord mogen elk maximaal 32 tekens bevatten. Deze categorie is alleen beschikbaar in appedities waarin deze is ingeschakeld.
