# Key mapping

Öppna **Settings > Key mapping** för att tilldela åtgärder till fysiska fjärrkontrollsknappar. Mappningarna hör till fjärrkontrollen som de registrerades från; korta och långa tryck kan ha separata tilldelningar.

## Lägga till eller redigera en mappning {/* #add-or-edit-a-mapping */}

1. Välj åtgärden för att lägga till en knapp, eller öppna en befintlig mappning.
2. Välj **Capture a key** och tryck på önskad knapp på den fysiska fjärrkontrollen. Registreringen avslutas när knapptryckningen har tagits emot. Pilknapparna och OK förblir navigeringskontroller.
3. Välj åtgärden som ska utföras. Aktivera **Long key press** om tilldelningen gäller ett långt tryck.
4. Välj **Save** för att spara tilldelningen.

Använd **Show default keys** för att ta med de inbyggda mappningarna i listan. Alternativet är avstängt som standard.

**Reset** kräver bekräftelse, slänger de väntande ändringarna och läser in mappningen igen. Alla fjärrkontrollsknappar återställs inte. **Delete** kräver bekräftelse innan den valda mappningen tas bort.

Om en knapptilldelning redan finns, en annan fjärrkontroll använder samma namn eller mappningen har ändrats någon annanstans ska du granska felet och rätta utkastet innan du sparar igen. Om en mappning sparas men inte kan tillämpas i den körande portalen använder du den erbjudna åtgärden **Retry** för att uppdatera den.
