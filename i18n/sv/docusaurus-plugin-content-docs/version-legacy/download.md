# Ladda ned {/* #download */}

![StbEmu Free](/img/stbemu_free_icon.png)

StbEmu finns i två versioner: Free (kostnadsfri) och Pro (betald).

| Kostnadsfri version | Pro-version (betald) |
|--------------|---------------------------------------------------|
| Visar annonser | Annonsfri |
| | Stöder programvarubaserade fjärrkontroller för MAG 250 * |
| [Ladda ned från Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Ladda ned från Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Kontrollera att en programvarubaserad fjärrkontroll från Google Play stöder MAG 250 innan du använder den.
