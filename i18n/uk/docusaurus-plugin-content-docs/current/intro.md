# StbEmu

**StbEmu** — це застосунок для Android 8.0+, який дає змогу завантажувати вебпортали,
призначені для телевізійних приставок (STB), на пристроях з Android: телефонах, планшетах і ТВ-приставках.
Наразі застосунок підтримує емуляцію кількох моделей приставок української компанії Infomir,
зокрема MAG 250, MAG 270 і MAG 322. Дивіться [список емульованих пристроїв](/supported-devices).

:::note
**StbEmu** — це нейтральний технологічний інструмент та емулятор обладнання. Він не надає, не розміщує
й не індексує медіаконтент, списки відтворення чи потокові портали. Застосунок призначений для доступу
користувачів до власного законно отриманого контенту. Розробник не пов'язаний зі сторонніми постачальниками контенту.
:::

Є дві версії застосунку: безкоштовна та платна. [Безкоштовна версія](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) показує рекламу, а [версія Pro](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) — ні.
Це основна відмінність між ними.
