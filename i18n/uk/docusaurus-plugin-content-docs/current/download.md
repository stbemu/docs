# Завантаження

![Безкоштовна версія StbEmu](/img/stbemu_free_icon.png)

Є дві версії StbEmu: безкоштовна та Pro (платна).

| Безкоштовна версія | Версія Pro (платна) |
|-------------------|--------------------|
| Показує рекламу | Без реклами |
| | Підтримує програмні пульти дистанційного керування для MAG 250 * |
| [Завантажити з Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Завантажити з Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Перш ніж використовувати програмний пульт дистанційного керування з Google Play, перевірте, чи підтримує він MAG 250.
