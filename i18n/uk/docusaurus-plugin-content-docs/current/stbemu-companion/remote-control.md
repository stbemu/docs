# Пульт керування {/* #remote-control */}

Відкрийте підключений пристрій і виберіть **Remote control**. Дія показується лише тоді, коли пристрій підтримує авторизоване дистанційне введення. Ці елементи керують StbEmu та його порталом; вони відокремлені від старішої служби пульта MAG, описаної в розділі [Застарілий пульт](../settings/common_settings.md#legacy-remote).

![Прокручуваний пульт із кольоровими клавішами та навігаційними кнопками](/img/companion/remote-control.png)

Торкніться кнопки для звичайної дії. Утримуйте її для довгої дії або повторних натискань, якщо це підтримується. Відпустіть, щоб припинити утримання. Доступні кнопки та поведінка утримання залежать від пристрою; не кожна клавіша підтримує повторення. Прокрутіть до решти елементів, зокрема клавіш відтворення, гучності, каналів і цифр.

Одночасно активний лише один жест клавіші. Вихід зі сторінки пульта чи застосунку, втрата з’єднання або авторизації скасовують активне введення. Після повторного підключення дистанційне введення не відтворюється: підключіться та свідомо натисніть знову.

## Пояснення відгуків {/* #read-the-feedback */}

Локальний відгук на натискання чи утримання означає, що Companion розпізнав жест. **Awaiting device confirmation** означає, що результат ще очікується. **Device accepted input** підтверджує прийняття введення StbEmu, але не обов’язково завершення дії каналу чи порталу.

Для **Input target unavailable** перевірте з’єднання. Для **Authorization expired. Pair again.** покажіть новий код у StbEmu та введіть його в Companion. Якщо дія більше не підтримується, припиніть її використовувати та перевірте доступні елементи керування. Підключіться повторно, якщо введення залишається недоступним.

Вібрацію пульта можна змінити в **Settings > Interface > Remote control haptic feedback**. Вона незалежна від **UI haptic feedback**; візуальний відгук доступний і з вимкненою вібрацією.
