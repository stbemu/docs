# Налаштування Companion {/* #companion-settings */}

Відкрийте меню застосунку та виберіть **Settings**. Ці налаштування впливають на Companion на телефоні чи планшеті. Для зміни сполученого встановлення StbEmu використовуйте дії його пристрою.

![Категорії налаштувань Companion](/img/companion/settings.png)

## Мова, оформлення та вібрація {/* #language-appearance-and-vibration */}

Відкрийте **Interface**:

- **Language:** виберіть доступну мову застосунку. Наразі Companion пропонує English та Ukrainian; мова документації не змінює мову застосунку.
- **Theme:** виберіть **Light** або **Dark**.
- **UI haptic feedback:** вібрація для кнопок, меню та елементів вибору застосунку.
- **Remote control haptic feedback:** вібрація для надісланих натискань, довгих натискань і повторів на пульті.

Обидва перемикачі вібрації типово ввімкнені та незалежні. Вимкнення вібрації інтерфейсу не вимикає вібрацію пульта. Візуальний відгук пульта доступний без вібрації.

Параметри зберігаються локально. Якщо збереження не вдалося, дотримуйтесь показаних вказівок щодо повтору чи помилки та перевірте вибране значення; не вважайте, що незбережений вибір зберігся.

## Налаштування резервного копіювання та ліцензії {/* #backup-settings-and-licenses */}

**Backups > System backup** налаштовує резервне копіювання Companion засобами Android. У розділі [Системне резервне копіювання Android](system-backup.md) описано включення архівів, оцінки та обмеження відновлення. Робоча бібліотека **Backups** відкривається з меню застосунку; це не сторінка налаштувань системного резервного копіювання.

**About > Third-party licenses** показує повідомлення щодо бібліотек, які розповсюджуються з Companion.
