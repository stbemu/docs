# Профілі STB

**Профіль STB** — це набір параметрів для емуляції телевізійної приставки в застосунку. Під час першого запуску
застосунок створює один профіль. Ви завжди можете змінити його або додати інший, щоб завантажувати різні портали
на одному пристрої. Відкрийте **Налаштування > Профілі** та виберіть **Додати профіль** або відкрийте наявний профіль.
Огляд групує параметри в розділах **Підключення**, **Відтворення та пристрій** і **Керування профілем**.
Доступні дії залежать від версії застосунку та обмежень профілю. Активний профіль видалити неможливо:
спочатку перейдіть на інший профіль. Видалення потребує підтвердження.

Зміни тексту й вибір зі списку потребують підтвердження; перемикачі зберігаються одразу.
Перевірку даних, конфлікти та застосування збережених змін описано в розділі [Збереження змін](/settings#збереження-змін).

StbEmu не надає, не розміщує й не індексує медіаконтент або списки відтворення IPTV.
Користувачі повинні мати законне право на доступ до контенту через емулятор.

### Ім'я профілю {/* #profile-name */}
Назва профілю. Може бути будь-яким непорожнім рядком.

### Налаштування порталу {/* #portal-settings */}
Набір параметрів для конкретного порталу.

##### URL адреса порталу {/* #portal-url */}
Введіть абсолютний URL **http://** або **https://**. Підтримуються вузли локальної мережі, localhost, IPv6 та міжнародні доменні імена. Мережеві URL не повинні містити пробілів.
Для внутрішнього порталу також підтримуються абсолютний шлях до файлів або абсолютний URL **file://**. Оновлений редактор не приймає FTP-адреси.

##### Мова порталу {/* #portal-language */}
Мова порталу за замовчуванням. Потрібно вказати дволітерний код мови за стандартом [ISO 639-1](https://en.wikipedia.org/wiki/ISO_639-1).

#### Налаштування HTTP-проксі {/* #http-proxy-settings */}
Параметри HTTP-проксі.

##### Використовувати HTTP-проксі {/* #use-http-proxy */}
Увімкніть, якщо хочете використовувати HTTP-проксі.

##### Адреса сервера {/* #proxy-host-name */}
Адреса хоста проксі задається окремо від порту; за замовчуванням — 127.0.0.1.
##### Порт {/* #proxy-port */}
За замовчуванням: 3128. Хост і порт доступні для редагування лише тоді, коли використання HTTP-проксі ввімкнено.

##### Це внутрішній портал {/* #portal-is-internal */}
Увімкніть для внутрішнього порталу MAG. Локальний URL автоматично вмикає цей параметр і блокує перемикач. Перехід на мережевий URL скидає автоматичне позначення внутрішнього порталу.

##### URL внутрішнього порталу {/* #internal-portal-url */}
Введіть локальний шлях або файловий URL у поле **URL адреса порталу**; окремого редактора внутрішньої адреси немає.

Щоб установити портал, відкрийте **Налаштування > Профілі > потрібний профіль > Налаштування порталу**, виберіть **Установити внутрішній портал…** та архів. Дочекайтеся розпакування
й підтвердьте запропонований локальний URL. Установлення файлів і прийняття адреси — окремі кроки.
Для видалення встановленого внутрішнього порталу виберіть **Видалити внутрішній портал…** у розділі **Налаштування порталу**.

### Налаштування приставки {/* #stb-configuration */}
Основні параметри емуляції.

#### Тип приставки {/* #stb-model */}
Модель приставки, яку потрібно емулювати.

#### Прошивка {/* #firmware */}
**Прошивка**, яку потрібно емулювати (справжня прошивка не встановлюється). Деякі портали можуть вимагати
певну прошивку. У такому разі виберіть її зі списку, якщо вона доступна.
Для більшості підтримуваних моделей STB доступна лише прошивка **Generic**, яка зазвичай відповідає найновішій версії.

Доступні прошивки:

* Generic — зазвичай найновіша доступна прошивка.
* Custom (лише для MAG 250) — прошивка з можливістю налаштування. Використовуйте її, якщо потрібно змінити окремі параметри прошивки.

Більшості користувачів слід використовувати прошивку **Generic**, вибрану за замовчуванням.

#### Налаштування прошивки {/* #firmware-settings */}
Цей параметр доступний лише для прошивки **Custom** (наразі лише для MAG 250).
Тут можна налаштувати версії рушія програвача, JavaScript API й STB API, версію, опис і дату образу.
Для власного рядка User Agent спочатку ввімкніть використання власного User Agent.

#### User Agent {/* #user-agent */}
Рядок User Agent для веббраузера застосунку.

#### Роздільна здатність екрану {/* #screen-resolution */}
Роздільна здатність, яку потрібно емулювати (вона не змінює фактичну роздільну здатність екрана).
Виберіть значення, яке підтримує ваш портал, зазвичай **1280x720**.

#### MAC-адреса {/* #mac-address */}
MAC-адреса емульованого пристрою. Якщо у вас є справжній пристрій MAG 250, можна використати його MAC-адресу
або будь-які 12 випадкових шістнадцяткових цифр (0–9, A–F), згрупованих попарно й розділених двокрапками. [^wrong_mac]

Більшість порталів вимагають, щоб MAC-адреса починалася з 00:1A:79.

[^wrong_mac]: На деяких пристроях, які мають лише з'єднання Wi-Fi, автоматично згенерована MAC-адреса може мати значення
    **00:1A:79:00:00:00**. Це означає, що застосунок не зміг правильно визначити її через обмеження Android.
    У такому разі замініть частину **00:00:00** випадковими шістнадцятковими цифрами, зберігши двокрапки між парами.

#### Серійний номер {/* #serial-number */}
Серійний номер емульованого пристрою. Більшість порталів його не перевіряють, тому зазвичай підійде довільний текстовий рядок.

#### ID пристрою {/* #device-id */}
Параметри ідентифікатора пристрою.

##### Використовувати ID пристрою на основі MAC-адреси {/* #use-mac-based-device-id */}
Вмикає генерацію ідентифікатора на основі MAC-адреси пристрою. Після ввімкнення або вимкнення цього параметра
натисніть **Скинути ID пристрою…**, щоб згенерувати ідентифікатор заново.

##### Надсилати ID пристрою {/* #send-device-id */}
Надсилає ідентифікатор пристрою на запит порталу. Якщо вимкнено, надсилається порожній рядок.

##### Зерно випадковості ідентифікатора пристрою {/* #device-id-random-seed */}
Початкове значення для генерації ідентифікатора пристрою. Використовуйте однакове значення на всіх пристроях
з однаковими URL порталу та MAC-адресою. Підтвердження нового значення автоматично перегенеровує ідентифікатори.
Не натискайте скидання, якщо хочете зберегти це значення: скидання його очищує.

##### ID пристрою {/* #device-id-value */}
Ідентифікатор пристрою. Можна використати згенероване значення або вказати власне.

##### Власні ідентифікатор пристрою 2 та підпис {/* #custom-device-id-2-and-signature */}
Увімкніть, щоб мати змогу змінювати ідентифікатор пристрою 2 та підпис.

##### Ідентифікатор пристрою 2 {/* #device-id-2 */}
##### Підпис {/* #signature */}
##### Скинути ID пристрою… {/* #reset-device-id-to-default-value */}
Після підтвердження очищує початкове значення та заново генерує **ID пристрою**, **Ідентифікатор пристрою 2** та підпис із поточних даних профілю. Інші параметри профілю зберігаються.

Ручне редагування поля **ID пристрою** доступне лише тоді, коли ввімкнено його надсилання та вимкнено генерацію на основі MAC-адреси.
Для редагування полів **Ідентифікатор пристрою 2** й **Підпис** також потрібно ввімкнути їхні власні значення.
Автоматично згенеровані значення залишаються доступними для читання.

#### Налаштування емуляції апаратної частини {/* #hardware-settings */}
##### Виробник {/* #vendor */}
##### Апаратна версія {/* #hardware-version */}

Параметри пристрою також містять сумісність із Ministra та перенаправлення браузера. Змінюйте їх за потреби вашого порталу.

### Налаштування медіапрогравача {/* #media-player-settings */}

Налаштування медіапрогравача для конкретного профілю.

#### Відеопрогравач {/* #media-player */}
Виберіть медіапрогравач за замовчуванням для профілю.

Список містить автоматичний вибір, Exo, внутрішній програвач Android і зовнішній програвач,
а також додаткові програвачі, доступні у вашій збірці. Вибирайте з варіантів, показаних у застосунку.
Підтримка кодеків внутрішнім програвачем залежить від Android; зовнішні програвачі відкривають потоки в іншому застосунку.

#### Налаштування UDPXY {/* #udpxy-settings */}
##### Ввімкнути підтримку UDPXY {/* #enable-udxpy-support */}
Перед увімкненням UDPXY введіть коректний HTTP/HTTPS URL сервера.
##### URL сервера UDPXY {/* #udpxy-server-url */}
URL можна ввести, поки UDPXY вимкнено. Порожнє значення дозволене лише у вимкненому стані; непорожній URL має бути коректною HTTP/HTTPS-адресою.
##### Замінювати протокол потоку {/* #overwrite-stream-protocol */}
Виберіть заміну протоколу потоку, коли UDPXY ввімкнено.
### Розширені налаштування {/* #advanced-settings */}
Параметри сумісності профілю охоплюють CSS-патчі, виявлення емулятора, виправлення кольору фону, локальних посилань і AJAX,
а також події повернення та кнопок для зовнішніх програвачів. Події Назад, Exit і OK залежать від увімкнення події повернення до списку каналів.
Змінюйте їх лише тоді, коли цього потребує портал або зовнішній програвач.
