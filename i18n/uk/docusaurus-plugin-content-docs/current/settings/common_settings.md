# Налаштування застосунку

Загальні параметри згруповано в наведених нижче категоріях [Налаштувань](/settings). Параметри окремого профілю розташовані в розділі [Профілі](/settings/profiles).

## Вигляд і керування {/* #appearance--controls */}

| Параметр | Призначення |
|----------|-------------|
| Мова застосунку | Вибір підтримуваної мови або системної мови Android. |
| Приховувати панель навігації | Приховування кнопок навігації Android, якщо пристрій це підтримує. На сенсорному екрані перший дотик може показати навігацію, а другий — елементи керування застосунку. |
| Завжди показувати екранні кнопки | Відображення екранних елементів керування. На ТВ-приставці можна вимкнути, якщо натискання пульта викликають небажані кнопки. |
| Приховувати елементи керування через… (мс) | Час показу екранних кнопок у мілісекундах. За замовчуванням: 5000 (5 секунд). |
| Орієнтація екрана | Вибір поведінки орієнтації застосунку. |
| Тип клавіатури | Вибір клавіатури застосунку. |
| Метод введення екранної клавіатури | Вибір способу обробки введення екранною клавіатурою. |

## Відтворення та поведінка {/* #playback--behavior */}

| Параметр | Призначення |
|----------|-------------|
| Призупиняти відтворення у фоні | Призупинення під час переходу до іншого застосунку. Недоступне, коли ввімкнено автоматичну картинку в картинці. |
| Картинка в картинці | Перехід до картинки в картинці під час виходу із застосунку, якщо Android і пристрій це підтримують. |
| Автоматичний запуск під час увімкнення пристрою | Запуск після ввімкнення пристрою. Застосунок має бути у внутрішній пам'яті; екран блокування може затримати запуск до розблокування. |
| Завжди використовувати системний рівень гучності | Використання системної гучності замість окремої гучності застосунку. |
| Увімкнути рекомендації | Картки профілів на підтримуваних головних екранах Android TV. |
| Медіасесії | Інтеграція з медіасесіями Android. |

## Мережа {/* #network */}

**Спосіб масштабування** змінює масштаб браузера, якщо портал виглядає завеликим або замалим. Більшість пристроїв можуть використовувати значення за замовчуванням; для екрана з низькою роздільною здатністю може знадобитися інший спосіб.

**Увімкнути мережевий кеш** вмикає кешування мережевих запитів для швидшого завантаження порталу. Вимкніть його, якщо часто виникають помилки автентифікації чи інші проблеми з мережею.

**Розмір кешу** задається в КБ. За замовчуванням: **20480 КБ (20 МБ)**. Якщо застосунок просить перезапуск для застосування нового розміру кешу, перезапустіть його.

## Безпека {/* #security */}

Увімкніть захист налаштувань паролем і задайте пароль. Захищені налаштування потребують автентифікації. Редактор пароля не зберігає секрет під час повторного створення екрана; за потреби введіть його знову.

## Старий пульт {/* #legacy-remote */}

Ця категорія налаштовує стару службу програмного пульта для MAG 250, AuraHD та подібних застосунків. Вона відокремлена від [Companion](/settings/companion) та [призначення фізичних кнопок](/settings/key-maps).

Увімкніть службу та задайте назву пристрою й пароль. Назва та пароль можуть містити до 32 символів кожен. Категорія доступна лише у версіях застосунку, де її ввімкнено.
