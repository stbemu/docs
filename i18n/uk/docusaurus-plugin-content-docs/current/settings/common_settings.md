# Налаштування застосунку

Загальні параметри згруповано в наведених нижче категоріях [Налаштувань](/settings). Параметри окремого профілю розташовані в розділі [Профілі](/settings/profiles).

## Вигляд і керування {/* #appearance--controls */}

| Параметр | Призначення |
|----------|-------------|
| Мова програми | Вибір підтримуваної мови або системної мови Android. |
| Сховати панель навігації | Приховування кнопок навігації Android, якщо пристрій це підтримує. На сенсорному екрані перший дотик може показати навігацію, а другий — елементи керування застосунку. |
| Завжди показувати екранні кнопки | Відображення екранних елементів керування. На ТВ-приставці можна вимкнути, якщо натискання пульта викликають небажані кнопки. |
| Час показу елементів керування (мс) | Час показу екранних кнопок у мілісекундах. За замовчуванням: 5000 (5 секунд). |
| Орієнтація екрану | Вибір поведінки орієнтації застосунку. |
| Тип клавіатури | Вибір клавіатури застосунку. |
| Метод клавіатурного вводу | Вибір способу обробки введення екранною клавіатурою. |

## Відтворення та поведінка {/* #playback--behavior */}

| Параметр | Призначення |
|----------|-------------|
| Зупиняти у фоні | Призупинення під час переходу до іншого застосунку. Недоступне, коли ввімкнено автоматичну картинку в картинці. |
| Перемикатися в режим PiP при згортанні додатку | Перехід до картинки в картинці під час виходу із застосунку, якщо Android і пристрій це підтримують. |
| Автозавантаження програми при ввімкненні пристрою | Запуск після ввімкнення пристрою. Застосунок має бути у внутрішній пам'яті; екран блокування може затримати запуск до розблокування. |
| Завжди використовувати системний рівень звуку | Використання системної гучності замість окремої гучності застосунку. |
| Ввімкнути рекомендації | Картки профілів на підтримуваних головних екранах Android TV. |
| Створювати медіасесію коли починається відтворювання | Інтеграція з медіасесіями Android. |

## Мережа {/* #network */}

**Метод масштабування** змінює масштаб браузера, якщо портал виглядає завеликим або замалим. Більшість пристроїв можуть використовувати значення за замовчуванням; для екрана з низькою роздільною здатністю може знадобитися інший спосіб.

**Ввімкнути мережевий кеш** вмикає кешування мережевих запитів для швидшого завантаження порталу. Вимкніть його, якщо часто виникають помилки автентифікації чи інші проблеми з мережею.

**Розмір кешу (в кілобайтах)** задається в КБ. За замовчуванням: **20480 КБ (20 МБ)**. Якщо застосунок просить перезапуск для застосування нового розміру кешу, перезапустіть його.

## Безпека {/* #security */}

Увімкніть перемикач **Захист паролем увімкнено** та введіть пароль у полі **Пароль для доступу до налаштувань**. Захищені налаштування потребують автентифікації. Редактор пароля не зберігає секрет під час повторного створення екрана; за потреби введіть його знову.

## Старий пульт {/* #legacy-remote */}

Ця категорія налаштовує стару службу програмного пульта для MAG 250, AuraHD та подібних застосунків. Вона відокремлена від [Companion](/settings/companion) та [призначення фізичних кнопок](/settings/key-maps).

Увімкніть перемикач **Увімкнути службу дистанційного керування** та заповніть поля **Назва пристрою** й **Пароль**. Назва та пароль можуть містити до 32 символів кожен. Категорія доступна лише у версіях застосунку, де її ввімкнено.
