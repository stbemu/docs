# Key mapping

افتح <span dir="ltr"><bdi dir="ltr">**Settings > Key mapping**</bdi></span> لتعيين إجراءات لأزرار جهاز التحكم الفعلي. ترتبط التعيينات بجهاز التحكم الذي التُقطت منه؛ ويمكن تعيين إجراء مستقل لكل من الضغط القصير والطويل.

## إضافة تعيين أو تعديله {/* #add-or-edit-a-mapping */}

1. اختر إجراء إضافة زر، أو افتح تعيينًا موجودًا.
2. اختر <bdi dir="ltr">**Capture a key**</bdi> واضغط الزر المطلوب على جهاز التحكم الفعلي. ينتهي الالتقاط بعد استلام الزر. تظل أزرار الأسهم وOK مخصصة للتنقل.
3. اختر الإجراء المطلوب تنفيذه. فعّل <bdi dir="ltr">**Long key press**</bdi> إذا كان هذا التعيين للضغط الطويل.
4. اختر <bdi dir="ltr">**Save**</bdi> لحفظ التعيين.

استخدم <bdi dir="ltr">**Show default keys**</bdi> لإدراج التعيينات المضمّنة في القائمة. هذا الخيار معطل افتراضيًا.

يطلب <bdi dir="ltr">**Reset**</bdi> التأكيد، ويتجاهل التغييرات المعلقة، ويعيد تحميل التعيين. لا يعيد ضبط جميع أزرار جهاز التحكم. يطلب <bdi dir="ltr">**Delete**</bdi> التأكيد قبل حذف التعيين المحدد.

إذا كان تعيين الزر موجودًا بالفعل، أو كان جهاز تحكم آخر يستخدم الاسم نفسه، أو تغير التعيين من مكان آخر، فراجع الخطأ وصحح المسودة قبل الحفظ مجددًا. إذا حُفظ التعيين وتعذر تطبيقه على البوابة قيد التشغيل، فاستخدم إجراء <bdi dir="ltr">**Retry**</bdi> المتاح لتحديثه.
