# إعدادات التطبيق {/* #application-settings */}

تُجمع الخيارات العامة للتطبيق ضمن الفئات التالية في [Settings](/settings). توجد الخيارات الخاصة بكل ملف شخصي ضمن [Profiles](/settings/profiles).

## Appearance & controls

| الخيار | الغرض |
|--------|---------|
| App language | استخدم إحدى اللغات التي يدعمها التطبيق أو اللغة الافتراضية لنظام Android. |
| Hide navigation bar | أخفِ أزرار التنقل في Android حيثما كان ذلك مدعومًا. على شاشة اللمس، قد تُظهر النقرة الأولى عناصر التنقل، وقد تحتاج إلى نقرة ثانية لإظهار عناصر التحكم في التطبيق. |
| Always show overlay buttons | اعرض عناصر التحكم على الشاشة. يمكنك تعطيل هذا الخيار على صندوق التلفاز إذا أدى الضغط على أزرار جهاز التحكم إلى إظهار أزرار غير مرغوبة. |
| Hide controls after… (ms) | اضبط مهلة إخفاء عناصر التحكم على الشاشة بالمللي ثانية. القيمة الافتراضية: 5000 (5 ثوانٍ). |
| Screen orientation | اختر سلوك اتجاه شاشة التطبيق. |
| Keyboard type | اختر لوحة المفاتيح التي يستخدمها التطبيق. |
| Software keyboard input method | اختر كيفية معالجة الإدخال بواسطة لوحة المفاتيح البرمجية. |

## Playback & behavior

| الخيار | الغرض |
|--------|---------|
| Pause media in background | أوقف التشغيل مؤقتًا عند الانتقال إلى تطبيق آخر. لا يتوفر عنصر التحكم هذا أثناء تفعيل وضع صورة داخل صورة التلقائي. |
| Picture-in-picture | استخدم وضع صورة داخل صورة عند مغادرة التطبيق، إذا كان نظام Android والجهاز يدعمان ذلك. |
| Auto start on device boot | ابدأ تشغيل التطبيق بعد بدء تشغيل الجهاز. يجب تثبيت التطبيق في مساحة التخزين الداخلية؛ وقد تؤخر شاشة قفل الجهاز بدء تشغيله حتى إلغاء القفل. |
| Always use system volume level | استخدم مستوى صوت النظام بدلًا من مستوى صوت مستقل للتطبيق. |
| Enable recommendations | اعرض بطاقات توصيات للملفات الشخصية على الشاشات الرئيسية لأجهزة Android TV المدعومة. |
| Media sessions | فعّل التكامل مع جلسات الوسائط في Android. |

## Network

يغيّر <bdi dir="ltr">**Scaling method**</bdi> تحجيم المتصفح إذا ظهرت البوابة بحجم أكبر أو أصغر من اللازم. يمكن الإبقاء على القيمة الافتراضية في معظم الأجهزة؛ وقد تحتاج الشاشات منخفضة الدقة إلى طريقة مختلفة.

يخزّن <bdi dir="ltr">**Enable network cache**</bdi> طلبات الشبكة مؤقتًا لتحسين تحميل البوابة. عطّله إذا واجهت مشكلات متكررة في المصادقة أو غيرها من مشكلات الشبكة.

تُدخل قيمة <bdi dir="ltr">**Cache size**</bdi> بوحدة KB. القيمة الافتراضية هي <bdi dir="ltr">**20480 KB (20 MB)**</bdi>. أعِد تشغيل التطبيق عند طلب ذلك لتطبيق التغيير في حجم ذاكرة التخزين المؤقت.

## Security

فعّل حماية الإعدادات بكلمة مرور وعيّن كلمة المرور. تتطلب الإعدادات المحمية المصادقة. لا يحتفظ محرر كلمة المرور بالمحتوى السري عند إعادة إنشاء الشاشة؛ فأدخله مجددًا عند الحاجة.

## Legacy remote

تضبط هذه الفئة خدمة التحكم عن بُعد البرمجية القديمة الخاصة بتطبيقات MAG 250 وAuraHD والتطبيقات المشابهة. وهي منفصلة عن [Companion](/settings/companion) وعن [تعيين أزرار أجهزة التحكم الفعلية](/settings/key-maps).

فعّل الخدمة واضبط اسم الجهاز وكلمة المرور الخاصين بها. يمكن أن يحتوي كل من اسم الجهاز وكلمة المرور على 32 حرفًا كحد أقصى. تتوفر هذه الفئة فقط في إصدارات التطبيق التي تتيحها.
