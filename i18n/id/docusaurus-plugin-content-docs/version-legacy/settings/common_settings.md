### Settings
#### App Language
Ubah bahasa aplikasi. Secara bawaan, aplikasi menggunakan bahasa sistem Android jika didukung.

#### Hide navigation bar
Sembunyikan bilah navigasi dan tombolnya (mungkin tidak berfungsi pada beberapa perangkat). Jika opsi ini diaktifkan dan Anda menggunakan
layar sentuh, Anda mungkin perlu mengetuk dua kali untuk menampilkan tombol di layar yang tersembunyi.
Ketukan pertama menampilkan bilah navigasi; ini merupakan pembatasan Android.

#### Always show overlay buttons
Tampilkan tombol di layar. Opsi ini biasanya sebaiknya tetap diaktifkan. Pada STB, Anda dapat menonaktifkannya jika tombol
muncul saat Anda menekan tombol pada remote.

#### Screen configuration
Aktifkan atau nonaktifkan rotasi layar saat orientasi perangkat berubah.

#### Keyboard configuration
Pengaturan remote (tidak tersedia pada versi gratis).

Atur server remote untuk mengendalikan portal menggunakan aplikasi kendali jarak jauh bagi MAG 250, AuraHD, atau perangkat serupa.

#### Boot options
##### Auto start on device boot

Jalankan aplikasi saat perangkat dinyalakan. Ini hanya berfungsi jika aplikasi diinstal di penyimpanan internal.
Jika layar kunci diaktifkan pada perangkat Anda (misalnya pada ponsel atau tablet), aplikasi dijalankan setelah Anda membuka kunci.

#### Stop in the background
Jeda aplikasi saat Anda beralih ke aplikasi lain.

#### Android TV
Opsi khusus untuk Android TV.

##### Enable recommendations

Aktifkan kartu rekomendasi pada layar utama Android. Aplikasi menampilkan kartu untuk setiap profil yang dikonfigurasi
agar Anda dapat mengaksesnya dengan cepat.

#### Browser settings
Pengaturan peramban.

##### Scaling method
Pilih metode penskalaan peramban yang berbeda jika portal tampak terlalu besar atau terlalu kecil.
Sebagian besar perangkat tidak memerlukan perubahan pengaturan ini. Pengecualiannya adalah perangkat yang resolusi layarnya lebih rendah
daripada resolusi portal, yang biasanya 1280x720.

#### Network settings
Pengaturan jaringan.

##### Enable network cache
Simpan permintaan jaringan dalam cache untuk mempercepat pemuatan portal pada sebagian besar kasus. Nonaktifkan opsi ini jika Anda sering
mengalami kesalahan autentikasi atau masalah jaringan lainnya.

##### Cache size
Ukuran cache jaringan. Nilai bawaan: 20 MB.
