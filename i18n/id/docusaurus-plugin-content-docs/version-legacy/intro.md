# StbEmu

**StbEmu** adalah aplikasi Android 8.0+ yang memuat portal web yang dirancang untuk set-top box (STB)
pada perangkat Android, termasuk ponsel, tablet, dan TV box.
Aplikasi ini saat ini mendukung emulasi beberapa model STB buatan perusahaan Ukraina Infomir,
seperti MAG 250, MAG 270, dan MAG 322. Lihat [daftar perangkat yang diemulasi](supported_devices.md).

:::note
**StbEmu** adalah alat teknologi netral dan emulator perangkat keras. Aplikasi ini tidak menyediakan, menghosting, atau mengindeks media,
daftar putar, maupun portal streaming apa pun. Aplikasi ini dirancang agar pengguna dapat mengakses konten milik mereka yang diperoleh secara legal.
Pengembang tidak berafiliasi dengan penyedia konten pihak ketiga mana pun.
:::

Aplikasi ini tersedia dalam dua versi: gratis dan berbayar. [Versi gratis](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) menampilkan iklan; [versi Pro](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) tidak.
Inilah perbedaan utama di antara keduanya.
