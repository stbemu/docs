# Kontrol jarak jauh {/* #remote-control */}

Buka perangkat yang terhubung dan pilih **Remote control**. Tindakan ini hanya ditampilkan jika perangkat mendukung masukan jarak jauh yang diizinkan. Kontrol ini mengoperasikan StbEmu dan portalnya; kontrol ini terpisah dari layanan remote MAG lama yang dijelaskan di [Remote lama](../settings/common_settings.md#legacy-remote).

![Remote yang dapat digulir dengan tombol berwarna dan tombol arah](/img/companion/remote-control.png)

Ketuk tombol untuk tindakan biasanya. Tahan tombol untuk tindakan tekan lama atau penekanan berulang jika didukung. Lepaskan untuk berhenti menahan. Tombol yang tersedia dan perilaku tahan bergantung pada perangkat; tidak semua tombol mendukung pengulangan. Gulir untuk menjangkau kontrol lainnya, termasuk tombol pemutaran, volume, saluran, dan angka.

Hanya satu gestur tombol yang aktif pada satu waktu. Meninggalkan halaman remote atau aplikasi, kehilangan koneksi, atau kehilangan izin akan membatalkan masukan aktif. Masukan jarak jauh tidak diputar ulang setelah terhubung kembali: hubungkan kembali lalu tekan lagi dengan sengaja.

## Memahami umpan balik {/* #read-the-feedback */}

Umpan balik tekan/tahan lokal berarti Companion mengenali gestur Anda. **Awaiting device confirmation** berarti hasil masih menunggu. **Device accepted input** mengonfirmasi bahwa StbEmu menerima masukan, bukan bahwa tindakan saluran atau portal pasti telah selesai.

Untuk **Input target unavailable**, periksa koneksi. Untuk **Authorization expired. Pair again.**, tampilkan kode baru di StbEmu dan masukkan di Companion. Jika suatu tindakan tidak lagi didukung, hentikan penggunaannya dan periksa kontrol yang tersedia. Hubungkan kembali jika masukan tetap tidak tersedia.

Ubah getaran remote di **Settings > Interface > Remote control haptic feedback**. Ini terpisah dari **UI haptic feedback**; umpan balik visual tetap tersedia saat getaran dimatikan.
