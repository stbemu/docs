# Pengaturan aplikasi {/* #application-settings */}

Opsi yang berlaku untuk seluruh aplikasi dikelompokkan ke dalam kategori berikut di [Setelan](/settings). Opsi khusus profil berada di [Profil](/settings/profiles).

## Tampilan dan kontrol {/* #appearance--controls */}

| Opsi | Kegunaan |
|--------|---------|
| Bahasa aplikasi | Gunakan bahasa aplikasi yang didukung atau bahasa bawaan sistem Android. |
| Sembunyikan bilah navigasi | Sembunyikan tombol navigasi Android jika didukung. Pada layar sentuh, ketukan pertama dapat menampilkan navigasi dan ketukan kedua mungkin diperlukan untuk menampilkan kontrol aplikasi. |
| Selalu tampilkan tombol overlay | Tampilkan kontrol di layar. Anda dapat menonaktifkannya pada TV box jika penekanan tombol remote memunculkan tombol yang tidak diinginkan. |
| Sembunyikan kontrol setelah… (ms) | Atur batas waktu kontrol di layar dalam milidetik. Nilai bawaan: 5000 (5 detik). |
| Orientasi layar | Pilih perilaku orientasi aplikasi. |
| Jenis papan ketik | Pilih papan ketik yang digunakan aplikasi. |
| Metode input papan ketik virtual | Pilih cara masukan ditangani oleh papan ketik perangkat lunak. |

## Pemutaran dan perilaku {/* #playback--behavior */}

| Opsi | Kegunaan |
|--------|---------|
| Hentikan di latar belakang | Jeda pemutaran saat beralih ke aplikasi lain. Kontrol ini tidak tersedia saat picture-in-picture otomatis diaktifkan. |
| Beralih ke mode PiP saat diminimalkan | Gunakan picture-in-picture saat meninggalkan aplikasi, jika didukung oleh Android dan perangkat. |
| Mulai otomatis saat perangkat menyala | Jalankan aplikasi setelah perangkat dinyalakan. Aplikasi harus diinstal di penyimpanan internal; layar kunci perangkat dapat menunda aplikasi dimulai hingga kunci dibuka. |
| Selalu gunakan volume sistem | Gunakan volume sistem, bukan volume aplikasi yang terpisah. |
| Aktifkan rekomendasi | Tampilkan kartu rekomendasi profil pada layar utama Android TV yang didukung. |
| Buat sesi media saat pemutaran dimulai | Aktifkan integrasi sesi media Android. |

## Jaringan {/* #network */}

**Metode penskalaan** mengubah penskalaan peramban jika portal tampak terlalu besar atau terlalu kecil. Sebagian besar perangkat dapat menggunakan nilai bawaan; layar beresolusi rendah mungkin memerlukan metode yang berbeda.

**Aktifkan cache jaringan** menyimpan permintaan jaringan dalam cache untuk mempercepat pemuatan portal. Nonaktifkan jika Anda mengalami masalah autentikasi berulang atau masalah jaringan lainnya.

**Ukuran cache (KByte)** dimasukkan dalam KB. Nilai bawaannya adalah **20480 KB (20 MB)**. Mulai ulang aplikasi saat diminta untuk menerapkan perubahan ukuran cache.

## Keamanan {/* #security */}

Aktifkan perlindungan pengaturan dengan kata sandi dan tetapkan kata sandinya. Pengaturan yang dilindungi memerlukan autentikasi. Editor kata sandi tidak menyimpan nilai rahasianya saat layar dibuat ulang; masukkan lagi jika perlu.

## Remote lama {/* #legacy-remote */}

Kategori ini mengatur layanan kendali jarak jauh perangkat lunak lama untuk MAG 250, AuraHD, dan aplikasi remote serupa. Layanan ini terpisah dari [Companion](/settings/companion) dan [pemetaan tombol fisik](/settings/key-maps).

Aktifkan layanan, lalu atur nama perangkat dan kata sandinya. Nama perangkat dan kata sandi masing-masing dapat berisi hingga 32 karakter. Kategori ini hanya tersedia pada edisi aplikasi yang mengaktifkannya.
