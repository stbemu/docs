# Pengaturan aplikasi {/* #application-settings */}

Opsi yang berlaku untuk seluruh aplikasi dikelompokkan ke dalam kategori berikut di [Settings](/settings). Opsi khusus profil berada di [Profiles](/settings/profiles).

## Appearance & controls

| Opsi | Kegunaan |
|--------|---------|
| App language | Gunakan bahasa aplikasi yang didukung atau bahasa bawaan sistem Android. |
| Hide navigation bar | Sembunyikan tombol navigasi Android jika didukung. Pada layar sentuh, ketukan pertama dapat menampilkan navigasi dan ketukan kedua mungkin diperlukan untuk menampilkan kontrol aplikasi. |
| Always show overlay buttons | Tampilkan kontrol di layar. Anda dapat menonaktifkannya pada TV box jika penekanan tombol remote memunculkan tombol yang tidak diinginkan. |
| Hide controls after… (ms) | Atur batas waktu kontrol di layar dalam milidetik. Nilai bawaan: 5000 (5 detik). |
| Screen orientation | Pilih perilaku orientasi aplikasi. |
| Keyboard type | Pilih papan ketik yang digunakan aplikasi. |
| Software keyboard input method | Pilih cara masukan ditangani oleh papan ketik perangkat lunak. |

## Playback & behavior

| Opsi | Kegunaan |
|--------|---------|
| Pause media in background | Jeda pemutaran saat beralih ke aplikasi lain. Kontrol ini tidak tersedia saat picture-in-picture otomatis diaktifkan. |
| Picture-in-picture | Gunakan picture-in-picture saat meninggalkan aplikasi, jika didukung oleh Android dan perangkat. |
| Auto start on device boot | Jalankan aplikasi setelah perangkat dinyalakan. Aplikasi harus diinstal di penyimpanan internal; layar kunci perangkat dapat menunda aplikasi dimulai hingga kunci dibuka. |
| Always use system volume level | Gunakan volume sistem, bukan volume aplikasi yang terpisah. |
| Enable recommendations | Tampilkan kartu rekomendasi profil pada layar utama Android TV yang didukung. |
| Media sessions | Aktifkan integrasi sesi media Android. |

## Network

**Scaling method** mengubah penskalaan peramban jika portal tampak terlalu besar atau terlalu kecil. Sebagian besar perangkat dapat menggunakan nilai bawaan; layar beresolusi rendah mungkin memerlukan metode yang berbeda.

**Enable network cache** menyimpan permintaan jaringan dalam cache untuk mempercepat pemuatan portal. Nonaktifkan jika Anda mengalami masalah autentikasi berulang atau masalah jaringan lainnya.

**Cache size** dimasukkan dalam KB. Nilai bawaannya adalah **20480 KB (20 MB)**. Mulai ulang aplikasi saat diminta untuk menerapkan perubahan ukuran cache.

## Security

Aktifkan perlindungan pengaturan dengan kata sandi dan tetapkan kata sandinya. Pengaturan yang dilindungi memerlukan autentikasi. Editor kata sandi tidak menyimpan nilai rahasianya saat layar dibuat ulang; masukkan lagi jika perlu.

## Legacy remote

Kategori ini mengatur layanan kendali jarak jauh perangkat lunak lama untuk MAG 250, AuraHD, dan aplikasi remote serupa. Layanan ini terpisah dari [Companion](/settings/companion) dan [pemetaan tombol fisik](/settings/key-maps).

Aktifkan layanan, lalu atur nama perangkat dan kata sandinya. Nama perangkat dan kata sandi masing-masing dapat berisi hingga 32 karakter. Kategori ini hanya tersedia pada edisi aplikasi yang mengaktifkannya.
