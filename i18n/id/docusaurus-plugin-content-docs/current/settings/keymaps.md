# Key mapping

Buka **Settings > Key mapping** untuk menetapkan tindakan pada tombol remote fisik. Pemetaan terkait dengan remote yang tombolnya direkam; tekan singkat dan tekan lama dapat memiliki penetapan berbeda.

## Menambah atau mengedit pemetaan {/* #add-or-edit-a-mapping */}

1. Pilih tindakan tambah tombol, atau buka pemetaan yang sudah ada.
2. Pilih **Capture a key**, lalu tekan tombol yang diinginkan pada remote fisik. Perekaman berakhir setelah tombol diterima. Tombol panah dan OK tetap berfungsi sebagai kontrol navigasi.
3. Pilih tindakan yang akan dilakukan. Aktifkan **Long key press** jika penetapan ini untuk tekan lama.
4. Pilih **Save** untuk menyimpan penetapan.

Gunakan **Show default keys** untuk menyertakan pemetaan bawaan dalam daftar. Opsi ini dinonaktifkan secara bawaan.

**Reset** meminta konfirmasi, membuang perubahan yang tertunda, dan memuat ulang pemetaan. Tindakan ini tidak mengatur ulang semua tombol remote. **Delete** meminta konfirmasi sebelum menghapus pemetaan yang dipilih.

Jika penetapan tombol sudah ada, remote lain menggunakan nama yang sama, atau pemetaan berubah di tempat lain, tinjau kesalahan dan perbaiki draf sebelum menyimpan lagi. Jika pemetaan disimpan tetapi tidak dapat diterapkan pada portal yang sedang berjalan, gunakan tindakan **Retry** yang ditawarkan untuk menerapkannya ulang.
