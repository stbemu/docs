# Pemetaan tombol {/* #key-mapping */}

Buka **Setelan > Pemetaan tombol** untuk menetapkan tindakan pada tombol remote fisik. Pemetaan terkait dengan remote yang tombolnya direkam; tekan singkat dan tekan lama dapat memiliki penetapan berbeda.

## Menambah atau mengedit pemetaan {/* #add-or-edit-a-mapping */}

1. Pilih tindakan tambah tombol, atau buka pemetaan yang sudah ada.
2. Pilih **Tangkap tombol**, lalu tekan tombol yang diinginkan pada remote fisik. Perekaman berakhir setelah tombol diterima. Tombol panah dan OK tetap berfungsi sebagai kontrol navigasi.
3. Pilih tindakan yang akan dilakukan. Aktifkan **Tekan lama tombol** jika penetapan ini untuk tekan lama.
4. Pilih **Simpan** untuk menyimpan penetapan.

Gunakan **Tampilkan tombol bawaan** untuk menyertakan pemetaan bawaan dalam daftar. Opsi ini dinonaktifkan secara bawaan.

**Setel ulang** meminta konfirmasi, membuang perubahan yang tertunda, dan memuat ulang pemetaan. Tindakan ini tidak mengatur ulang semua tombol remote. **Hapus** meminta konfirmasi sebelum menghapus pemetaan yang dipilih.

Jika penetapan tombol sudah ada, remote lain menggunakan nama yang sama, atau pemetaan berubah di tempat lain, tinjau kesalahan dan perbaiki draf sebelum menyimpan lagi. Jika pemetaan disimpan tetapi tidak dapat diterapkan pada portal yang sedang berjalan, gunakan tindakan **Coba lagi** yang ditawarkan untuk menerapkannya ulang.
