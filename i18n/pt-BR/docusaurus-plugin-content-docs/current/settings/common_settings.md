# Configurações do aplicativo {/* #application-settings */}

As opções que se aplicam a todo o aplicativo estão agrupadas nas categorias abaixo em [Configurações](/settings). As opções específicas de cada perfil ficam em [Perfis](/settings/profiles).

## Aparência e controles {/* #appearance--controls */}

| Opção | Finalidade |
|-------|------------|
| Idioma do aplicativo | Usar um idioma compatível com o aplicativo ou o padrão do sistema Android. |
| Ocultar barra de navegação | Ocultar os botões de navegação do Android quando houver suporte. Em uma tela sensível ao toque, o primeiro toque pode exibir a navegação, e um segundo toque pode ser necessário para exibir os controles do aplicativo. |
| Sempre mostrar botões sobrepostos | Mostrar controles na tela. Você pode desativar essa opção em uma TV box se pressionar as teclas do controle remoto fizer aparecer botões indesejados. |
| Ocultar controles após… (ms) | Definir o tempo limite dos controles na tela em milissegundos. Padrão: 5000 (5 segundos). |
| Orientação da tela | Escolher o comportamento da orientação do aplicativo. |
| Tipo de teclado | Escolher o teclado usado pelo aplicativo. |
| Método de entrada do teclado virtual | Escolher como a entrada é processada pelo teclado virtual. |

## Reprodução e comportamento {/* #playback--behavior */}

| Opção | Finalidade |
|-------|------------|
| Parar em segundo plano | Pausar a reprodução ao mudar para outro aplicativo. Este controle fica indisponível quando o picture-in-picture automático está ativado. |
| Alternar para o modo PiP ao minimizar | Usar picture-in-picture ao sair do aplicativo, quando houver suporte no Android e no dispositivo. |
| Iniciar automaticamente ao ligar o dispositivo | Iniciar o aplicativo após a inicialização do dispositivo. O aplicativo precisa estar instalado no armazenamento interno; uma tela de bloqueio pode adiar a inicialização até que o dispositivo seja desbloqueado. |
| Sempre usar o volume do sistema | Usar o volume do sistema em vez de um volume separado para o aplicativo. |
| Ativar recomendações | Mostrar cartões de recomendação de perfis nas telas iniciais de Android TV compatíveis. |
| Criar sessão de mídia ao iniciar a reprodução | Ativar a integração com as sessões de mídia do Android. |

## Rede {/* #network */}

**Método de dimensionamento** altera a escala do navegador quando um portal aparece grande ou pequeno demais. Na maioria dos dispositivos, é possível manter o padrão; uma tela de baixa resolução pode precisar de outro método.

**Ativar cache de rede** armazena solicitações de rede em cache para melhorar o carregamento do portal. Desative se ocorrerem problemas recorrentes de autenticação ou de rede.

O **Tamanho do cache (KBytes)** é informado em KB. O padrão é **20480 KB (20 MB)**. Reinicie o aplicativo quando solicitado para aplicar a alteração no tamanho do cache.

## Segurança {/* #security */}

Ative a proteção das configurações por senha e defina uma senha. As configurações protegidas exigem autenticação. O editor de senha não mantém a senha quando a tela é recriada; digite-a novamente se necessário.

## Controle remoto legado {/* #legacy-remote */}

Esta categoria configura o serviço antigo de controle remoto por software para MAG 250, AuraHD e aplicativos de controle remoto semelhantes. Ele é separado do [Companion](/settings/companion) e do [mapeamento de teclas físicas](/settings/key-maps).

Ative o serviço e configure o nome do dispositivo e a senha. Cada um desses campos aceita até 32 caracteres. Esta categoria está disponível apenas nas edições do aplicativo que a habilitam.
