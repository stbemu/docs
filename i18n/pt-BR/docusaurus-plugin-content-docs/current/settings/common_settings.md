# Configurações do aplicativo {/* #application-settings */}

As opções que se aplicam a todo o aplicativo estão agrupadas nas categorias abaixo em [Settings](/settings). As opções específicas de cada perfil ficam em [Profiles](/settings/profiles).

## Appearance & controls

| Opção | Finalidade |
|-------|------------|
| App language | Usar um idioma compatível com o aplicativo ou o padrão do sistema Android. |
| Hide navigation bar | Ocultar os botões de navegação do Android quando houver suporte. Em uma tela sensível ao toque, o primeiro toque pode exibir a navegação, e um segundo toque pode ser necessário para exibir os controles do aplicativo. |
| Always show overlay buttons | Mostrar controles na tela. Você pode desativar essa opção em uma TV box se pressionar as teclas do controle remoto fizer aparecer botões indesejados. |
| Hide controls after… (ms) | Definir o tempo limite dos controles na tela em milissegundos. Padrão: 5000 (5 segundos). |
| Screen orientation | Escolher o comportamento da orientação do aplicativo. |
| Keyboard type | Escolher o teclado usado pelo aplicativo. |
| Software keyboard input method | Escolher como a entrada é processada pelo teclado virtual. |

## Playback & behavior

| Opção | Finalidade |
|-------|------------|
| Pause media in background | Pausar a reprodução ao mudar para outro aplicativo. Este controle fica indisponível quando o picture-in-picture automático está ativado. |
| Picture-in-picture | Usar picture-in-picture ao sair do aplicativo, quando houver suporte no Android e no dispositivo. |
| Auto start on device boot | Iniciar o aplicativo após a inicialização do dispositivo. O aplicativo precisa estar instalado no armazenamento interno; uma tela de bloqueio pode adiar a inicialização até que o dispositivo seja desbloqueado. |
| Always use system volume level | Usar o volume do sistema em vez de um volume separado para o aplicativo. |
| Enable recommendations | Mostrar cartões de recomendação de perfis nas telas iniciais de Android TV compatíveis. |
| Media sessions | Ativar a integração com as sessões de mídia do Android. |

## Network

**Scaling method** altera a escala do navegador quando um portal aparece grande ou pequeno demais. Na maioria dos dispositivos, é possível manter o padrão; uma tela de baixa resolução pode precisar de outro método.

**Enable network cache** armazena solicitações de rede em cache para melhorar o carregamento do portal. Desative se ocorrerem problemas recorrentes de autenticação ou de rede.

O **Cache size** é informado em KB. O padrão é **20480 KB (20 MB)**. Reinicie o aplicativo quando solicitado para aplicar a alteração no tamanho do cache.

## Security

Ative a proteção das configurações por senha e defina uma senha. As configurações protegidas exigem autenticação. O editor de senha não mantém a senha quando a tela é recriada; digite-a novamente se necessário.

## Legacy remote

Esta categoria configura o serviço antigo de controle remoto por software para MAG 250, AuraHD e aplicativos de controle remoto semelhantes. Ele é separado do [Companion](/settings/companion) e do [mapeamento de teclas físicas](/settings/key-maps).

Ative o serviço e configure o nome do dispositivo e a senha. Cada um desses campos aceita até 32 caracteres. Esta categoria está disponível apenas nas edições do aplicativo que a habilitam.
