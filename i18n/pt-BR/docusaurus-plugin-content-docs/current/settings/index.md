# Settings

Abra o menu do aplicativo e selecione **Settings**. Este guia aborda a interface de Configurações reformulada; versões mais antigas do aplicativo podem agrupar as opções de outra forma. As categorias e ações disponíveis dependem da edição do aplicativo e de sua configuração.

## Navegação {/* #navigation */}

Em uma TV, use Up/Down para selecionar uma categoria no painel esquerdo. A página correspondente é carregada automaticamente. Pressione Right para entrar na página, Left para voltar às categorias, OK para ativar um controle e Back para retornar à página anterior. Enter e Esc também são aceitos.

Em um celular, selecione uma categoria na página inicial de Settings. Use o controle Back ou a ação Voltar do Android para retornar. Em telas sensíveis ao toque mais largas, as categorias podem aparecer ao lado da página selecionada.

## Como salvar alterações {/* #saving-changes */}

Os interruptores salvam as alterações ao serem acionados. Os editores de texto e de seleção salvam após sua confirmação. Aguarde a conclusão de um salvamento pendente antes de enviar outra alteração. Sair de uma página não cancela um salvamento já aceito.

Entradas inválidas permanecem no editor com uma explicação. Se as configurações forem alteradas em outro lugar enquanto você edita, escolha **Reload**, compare seu rascunho com as configurações atualizadas e confirme novamente. Reload mantém o rascunho para revisão; não o salva automaticamente. Um item excluído não pode ser salvo.

Se o aplicativo informar que uma alteração foi salva, mas não pôde ser aplicada ao aplicativo em execução, o valor armazenado já foi alterado. Siga a instrução para tentar novamente ou reiniciar, em vez de presumir que o salvamento falhou. As configurações protegidas por senha podem pedir uma nova autenticação depois de serem reabertas.
