# Key mapping

Abra **Settings > Key mapping** para atribuir ações às teclas de um controle remoto físico. Os mapeamentos pertencem ao controle remoto do qual foram capturados; toques curtos e longos podem ter atribuições separadas.

## Adicionar ou editar um mapeamento {/* #add-or-edit-a-mapping */}

1. Selecione a ação de adicionar tecla ou abra um mapeamento existente.
2. Selecione **Capture a key** e pressione a tecla desejada no controle remoto físico. A captura termina assim que a tecla é recebida. As setas e OK continuam funcionando como controles de navegação.
3. Escolha a ação a executar. Ative **Long key press** se esta atribuição for para um toque longo.
4. Selecione **Save** para armazenar a atribuição.

Use **Show default keys** para incluir os mapeamentos predefinidos na lista. Essa opção fica desativada por padrão.

**Reset** pede confirmação, descarta as alterações pendentes e recarrega o mapeamento. Essa ação não redefine todas as teclas do controle remoto. **Delete** pede confirmação antes de excluir o mapeamento selecionado.

Se já existir uma atribuição para a tecla, se outro controle remoto usar o mesmo nome ou se o mapeamento tiver sido alterado em outro lugar, verifique o erro e corrija o rascunho antes de salvar novamente. Se um mapeamento for salvo, mas não puder ser aplicado ao portal em execução, use a ação **Retry** oferecida para atualizá-lo.
