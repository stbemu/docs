# StbEmu

**StbEmu** é um aplicativo para Android 8.0 ou superior que carrega portais da web criados para decodificadores (STBs)
em dispositivos Android, incluindo celulares, tablets e TV boxes.
Atualmente, o aplicativo permite emular vários modelos de STB fabricados pela empresa ucraniana Infomir,
como MAG 250, MAG 270 e MAG 322. Consulte a [lista de dispositivos emulados](supported_devices.md).

:::note
**StbEmu** é uma ferramenta tecnológica neutra e um emulador de hardware. Ele não fornece, hospeda nem indexa mídia,
listas de reprodução ou portais de streaming. O aplicativo foi desenvolvido para que os usuários acessem conteúdo próprio adquirido legalmente.
O desenvolvedor não tem vínculo com nenhum provedor de conteúdo de terceiros.
:::

Existem duas versões do aplicativo: gratuita e paga. A [versão gratuita](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) exibe anúncios; a [versão Pro](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) não.
Essa é a principal diferença entre elas.
