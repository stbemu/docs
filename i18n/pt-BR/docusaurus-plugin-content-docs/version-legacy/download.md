# Download

![StbEmu gratuito](/img/stbemu_free_icon.png)

O StbEmu está disponível em duas versões: gratuita e Pro (paga).

| Versão gratuita | Versão Pro (paga) |
|-----------------|-------------------|
| Exibe anúncios | Sem anúncios |
| | Compatível com controles remotos por software para MAG 250 * |
| [Baixar no Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Baixar no Google Play](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Antes de usar um controle remoto por software do Google Play, verifique se ele é compatível com o MAG 250.
