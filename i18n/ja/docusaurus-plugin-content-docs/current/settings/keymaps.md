# Key mapping {/* #key-mapping */}

**Settings > Key mapping** を開くと、物理リモコンのキーに操作を割り当てられます。割り当ては、キーを取得したリモコンに紐づきます。短押しと長押しには、それぞれ別の操作を割り当てられます。

## 割り当ての追加と編集 {/* #add-or-edit-a-mapping */}

1. キーを追加する操作を選ぶか、既存の割り当てを開きます。
2. **Capture a key** を選び、物理リモコンの目的のキーを押します。キーを受信すると取得は終了します。矢印キーと OK は引き続き画面移動に使われます。
3. 実行する操作を選びます。長押しに割り当てる場合は、**Long key press** を有効にします。
4. **Save** を選んで割り当てを保存します。

**Show default keys** を使うと、標準の割り当ても一覧に表示されます。既定では無効です。

**Reset** は確認後、保留中の変更を破棄してその割り当てを再読み込みします。すべてのリモコンキーをリセットする操作ではありません。**Delete** は確認後、選択した割り当てを削除します。

キーの割り当てがすでにある場合、別のリモコンが同じ名前を使用している場合、または別の場所で割り当てが変更された場合は、エラーを確認して下書きを修正してから再保存してください。割り当てを保存できても実行中のポータルに適用できない場合は、表示された **Retry** で更新してください。
