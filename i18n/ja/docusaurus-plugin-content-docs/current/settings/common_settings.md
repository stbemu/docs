# アプリの設定 {/* #application-settings */}

アプリ全体の設定は、[設定](/settings) の以下のカテゴリに分類されています。プロファイル固有の設定は [プロファイル](/settings/profiles) にあります。

## 表示と操作 {/* #appearance--controls */}

| 設定項目 | 用途 |
|--------|---------|
| アプリの言語 | 対応言語または Android のシステム既定の言語を使用します。 |
| ナビゲーションバーを非表示 | 対応端末で Android のナビゲーションボタンを非表示にします。タッチ画面では、最初のタップでナビゲーションが表示され、アプリの操作ボタンを表示するためにもう一度タップが必要になる場合があります。 |
| オーバーレイボタンを常に表示 | 画面上の操作ボタンを表示します。TV ボックスでリモコンのキーを押した際に不要なボタンが表示される場合は、無効にできます。 |
| 操作ボタンを非表示にするまでの時間…（ミリ秒） | 画面上の操作ボタンが消えるまでの時間をミリ秒で設定します。既定値：5000（5 秒）。 |
| 画面の向き | アプリの画面の向きの動作を選びます。 |
| キーボードの種類 | アプリで使用するキーボードを選びます。 |
| ソフトウェアキーボードの入力方式 | ソフトウェアキーボードでの入力処理方法を選びます。 |

## 再生と動作 {/* #playback--behavior */}

| 設定項目 | 用途 |
|--------|---------|
| バックグラウンドで停止 | 別のアプリに切り替えたときに再生を一時停止します。自動ピクチャーインピクチャーが有効な間は、この項目を操作できません。 |
| 最小化時に PiP モードに切り替え | Android と端末が対応している場合に、アプリを離れるとピクチャーインピクチャーを使用します。 |
| デバイス起動時に自動起動 | 端末の起動後にアプリを起動します。アプリは内部ストレージにインストールされている必要があります。ロック画面がある端末では、解除されるまで起動が遅れる場合があります。 |
| 常にシステムの音量を使用 | アプリ独自の音量ではなく、システムの音量を使用します。 |
| おすすめを有効にする | 対応する Android TV のホーム画面に、プロファイルのおすすめカードを表示します。 |
| 再生開始時にメディアセッションを作成 | Android のメディアセッション連携を有効にします。 |

## ネットワーク {/* #network */}

**拡大縮小方式** は、ポータルが大きすぎる、または小さすぎる場合にブラウザーの拡大縮小方法を変更します。ほとんどの端末では既定値のままで使用できますが、低解像度の画面では別の方法が必要になる場合があります。

**ネットワークキャッシュを有効にする** は、ネットワークリクエストをキャッシュしてポータルの読み込みを改善します。認証などのネットワークの問題が繰り返し発生する場合は無効にしてください。

**キャッシュサイズ（KB）** は KB 単位で入力します。既定値は **20480 KB (20 MB)** です。キャッシュサイズの変更を適用するために再起動を求められたら、アプリを再起動してください。

## セキュリティ {/* #security */}

設定のパスワード保護を有効にし、パスワードを設定します。保護された設定には認証が必要です。画面が再作成されるとパスワード入力欄の内容は保持されないため、必要に応じて再入力してください。

## 従来のリモコン {/* #legacy-remote */}

このカテゴリでは、MAG 250、AuraHD などの古いリモコンアプリ向けソフトウェアリモコンサービスを設定します。[Companion](/settings/companion) や[物理キーの割り当て](/settings/key-maps)とは別の機能です。

サービスを有効にし、端末名とパスワードを設定します。端末名とパスワードは、それぞれ最大 32 文字です。このカテゴリは、当該機能を有効にしたアプリのエディションでのみ利用できます。
