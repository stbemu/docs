# アプリ情報と更新 {/* #about--updates */}

**設定 > アプリ情報と更新** を開くと、アプリ情報と、同梱ライブラリに関する通知をまとめた **サードパーティに関する表記** を確認できます。

更新設定、更新一覧、更新の詳細は、アプリ内更新を有効にしたビルドにのみ表示されます。ここで説明する 設定 のバージョンでは、Google Play 版のアプリ内更新は無効になっています。更新セクションが表示されなくても、設定のエラーではありません。

更新を利用できる場合は、選択した更新の内容を確認してからダウンロードしてください。アプリにはダウンロードの進行状況が表示され、キャンセルも可能です。Android のインストーラーが開いただけでは更新はインストールされていません。Android 側でインストールを完了し、その後アプリのバージョンを確認してください。
