# 設定 {/* #settings */}

アプリのメニューを開き、**設定** を選びます。このガイドは新しく設計された 設定 画面を対象としています。古いバージョンでは設定項目の分類が異なる場合があります。利用できるカテゴリや操作は、アプリのエディションと構成によって異なります。

## 画面の操作 {/* #navigation */}

テレビでは、上・下キーで左側のカテゴリを選びます。選んだページは自動的に読み込まれます。右キーでページに移り、左キーでカテゴリに戻り、OK で項目を操作し、戻る で前のページに戻ります。Enter と Esc にも対応しています。

スマートフォンでは、設定 のホームページからカテゴリを選びます。戻るには 戻る コントロールか Android の戻る操作を使用します。幅の広いタッチ画面では、選択したページの横にカテゴリが表示される場合があります。

## 変更の保存 {/* #saving-changes */}

スイッチは操作時に保存されます。テキストや選択項目は、確認後に保存されます。次の変更を送信する前に、処理中の保存が完了するのを待ってください。ページを離れても、すでに受け付けられた保存はキャンセルされません。

無効な入力は、説明とともに入力画面に残ります。編集中に別の場所で設定が変更された場合は、**再読み込み** を選び、更新された設定と下書きを比較してから、もう一度確定してください。再読み込み は確認用に下書きを保持しますが、自動保存はしません。削除済みの項目は保存できません。

変更は保存されたものの実行中のアプリに適用できなかったと表示された場合、保存値はすでに変更されています。保存が失敗したと考えるのではなく、再試行または再起動の指示に従ってください。パスワードで保護された設定は、開き直すと再認証を求められる場合があります。
