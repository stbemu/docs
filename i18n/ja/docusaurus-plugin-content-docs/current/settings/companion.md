# Companion {/* #companion */}

**設定 > Companion** を開くと、Companion サービスとペアリング済み端末を管理できます。このページを開くだけでは、ペアリングは開始されません。

## Companion サービス {/* #service */}

サービスの有効・無効やポートを設定し、サービスと検出の状態を確認します。起動に失敗して **接続サービスを再試行** が表示された場合は、報告された問題を解消してから使用してください。サービスが有効でも、まだ接続を待ち受けているとは限りません。状態と表示されたアドレスを確認してください。

## Companion をペア設定 {/* #pairing */}

新しい Companion 端末を許可したいときに、明示的にペアリングを開始します。ペアリングの受付時間内に、表示されたワンタイムコードを使用してください。不要になったらペアリングの受付をキャンセルします。ペアリングコードの画面は、画面キャプチャから保護されています。

## 記憶済みの Companion {/* #remembered-devices */}

記憶済みの端末を確認し、アクセスを取り消したい端末を選びます。取り消しには確認が必要で、選択した端末に適用されます。ペアリングによる信頼と取り消しの記録は、[設定のバックアップ](/settings/backup-restore)では転送されません。

[従来のリモコン](/settings/common-settings#legacy-remote) カテゴリでは、古い MAG ソフトウェアリモコン向けの別のサービスを設定します。

スマートフォン・タブレット用アプリについては、[StbEmu Companion のガイド](../stbemu-companion/index.md)を参照してください。
