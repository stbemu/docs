# バックアップと復元 {/* #backup--restore */}

**設定 > バックアップと復元** を開きます。このカテゴリは、アプリでバックアップ操作が有効になっている場合にのみ利用できます。

## バックアップの保存と共有 {/* #save-or-share-a-backup */}

**設定とプロファイルを保存…** を選び、Android のドキュメント選択画面で保存先を指定します。**設定とプロファイルを共有…** を選ぶと、バックアップを作成して Android の共有機能で送信できます。

ドキュメント選択画面を利用できない場合は、アクセス可能なバックアップフォルダーとアプリ内ファイルブラウザーが使用されます。**保存済みのバックアップを参照** には、利用可能なフォルダーで見つかったバックアップが表示されます。端末の権限や利用可能なファイルプロバイダーによって、アクセスできるファイルが制限されることがあります。

## バックアップの復元 {/* #restore-a-backup */}

1. **設定とプロファイルを復元…** を選んでバックアップを指定するか、保存済みバックアップのブラウザーから選びます。
2. ファイル名、プロファイル数、表示された復元の影響を確認します。
3. 復元を確定します。選択画面をキャンセルした場合や権限を拒否した場合、復元は開始されません。

復元すると、一致するプロファイルが更新され、アプリの設定が復元され、リモコンのキーマッピングが置き換えられます。Companion サービスの識別情報、認証情報、取り消した端末の記録、操作履歴は、持ち運び用のバックアップには含まれません。

:::warning
復元は複数の段階で変更を適用します。後の段階が失敗しても、それ以前の変更はすでに保存されている場合があります。失敗した場合は設定を再読み込みし、現在の構成を確認してください。このローカル復元処理には、復元全体のロールバックや、選択可能な結合・置換モードはありません。
:::
