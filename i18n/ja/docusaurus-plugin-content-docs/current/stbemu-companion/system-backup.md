# Android システムバックアップ {/* #android-system-backup */}

**Settings > Backups > System backup** を開きます。Android の復元が成功すると、Android システムバックアップから Companion の設定、保存済みデバイスと名前、検証済みの信頼関係、有効なままのペアリング認証情報を復元できます。ペアリング済みデバイスに [StbEmu の JSON バックアップ](backups.md)を復元する操作とは別です。

## ローカルアーカイブを含める {/* #include-local-archives */}

**Include local archives** は既定で有効です。ローカルライブラリにある、対象となる完了済みの StbEmu バックアップを、今後のシステムバックアップに含めます。オフにしてもローカルファイルや Companion の設定・デバイスは残りますが、今後のバックアップにはアーカイブが含まれません。過去のクラウド上の内容は削除されません。

このページには、選択した内容の推定サイズが表示されます。再計測するには **Refresh estimate**、Android のバックアップ設定を確認するには **Open Android settings**、自分でファイルをエクスポートするには **Open archive library / manual export** を使います。

## 利用条件と制限 {/* #availability-and-limits */}

Companion 自体は Android 8 に対応していますが、システムバックアップには **Android 9 以降**が必要です。暗号化されたクラウドバックアップには、対応するアカウント、安全な画面ロック、Android のクライアント側暗号化も必要です。実行時期、転送方式の適格性、復元の可否は Android が管理します。

クラウドの公称容量枠は **25 MiB** ですが、実際に利用できる枠はそれより少ないことがあります。デバイス間転送の **256 MiB** という上限はアプリの制限であり、転送容量を保証するものではありません。選択した内容全体が大きすぎる場合は、ローカルアーカイブを除外するか、手動でエクスポートしてください。Companion が選択内容の一部だけを黙ってバックアップすることはありません。

見積もりやローカル準備のメッセージは、Android がクラウドにバックアップを保存したことの確認にはなりません。見積もりが利用できない場合も、バックアップのサイズがゼロという意味ではありません。バックアップが無効または非対応と表示された場合は、データが保護されていると思い込まず、アーカイブを手動でエクスポートしてください。

## Android が Companion を復元した後 {/* #after-android-restores-companion */}

復元されたデバイスを接続済みとして表示するには、検証が必要です。引き続き許可されているペアリング認証情報は、新しいペアリングなしで再接続できます。ただし、復元によって StbEmu 側の取り消しを元に戻すことはできません。復元されたコピーは同じ許可を共有するため、その許可を取り消すとコピーにも影響します。

ライブラリには、実際に復元された完了済みアーカイブファイルが表示されます。メタデータだけでは、存在しないファイルを再作成できません。未完了の操作が自動的に再送されることはありません。再接続し、利用可能な場合は[操作結果](profiles.md#operation-results)を確認してください。
