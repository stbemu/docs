# バックアップと復元 {/* #backups-and-restore */}

Companion の **Backups** ライブラリは、完了した StbEmu の JSON バックアップをスマートフォンやタブレット内に非公開で保存します。保存済みファイルはオフラインでも利用できます。このライブラリは、Companion 自身の状態を保護する [Android システムバックアップ](system-backup.md)とは別です。

![バックアップライブラリとデバイスのバックアップ作成](/img/companion/backup-library.png)

## ファイルの保存と管理 {/* #save-and-manage-files */}

- **Create backup:** 接続済みでペアリング済みのデバイスの **Create backup** 操作を開き、**Backup name** を入力して **Create backup** を選びます。**Backup saved** が表示されるまで待ちます。
- **Import backup:** アプリメニューから **Backups** を開き、**Import backup** を選んで StbEmu の JSON ファイルを指定します。ローカルのインポート、エクスポート、共有には、StbEmu デバイスへの接続は不要です。
- **Export JSON:** ライブラリのバックアップ項目でこの操作を選び、外部の保存先を指定します。
- **Share JSON:** ライブラリのバックアップ項目でこの操作を選ぶと、Android の共有シートが開きます。開いただけでは、選択したアプリへの受け渡し完了は確認できません。
- **Delete local backup:** そのローカルコピーの削除を確定します。元の StbEmu デバイスは変更されません。

JSON の上限は **16 MiB（16,777,216 バイト）**です。インポートしたファイルは検証され、元のバイト列が保持されます。インポートしたファイルには **Source device unknown** と表示されます。整合性の確認で作成者まで分かるわけではありません。外部へのエクスポートに失敗すると、保存先に不完全なファイルが残ることがありますが、既存のローカルバックアップは保持されます。

:::note
バックアップファイルには、パスワード、ポータルのデータ、デバイス識別子が含まれることがあります。エクスポートや共有でもこれらの値は残るため、それを考慮して保存先や共有相手を選んでください。
:::

## バックアップを復元する {/* #restore-a-backup */}

1. ライブラリの項目、またはデバイスの操作ページで **Restore backup** を選びます。
2. **Destination device**、**Backup to restore**、対応する **Restore mode** を選びます。
3. **Review restore** を選びます。追加・上書き・削除されるプロファイル、**Changed settings**、リモコンの割り当て、除外されるローカルメタデータ、互換性のない項目やロックされた項目を確認します。
4. 確認のチェックボックスにチェックを入れ、**Apply restore** を選びます。

![Merge の動作を示す復元画面](/img/companion/restore.png)

**Merge** は UUID が一致するプロファイルを上書きし、新しいプロファイルを追加し、送信先にしかないプロファイルを保持します。**Replace all** は、バックアップにない送信先のプロファイルも削除します。一致の判定はプロファイル名ではなく識別子に基づきます。どちらのモードも、移植可能なアプリ設定とリモコンの割り当てを復元します。ローカルの行 ID、アプリのバージョン、更新ディレクトリなど、送信先固有のローカルメタデータは除外されます。

:::warning
適用する前に、すべての上書きと削除を確認してください。**Replace all** はプロファイル一式を置き換えるもので、選択したプロファイルだけを追加する方法ではありません。選択的にコピーするには、[プロファイルの転送](transferring-profiles.md)を使ってください。
:::

## 結果と保存した設定の適用 {/* #results-and-applying-saved-settings */}

プレビューの期限が切れた場合は、**Start a new attempt** と再確認が必要です。結果が不明な場合は、復元を繰り返す前に[操作結果](profiles.md#operation-results)を確認してください。元のバックアップが利用できなくなっていても、結果の回復処理で送信先に照会できます。

設定の保存と実行時の反映は別です。変更があった場合、仮想リモコンの設定は StbEmu の次の通常の一時停止・再開時に反映され、キャッシュサイズには StbEmu プロセスの再起動が必要です。言語変更ではアクティビティが再作成されることがあります。UPnP 互換性フラグは、再起動後も含め、現在の UPnP の実行状態を切り替えません。**Check result** はこれらの実行時の更新を再試行しません。
