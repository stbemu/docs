# プロファイルと設定の転送 {/* #transferring-profiles-and-settings */}

転送を使うと、異なる二つのペアリング済み StbEmu インストール間で、選択した内容を直接コピーできます。両方が接続され、選択した送信元と送信先の操作に対応している必要があります。同じインストール内にコピーする場合は、[Copy profile > This device](profiles.md#copy-a-profile) を使ってください。

![対応する送信先を待っている転送画面](/img/companion/transfer.png)

## 選択と確認 {/* #select-and-review */}

1. 送信元デバイスを開き、**Transfer to another device** を選びます。
2. **Destination device** を選びます。選択できるデバイスがない場合は **Devices** に戻り、別のペアリング済みデバイスを接続して再試行します。
3. **Application settings and remote mappings**、プロファイル、または両方を選びます。プロファイルについては **Do not copy profiles**、**All profiles**、**Choose individual profiles** のいずれかを選びます。少なくとも一つのカテゴリを選ぶ必要があります。
4. **Review transfer** を選びます。新しいプロファイル、設定変更、リモコン割り当てへの影響、アクティブなプロファイルの変更、除外項目、非互換の内容を確認します。
5. **I confirm these changes** にチェックを入れ、**Confirm transfer** を選びます。

個別に選択するには、送信元の完全かつ最新のプロファイル一覧が必要です。選択したプロファイルが見つからなくなった場合は、**Refresh** で一覧を確認し、それでも見つからないプロファイルのチェックを明示的に外してください。更新によって選択済みプロファイルが勝手に削除・置換されることはありません。

## 変更される内容 {/* #what-changes */}

転送されたプロファイルは、送信先で新しい識別情報を持つ新規コピーになります。送信先にある既存のプロファイルは残ります。MAC アドレス、シリアル番号、デバイス ID、その他のプロファイル値はそのまま保持されるため、コピーによって新しい契約やプロバイダーの許可が得られるわけではありません。この手順には **Merge**/**Replace all** の選択肢はありません。これらは[バックアップの復元](backups.md#restore-a-backup)のモードです。

プロファイルのみの転送では、送信先のアプリ設定、リモコンの割り当て、現在のアクティブ選択が保持されます。設定のみの転送では、送信先のプロファイルとアクティブ選択が保持されます。両方をコピーする場合、送信元のアクティブなプロファイルが含まれているときに限り、その新しいコピーがアクティブになります。含まれない場合は、送信先のアクティブ選択が保持されます。

アプリ設定には、移植可能な StbEmu の設定とリモコンキーの割り当てが含まれます。Companion の言語・テーマ、ペアリングの許可、サービスの識別情報、操作履歴は含まれません。サポートされていない値は、黙って捨てられるのではなく報告されます。確定する前に、パスワード関連の設定やその他の上書き対象を確認してください。保存した設定によっては、StbEmu のライフサイクルの変化や再起動が必要です。[保存した設定の適用](backups.md#results-and-applying-saved-settings)を参照してください。

送信元スナップショットの検証完了を Companion が報告した後は、送信元が切断されても、その試行を続行できます。転送によってバックアップライブラリに永続的な項目は作成されません。結果が不明な場合やキャンセルした場合は、[操作結果](profiles.md#operation-results)を使ってください。
