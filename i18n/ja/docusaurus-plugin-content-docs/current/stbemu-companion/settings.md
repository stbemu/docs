# Companion の設定 {/* #companion-settings */}

アプリメニューを開いて **Settings** を選びます。これらの設定は、スマートフォンやタブレット上の Companion に適用されます。ペアリング済みの StbEmu インストールを変更するには、そのデバイスの操作を使ってください。

![Companion の設定カテゴリ](/img/companion/settings.png)

## 言語、外観、振動 {/* #language-appearance-and-vibration */}

**Interface** を開きます。

- **Language:** 利用可能なアプリの言語を選びます。現在、Companion では **English** と **Ukrainian** を利用できます。ドキュメントの言語を変えてもアプリの言語は変わりません。
- **Theme:** **Light** または **Dark** を選びます。
- **UI haptic feedback:** アプリのボタン、メニュー、選択コントロールで振動します。
- **Remote control haptic feedback:** リモコンから送信するキーの押下、長押し、連続入力で振動します。

両方の振動スイッチは既定でオンで、それぞれ独立しています。UI の振動をオフにしても、リモコンの振動はオフになりません。振動なしでも、リモコンの画面上のフィードバックは利用できます。

設定はローカルに保存されます。保存に失敗した場合は、表示された再試行やエラーの案内に従い、選択値を確認してください。未保存の選択が保持されたとは考えないでください。

## バックアップ設定とライセンス {/* #backup-settings-and-licenses */}

**Backups > System backup** では、Companion の Android バックアップを設定します。アーカイブの追加、容量の見積もり、復元の制限については、[Android システムバックアップ](system-backup.md)を参照してください。普段使う **Backups** ライブラリはアプリメニューから開きます。これはシステムバックアップの設定ページとは別です。

**About > Third-party licenses** には、Companion とともに配布されるライブラリの通知が表示されます。
