# リモコン {/* #remote-control */}

接続済みデバイスを開いて **Remote control** を選びます。この操作は、デバイスが許可済みのリモート入力に対応している場合にのみ表示されます。これらのボタンは StbEmu とそのポータルを操作するもので、[旧式リモコン](../settings/common_settings.md#legacy-remote)で説明する従来の MAG リモコンサービスとは別です。

![色付きキーと方向パッドを備えたスクロール可能なリモコン](/img/companion/remote-control.png)

通常の操作はボタンをタップします。対応している場合は、押し続けると長押し操作や連続入力になります。指を離すと長押しが終わります。利用できるボタンと長押しの動作はデバイスによって異なり、すべてのキーが連続入力に対応しているわけではありません。スクロールすると、再生、音量、チャンネル、数字キーなど、残りのボタンを使えます。

同時に有効になるキー操作は一つだけです。リモコンページやアプリから離れたり、接続や権限が失われたりすると、進行中の入力は中止されます。再接続後にリモート入力が再送されることはありません。再接続してから、意図的にもう一度押してください。

## フィードバックの確認 {/* #read-the-feedback */}

端末側の押下・長押しフィードバックは、Companion が操作を認識したことを示します。**Awaiting device confirmation** は結果を待っている状態です。**Device accepted input** は StbEmu が入力を受け付けたことを示しますが、チャンネルやポータルの操作が完了したとは限りません。

**Input target unavailable** の場合は接続を確認してください。**Authorization expired. Pair again.** の場合は、StbEmu で新しいコードを表示し、Companion に入力してください。操作がサポートされなくなった場合は、使用をやめて利用可能なボタンを確認します。入力が利用できない状態が続く場合は再接続してください。

リモコンの振動は **Settings > Interface > Remote control haptic feedback** で変更します。**UI haptic feedback** とは独立した設定です。振動をオフにしても、画面上のフィードバックは表示されます。
