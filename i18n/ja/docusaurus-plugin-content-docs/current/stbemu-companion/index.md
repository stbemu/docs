# StbEmu Companion {/* #stbemu-companion */}

**StbEmu Companion** は、ローカルネットワーク上の StbEmu をスマートフォンやタブレットから管理する Android アプリです。リモコン、プロファイル管理、デバイス間の転送、専用のバックアップライブラリを提供します。テレビチャンネル、プレイリスト、IPTV の契約は提供しません。

:::note
StbEmu Companion で接続するデバイスには、**StbEmu 2.0.25 以降**がインストールされている必要があります。
:::

:::note
StbEmu Companion はまだ一般公開されていません。ベータテストへの参加を希望する方は、[support@stbemu.com](mailto:support@stbemu.com) までメールでご連絡ください。
:::

Companion には Android 8.0 以降と、Companion に対応した StbEmu のビルドが必要です。両方のデバイスを相互に通信できる同じローカルネットワークに接続し、[StbEmu の Companion 設定](../settings/companion.md)でサービスを有効にしてください。ペアリングによって接続が許可されます。操作は、接続先のデバイスと現在のアクセス権限でサポートされている場合にのみ表示されます。

![ペアリング済み StbEmu デバイスで利用できる操作](/img/companion/device-actions.png)

まず[接続とペアリング](connecting-devices.md)を行い、次のガイドを選んでください。

- [リモコン](remote-control.md)：ポータル内の移動や、対応している再生キーの操作を行います。
- [プロファイル](profiles.md)：プロファイルの表示、作成、編集、削除、コピーを行います。
- [プロファイルと設定の転送](transferring-profiles.md)：選択した内容を別のペアリング済みデバイスにコピーします。
- [バックアップと復元](backups.md)：StbEmu の JSON ファイルの保存、インポート、エクスポート、共有や、デバイスへの復元を行います。
- [Companion の設定](settings.md)：言語、外観、振動、ライセンスについて説明します。
- [Android システムバックアップ](system-backup.md)：Companion 自身の設定、保存済みデバイス、任意のアーカイブのバックアップについて説明します。

ドキュメントは、アプリよりも多くの言語で提供されています。このガイドでは、ボタン名や設定名にアプリの英語表記を使っています。スクリーンショットも英語の画面です。デバイス名、バージョン、利用できる操作は例と異なる場合があります。
