# プロファイルの管理 {/* #managing-profiles */}

接続済みデバイスを開いて **Profiles** を選びます。一覧にはプロファイル名、識別子（UUID）、利用可能なポータルアドレスが表示されます。プロファイルを選ぶと設定を確認できます。次のページには **Load more**、最新データの取得には **Refresh** を使います。操作はデバイスがサポートする権限によって異なります。

## 作成、編集、削除 {/* #create-edit-and-delete */}

- 一覧から **Create profile** を選びます。対応する作成項目には **Name** と **Portal URL** があります。変更しなかった項目には StbEmu の既定値が使われます。
- プロファイルを開いて **Edit profile** を選び、サポートされている編集可能な項目を変更します。編集した項目だけが変更され、デバイスが保持するその他の設定は残ります。
- **Delete profile** を選んで削除を準備します。確定する前に、アクティブなプロファイルの変更や代わりに使われるプロファイルを確認してください。

**Review changes** を選び、プレビューと警告を確認してから、**Confirm changes** または **Confirm deletion** を選びます。最初の操作では、すぐに保存や削除は行われません。互換性のない変更は確定できません。編集中にプロファイルや利用可能な項目が変わった場合は、更新して再確認してください。

StbEmu のプロファイル項目の意味は、[STB プロファイル](../settings/profiles.md)を参照してください。

## プロファイルをコピーする {/* #copy-a-profile */}

プロファイルを開いて **Copy profile** を選びます。同じデバイス内にコピーするには **This device** を選び、変更を確認して確定します。コピーには新しい識別情報が割り当てられるため、名前だけで判断しないでください。成功後に **Edit copied profile** が表示される場合、この操作は元のプロファイルではなく、結果として返されたコピーを開きます。

条件を満たす別のペアリング済みデバイスを選ぶと、そのプロファイルを選択した状態で[転送ガイドの手順](transferring-profiles.md)が開きます。

## 操作結果 {/* #operation-results */}

接続に失敗した場合や結果が不明な場合は、次の変更を始める前にデバイスの **Recent operation results** を開き、**Check result** を使ってください。結果の確認には許可済みの接続が必要です。元の操作を照会するもので、変更を再送することはありません。[転送](transferring-profiles.md)や[バックアップの復元](backups.md)も同様です。

期限切れのプレビューは、明示的にもう一度確認する必要があります。キャンセルと保存が同時に進むことがあるため、**Cancel operation** で変更が元に戻ったと思い込まず、最終結果を読んでください。**Changes saved on the device** はデータの保存を示しますが、実行中の状態の更新はまだ完了していないことがあります。結果を確認しても実行中の状態の更新は再試行されません。また、削除されたコピーのプロファイルが履歴の確認で再作成されることはありません。
