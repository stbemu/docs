# StbEmu {/* #stbemu */}

**StbEmu** は、セットトップボックス（STB）向けの Web ポータルを
スマートフォン、タブレット、TV ボックスなどの Android 端末で読み込む、Android 8.0 以降向けのアプリです。
現在、ウクライナの Infomir 社が製造する複数の STB モデルのエミュレーションに対応しており、
MAG 250、MAG 270、MAG 322 などを利用できます。[エミュレート可能な端末の一覧](/supported-devices)を参照してください。

:::note
**StbEmu** は中立的な技術ツールであり、ハードウェアエミュレーターです。メディア、
プレイリスト、ストリーミングポータルの提供、ホスティング、インデックス作成は行いません。利用者が合法的に取得したコンテンツにアクセスするためのアプリです。
開発者は第三者のコンテンツプロバイダーとは一切提携していません。
:::

アプリには無料版と有料版があります。[無料版](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free)には広告が表示されますが、[Pro 版](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro)には表示されません。
これが両者の主な違いです。

[ダウンロード](/download)のページを参照してください。
