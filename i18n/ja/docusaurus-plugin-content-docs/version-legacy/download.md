# ダウンロード {/* #download */}

![StbEmu Free](/img/stbemu_free_icon.png)

StbEmu には、無料版の Free と有料版の Pro の 2 種類があります。

| 無料版 | Pro（有料）版 |
|--------------|---------------------------------------------------|
| 広告あり | 広告なし |
| | MAG 250 用ソフトウェアリモコンに対応 * |
| [Google Play からダウンロード](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.free) | [Google Play からダウンロード](https://play.google.com/store/apps/details?id=com.mvas.stb.emu.pro) |

* Google Play のソフトウェアリモコンを使用する前に、MAG 250 に対応していることを確認してください。
